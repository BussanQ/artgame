# 赤潮 · 战术演习

TypeScript + Vite 网页自走棋开发框架和单机原型。参考《战争艺术：赤潮》公开自走棋资料，使用独立原型数值、ImageGen 生成棋子形象与 2.5D 战场表现。

## 运行

推荐 Node.js 22.12+ 或 24。

```sh
npm install
npm run dev
```

浏览器打开终端输出的本地地址（默认 http://127.0.0.1:5173）。

```sh
npm run build       # TypeScript 检查 + 生产构建
npm run preview     # 预览 dist
npm run test:engine # 仅必要引擎模块测试
npm run test:visual # 仅必要表现层模块测试
```

## 操作

购买棋子 → 点击备战棋子 → 点击棋盘下半区部署 → 开始战斗 → 胜负特效与自动结算 → 自动进入下一回合准备阶段。终局停留在最终战报。点击场上棋子后可换位、撤回或出售；悬停备战棋子可查看属性与动作信息。三枚同星同名棋子自动升星，购买经验提高人口，锁定商店保留下一轮卡牌。

已实现 8 人本地演习（7 AI）、共享卡池、12 种棋子、8 类简化羁绊、经济、升星、自动战斗与排名。刷新页面会重开。完整原版技能、装备、野怪、在线多人和原作美术尚未实现。

资料与开发方案从 [docs/README.md](docs/README.md) 开始。当前实际规则与原作差异见 [原型规则](docs/design/prototype-rules.md)。本项目没有部署远程服务。

## 视觉升级

已生成并接入 12 个独立透明棋子形象及云海遗迹背景；战场采用 2.5D Canvas 绘制，支持移动插值、弹道、挥击、技能光效、伤害飘字和死亡淡出。顶部「观看战斗演示」可直接观看六对六演示；可暂停或切换速度。

8 种近战单位拥有不同的攻击动作；4 种远程单位分别采用三连点射、蓄力狙击、抛射轰击与聚能轨道炮，包含独立后坐动作及命中特效。实现说明见 [兵种动作与交互](docs/design/melee-and-bench.md)。

新增验证命令：`npm run test:visual`。美术说明及完整提示词见 [视觉重制说明](docs/design/visual-remake.md)。这是 AI 重制形象与精灵动画，未使用原作 3D 模型。
