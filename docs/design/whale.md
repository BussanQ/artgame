# 幻鲸 / singleplayer-0.18

当前 46 种可招募棋子，18 近战、28 远程，22 类羁绊。新增五费海神/攻城幻鲸，补充后期针对高生命阵容的持续输出选择；沿用 metamorph 战斗版本。

## 资料与自主配置

[S29，2019-07-03](https://news.17173.com/z/zzq/content/07032019/230406491.shtml)记录幻鲸改版后按最大生命比例造成真实伤害，并用于海神阵容。[S30，2019-05-27](https://news.17173.com/z/zzq/content/05272019/180953197.shtml?_platform=PC)记录五费、十秒持续输出。两篇不同日期的转载不是统一官方配置。其余基础属性、范围、百分比、打断、装备影响和表现均是本项目的自主实现。

| 配置 | 当前实现 |
|---|---|
| 费用 / 卡池 | 5 金 / 10 份 |
| 分类 | 海神、攻城；飞行，无空军分类 |
| 一星属性 | 1100 生命、90 攻击、4 护甲、射程 3、普攻间隔 1.25 秒 |
| 初始能量 | 35 |
| 潮汐区域 | 施法时锁定当前目标的格子，曼哈顿距离 ≤ 2；不追踪 |
| 时序 | 1 秒后第一次，每秒一次，共十次 |
| 伤害 | 每次为命中目标当时最大生命的 3%/4%/5%，按施法者星级；乘以施法时技能强度 |
| 防御 | 无视护甲、法术减伤与普攻闪避；护盾吸收、不朽免伤仍生效 |
| 引导 | 不移动、不普攻；攻击冷却照常流逝；眩晕、魅惑、阵亡中断 |
| 反制 | 离开区域、分散站位、护盾、残魂、控制或击杀施法者 |

每个脉冲重新筛选当前敌人与站位，已离开目标不受伤，后进入者可命中。攻击属性和攻速不提高百分比或脉冲频率。范围可以命中隐蔽单位；真实伤害仍触发灵能反伤，同一次脉冲被反伤击杀后停止处理余下目标。引导期间受击和海神命中可照常回能，但不会并行重叠施法；结束后再次满能量才重新施放。

AI 沿用海神/攻城偏好、完整羁绊选阵与后排站位；装备评分明确计作技能输出单位。未为幻鲸提供额外金币或卡池优待。空海演示用二星幻鲸替换玄龟，并携带聚能法杖，展示施法和被切后排的风险。
