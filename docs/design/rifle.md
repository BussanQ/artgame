# 0.67 神枪手被动火力

神枪手改为依靠普通攻击的物理核心，取消能量累积和原型主动破甲。每次开火只产生一次真实伤害；一、二、三星基础间隔为1、0.75、0.5秒，继续接受装备、野兽攻速与减速，最低0.25秒。沉默不阻止普通射击，眩晕、石化与阵亡照常限制行动。

基础身板采用玩家实测表首行：400生命、34–38攻击取均值36、5甲、4格、1秒。表中名称是“神射手”，与当前一费神枪手的对应属于定位推断。星级射速梯度和“快速射击”名称为本地适配；玩家文章中带羁绊装备的一秒三枪不能作为额外三段伤害依据。详见[原始资料与边界](../research/rifle-history.json)。

战斗、备战详情和AI共用星级间隔；AI不再给旧主动技能估值，纯能量／法强装备不投给没有收益的被动核心。战报记录实际开火次数；菜单“战斗演示 → 步枪火力”可对比三个星级。当前版本为`rifle`、存档schema66，39版旧定义、旧主动破甲、原形象及回放保留，进行中的旧战斗到准备期才升级。

红灰形象使用内置ImageGen编辑既有角色，两次生成，第二次完善头盔、枪口与双脚的透明留白。原生PNG直接复制，没有栅格后处理；旧图原本已有透明通道。[完整提示词与文件指纹](../research/rifle-assets.json)。

推送前106项相关模块检查与生产构建通过；不开展整局或批量采样。新增神枪手的实际浏览器专项画面仍待核对，模块路由断言不代表画面验收；0.66藤妖画面记录保持为旧版本记录。[验证清单](../analysis/rifle-v067-validation.json)。
