# 0.69 杀人蜂双圈爆发

杀人蜂补为脆身板的远程爆发位：450生命、31攻击、5甲、3格、1.3秒，四费与原有飞行标签保留。满能量且20秒冷却结束时，原地蓄力0.75秒，释放内圈200／300／400、外圈100／150／200基础法伤。每名敌人仅结算一个圈，边界归内圈；法强放大伤害，攻击力不增加震荡伤害。

基础属性和20秒冷却有S04原始实测表支持；双圈伤害及原始半径9／11／14与20／22／25来自繁体原作者测量。这里将9个原始单位归一为一个棋格，属于本地换算。六月繁体记录与七月身板不是一张已确认客户端卡，技能原名、初始能量、起手、时序及反伤交互仍有资料缺口。[原始字段与适配边界](../research/hive-history.json)。

普通攻击采用三针连射的本地适配，每针100%当前攻击，后两针相隔0.25秒，每轮仅首针恢复普通攻击能量。各针独立结算护甲、闪避、护盾、吸血和反伤；硬控、阵亡、阵营改变或目标失效取消余针。沉默不取消普通连射；攻速只缩短轮间隔，每轮最低0.75秒，备战详情与战斗共用下限。0.71复核补足S19原作者对三连击的谨慎目测观察，为方向提供一手线索；每针倍率、间距和回能尚无完整原卡或原始公告确认，未把8月转载当作早期已证实参数。

蓄力时展示金色内圈和绿色外圈，不能移动或普攻；眩晕、沉默、魅惑和阵亡可打断且不退款。释放时按敌人当前站位、法术减伤和护盾判定，敌人可以走出范围，飞行或隐蔽敌军仍可能被波及；不附加毒伤、控制或减甲。普通针被致死反伤会停下余针，已释放的同次震荡则完成其他接触结算。AI采用部分连射与范围覆盖的折扣估值，未凭这一个局面证明整体平衡。

内置ImageGen两次修整既有金甲蜂形象，补齐翼尖并增加透明留白，原生PNG直接复制到[新资产](../../public/assets/units/wasp-hive.png)，旧图不覆盖。[完整提示词与指纹](../research/hive-assets.json)。

`hive`为第42个战斗规则版本，规则`singleplayer-0.69`、schema68；41版旧身板、旧范围技能、旧形象和两个修改前回放SHA保留。旧目录、经营资源、历史与播放进度不变，进行中的旧战斗到准备阶段才升级。战报增加连射轮数、发针次数、内外圈接触和蓄力中断，回看不会泄露未来计数。

60项相关模块及生产构建通过；桌面1280×720／390px已核对蓄力、释放、连射、新形象、详情、战报、图鉴、滚动关闭和退出资源。同一二对二在1秒打出内圈408＋外圈204＝612技能生命伤害，在2秒显示已发两针、剩一针，之后被硬控取消余针；没有新增完整经营局或批量采样。[验证记录](../analysis/hive-v069-validation.json)。整体难度、多构筑经营与真实设备性能继续推进。
