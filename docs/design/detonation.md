# 爆裂虫自爆与前排站位

`singleplayer-0.82`，战斗版本 `detonation`，存档schema81。64种棋子、22类连携和19件装备保持，改进爆裂虫的属性、自爆、攻击画面与AI估值。

## 历史依据和边界

本轮目视[S04原始属性表](../research/images/s04-main-attributes.jpg)第22行：二费、500生命、38–42攻击、零甲、2格射程、1.2秒间隔、被动。[五月9日公告](https://www.taptap.cn/moment/15209355339104422?group_id=42979)也记录费用1→2、射程3→2；公告署名及未核验账号标识保留于研究记录。

[原作者七月实战评测](https://www.taptap.cn/moment/15216144952591652)描述死亡立即爆炸，原来的自爆动画承伤与冲锋已移除。[七月11日社区转载](https://forum.gamer.com.tw/Co.php?bPage=0&bsn=36595&sn=141&subbsn=1)及[当日媒体报道](https://news.17173.com/z/zzq/content/07112019/223915220.shtml?_platform=PC)索引给出200/300/400→200/350/500。后两者是二手证据，本轮没有取得发行方完整同版技能卡，也未证实它们的来源独立。

因此采用200/350/500为分星基础伤害；伤害类型、法强／防御公式及横纵合计2格范围继续明确作为本地适配。固定攻击40、既有星级成长及离散时钟也是实现选择，不声称统一历史版本已还原。原始图片、HTML指纹、时间边界及未知项见[研究记录](../research/detonation-history.json)。

## 战术与结算

- 500生命、零甲、2格射程和1.2秒间隔改变它的接敌位置。普通攻击使用一次物理喷吐；鼓囊、收颚和弹道只呈现一次真实普攻，不追加伤害。
- 每场在首次阵亡当帧自爆，基础200/350/500乘技能强度，再计算技能防御、魔抗和护盾。装备生命不会提高爆炸；法强、前排保护与靠近敌人的阵位分别有实际取舍，远处阵亡允许空爆。
- 自爆不使用能量，眩晕、沉默和封能不延迟死亡被动。范围可命中隐形、飞行和已有召唤物；不伤友军，不追踪范围外敌人。
- 先消耗一次机会，再处理敌方爆裂虫的递归连锁。每个爆炸固定死亡时位置、阵营和伤害；连锁炸死控制者并解除魅惑后，剩余伤害仍按原快照辨敌。仍存活且是该次爆炸敌军的目标才结算。
- 战报和棋子详情分别显示爆炸次数、有效波及、实际生命伤害与破盾，不计溢出或免疫命中，也不重复增加蜘蛛的诱导普攻伤害。刑杀仍不能把爆裂虫复制为刑傀。
- AI按分星基础伤害和有限波及机会估值，生命只改善生存，能量不增加这项被动收益；法强增加爆炸估值。估值仍是有界启发式，不当作胜率证明。

## 形象和交互

[发行方四月异虫原图](../research/images/s20-insects-client.jpg)显示蓝色圆囊、白色后壳与深青卷颚；该图的一费卡面与七月二费属性分期记录。内置ImageGen生成透明棋子，原始字节复制到 `public/assets/units/blastbug-detonation-v082.png`；完整提示词与生成指纹在研究记录中，未使用CLI/API。旧橙色形象仍供历史战斗使用。

战斗有独立鼓囊收颚喷吐、死亡青色爆发及实际波及格轮廓；低动态模式保留静态范围与文字。图鉴、商店、战场和战报均接入同一版本形象。实际画面验收发现战斗图像入口仍选旧图，已补接并定向验证。

菜单 → 战斗演示 → **囊爆连锁** 提供合法1对1等星固定阵容，退出后返回原经营进度；不改商店、库存或卡池。

## 版本与验证

schema80→81只在准备阶段升级战斗规则，战斗／结算／终局保留 `sea-fog`；目录、资源、历史与播放状态保持。旧定义棋子在新战斗中仍保留原配置；54代定义、三档星级呈现、19件装备及一场0.81异虫小回放SHA保持。

必要模块检查与桌面／390px验收见[本轮验证记录](../analysis/detonation-v082-validation.json)。仅使用直接模块局面及几个固定小阵容（最终演示1对1、开发中的2对3及旧2对2），没有全量测试、完整经营局或批量对战。截图统一保存在根目录 `tmp/` 并忽略Git。

其他原型能力、统一历史版本、整体难度、多构筑经营与真实设备性能继续推进，完整单机目标尚未完成。
