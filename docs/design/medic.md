# 军医 / singleplayer-0.19

当前47种可招募棋子：18近战、29远程，22类羁绊。本轮增加一费步兵/支援军医及持续治疗、独立注射枪攻击、音效、生成形象、AI选阵和增量存档迁移。沿用metamorph战斗版本；原有棋子的战斗计算不变。master的显示名由混用的“棍奴熊猫”更正为“武僧熊猫”，保留ID、四费属性与横扫技能；这只修正名称，不代表已经还原历史的一费肉盾设计。

## 历史依据与自主配置

[S20发行方种族表](https://game.xiaomi.com/viewpoint/1103968488_1556086391745_13)及[S25职业表](https://wap.gamersky.com/sygl/Content-1179303.html)支持军医的步兵/支援分类。[S32官方来源转载](https://news.17173.com/content/05172019/112538567.shtml)把军医列为一费治疗棋子。

[S31军医攻略](https://www.8090.com/news/xinqing/article_329043.html)的检索摘要提到生命守护、小范围多次治疗、300/400/500和16秒冷却，但页面直读失败；早期社区资料对治疗量是全体共享预算还是每名友军总量也有歧义。这里仅参考持续范围治疗方向，采用项目自己的能量系统、四次脉冲及每目标治疗值，不宣称复原原作全部参数。

| 配置 | 当前实现 |
|---|---|
| 费用 / 共享卡池 | 1金 / 45份 |
| 一星属性 | 生命500、攻击25、护甲2、射程3、普攻间隔1秒 |
| 分类 | 步兵、支援；地面远程 |
| 施法条件 | 初始能量50，满100且两格内有存活、可治疗的受伤友军；可以包括自己 |
| 区域 | 施法者当时所在格为固定中心，曼哈顿距离≤2；不跟随施法者或友军移动 |
| 时序 | 一秒后首次，每秒一次，共四次 |
| 每次治疗 | 每名合法友军75/100/125，按星级；乘以施法时锁定的技能强度，再取整 |
| 引导 | 不能移动或普攻，攻击冷却正常流逝；眩晕、魅惑或阵亡中断 |
| 排除 | 敌人、已阵亡单位、不朽残魂、涅槃火种、当前范围外单位；不复活、不过量治疗 |

每次脉冲按当前阵营、站位、存活状态重新判断。友军走入可开始受治疗，走出停止；没有受伤友军时保留能量，仍可普攻或追击。受击可以回能，但战斗循环先处理正在引导的技能，不会同时开第二条治疗。治疗统计只计实际回复；支援羁绊的阵亡治疗也会计在该棋子的总治疗贡献中，不能把面板总量全部当作生命守护收益。

## AI与表现

军医按支援角色放在前排后方；法杖作为施法装备参与分配。评分估算最多两名目标、四次中的三次治疗，按技能强度计算，额外价值不超过棋子自身战力的80%。这是有界估值，不意味着每次一定命中三轮。

初稿30%的上限让不同星级的裸装军医和携带法杖军医在同一阵容中完全同分，AI因此按UID选中了无装备者。定向回归使用盾兵、神枪手、两枚同星军医，验证一至三星均优先选择法杖军医、候选不被修改、部署占位合法。此次修改只作用于军医，没有调整所有治疗单位或难度补贴。

普通攻击为泵压、后坐与薄荷色注射弹；技能期间显示绿色固定格区及剩余治疗次数，每次实际治疗使用绿色数值与治疗光效。低动态模式保留静态范围和文字。

内置image_gen生成单枚透明全身棋子，直接复制选用原图，未做程序化抠图。资产位于`public/assets/units/medic.png`，1254×1254 RGBA，alpha范围0–255，透明像素1,138,112，四角透明。完整提示词和原件路径见[军医资产清单](../research/medic-assets.json)，总清单也已收录。这是生成的重制形象，不是原作模型。

## 对局采样与仍待解决的问题

最终[63局采样](../analysis/balance-medic-v019-final.json)使用137/3067/4601三个种子、7种构筑、3档难度，全部通过逐轮经济、卡池、人口和占位检查；报告21份源码哈希与最终规则代码一致。样本是固定策略机器人，不是人类胜率。

同样三个种子的初稿基线由[137种子](../analysis/balance-medic-v019-validation.json)与[另外两种子](../analysis/balance-medic-v019-additional.json)合并；只比较军医估值修正前后，不混用更早的AI版本。

| 难度 | 初稿平均名次 | 修正后平均名次 | 初稿前四/21 | 修正后前四/21 |
|---|---:|---:|---:|---:|
| 休闲 | 2.48 | 2.29 | 19 | 19 |
| 标准 | 5.43 | 5.24 | 6 | 8 |
| 挑战 | 7.05 | 7.62 | 1 | 1 |

军医在玩家阵容中出现的采样回合数186→238；137种子初稿为0，不代表其他种子也无法招募。挑战成绩退步，不能称为整体平衡改善。接下来需要拆分挑战AI的可见对手试算、经济投入和治疗反制，避免用单个种子调参或给予玩家隐藏属性补贴。

另外运行了[移除军医的21局对照](../analysis/balance-medic-v019-control.json)：在独立临时副本中只移除新增单位配置，保留其余代码，137种子的标准平均名次4.86，初稿加入军医后6.71。新增卡池会改变同种子后续抽卡与对局路径，因此该差异不能直接归因于军医战斗强弱；只能证明需要多种子验证。最终平均战斗19.02秒，当前开发机平均回合计算51.16ms、最大370.11ms，不代表手机性能。

整体目标仍未完成：四月53名基线尚缺16项，已有映射中8项分类不同，另有技能/费用差异。见[历史兵种映射](../research/roster-mapping.md)。军医完成是单机内容的一次增量，不能替代原版完整性、真实弱设备表现和最终人工体验审计。
