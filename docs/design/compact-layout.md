## 布局

- 1200px 及以上：指挥官、羁绊、装备位于左侧；棋盘、备战席、招募位于中间；排名、简报、守军位于右侧。1000–1199px 将右侧情报下移，让出棋盘宽度。
- 1000px 及以上将八个备战位竖排在棋盘右侧；战场按可用宽度及 1.8 比例确定高度。中间区域优先保证操作大小，短窗口允许页面滚动。
- 战场比例为 1.8，Canvas 等比放大，只裁去底部装饰前景，完整保留敌方后排头部。点击仍按完整 Canvas 的边界换算坐标。
- 商店保留费用、羁绊、已有数量、合成预览及利息变化。减少重复说明，把详情按钮叠放在卡片角落。
- 备战说明改为更宽的紧凑排版。上、下空间不足时优先放到棋子侧面；空间确实不足时才允许浮层滚动。
- 展开的精确布阵、配方和羁绊保持文档流，允许页面自然增高，不裁掉内容、不新增面板内滚动条。
- 701–999px 使用两栏，情报下移，棋盘比例 1.4、Canvas 等比放大 25%。700px 以下使用下述手机分区布局。

## 手机分区布局

针对“手机端没什么变化”的反馈，700px 以下改为独立视图，不再把全部桌面面板连续堆叠。

- 底部五个按钮切换战场、招募、装备、升级、情报，当前视图使用金色高亮。切换只调整显示状态，不重新创建对局或清除已选棋子，装备页继续使用战场选中的棋子。
- 顶部只保留品牌和菜单，工具入口默认收起。回合、阶段和开始战斗按钮保持一行。开始战斗、演示或历史回放时切回战场。
- 手机棋盘比例由 1.4 改为 1.2，Canvas 宽度由容器的 125% 改为 150%，即在同宽手机上棋子线性尺寸再增大 20%。高度按原始 1280×800 比例缩放；完整棋格范围保持在裁剪窗口内。以上为样式计算值，尚未完成新版本浏览器实测。
- 暂停、速度、分析按钮移动到棋盘下方，避免遮住棋格；备战席固定为四列两行，详情保留独立按钮。布阵、选择、播放及底部导航的主要按钮高度为 40–44px。
- 招募保留三列卡片及原有合成、利息提示，下方提供返回战场布阵入口。升级页包含指挥官和羁绊，情报页保留排名、简报与守军资料。
- 展开精确布阵、长文本及小尺寸屏幕仍允许自然纵向滚动，不强制裁切页面。
