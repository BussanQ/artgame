# 蜘蛛迷梦、来源解除与引火

`singleplayer-0.79`，战斗版本`dream`，存档schema78。补齐蜘蛛的随机策反、来源生存约束和短时引火；兵种总数保持64，复用已有ImageGen蜘蛛形象。

## 原型差异与资料

此前蜘蛛选择3格内攻击最高的非召唤敌人，控制2/3/4秒、统一增加20%攻击；蜘蛛阵亡后控制仍继续。五月九日更新原帖的归档正文明确改为随机选人、5/6.5/8秒，并要求蜘蛛死亡时立即恢复目标。七月社区属性表第23行实际目视为三费、550生命、68–75攻击、5甲、3格、2.2秒攻击间隔和40秒技能冷却。

[逐字段研究与出处](../research/dream-history.json)分别记录五月公告、七月测量和早期媒体技能线索。它们不构成同一个客户端的完整卡面；确定攻击71.5、初始能量50、攻击增幅与嘲讽交互的依据和适配均单列。

## 本局行为

- 满能量时，从3格内可见、存活、非召唤的合法敌人中随机选择一名，策反5/6.5/8秒，攻击增加10/20/30%。无目标保留能量；随机序列可重放，不消耗商店随机数，也不随数组顺序改变。
- 目标立即嘲讽周围2格可见原队友1.5秒。它们后续普攻和追击转向被策反者，不能开始新技能；已经发出的攻击与技能保持既有结算规则。范围和嘲讽时长为本地适配。
- 策反期间可移动和普攻，不能施法或回能。召唤物、刑傀、残魂、火种、已被魅惑者、隐蔽和旋转免控者不成为新目标。被控蜘蛛立即断开自己先前的控制，避免连锁永久改队。
- 来源死亡或进入残魂时在致死伤害当帧断开；来源失去自身阵营、离场，或目标死亡／化蛋／进入残魂也会解除。来源眩晕或沉默不撤回已成功的蛛丝。
- 目标原阵营的灵鱼可以驱散它及附带嘲讽；蜘蛛同队灵鱼不会误解除己方策反。到期只撤回本次攻击增幅，不回滚期间其他合法攻击成长。
- 只改变战斗当前阵营，原归属、棋子、装备和卡池不变。最后敌人被策反时继续等待或交战，不直接判胜。40秒CD在本地40秒战斗上限内按每场一次处理。

战场增加蛛丝连线、目标环和控制来源／剩余时间，低动态模式使用静止连线。战斗演示中新增“迷梦蛛丝”。控制次数、引火人数、诱导普通攻击的实际生命伤害与破盾单列；不把诱导伤害重复加到蜘蛛自身伤害。AI按有限持续时间估值，生命／护甲保护控制来源，法强不虚增控制收益。
