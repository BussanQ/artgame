# 连携与进化的版本继承修复（0.55）

0.54新增`jungle`时，两处枚举判断没有接入该版本：`traitTiers`退回早期`AIRSEA_TRAIT_TIERS`，`mergeCount`退回普通三合一。这会改变整套连携与异虫经营，不能把0.54样本中的树妖/三星减少仅归因于AI估值或树妖身板。该轮先修复规则路由，当时AI评分保持0.54源码指纹，探索中的额外试算尚未接入。随后已完成[公开对手布阵与控制位经营](scouting.md)增量，以下保留修复当时的独立证据。

## 当前行为

- 0.55的`continuity`恢复22类完整连携，包括步兵2/4/6减甲3/9/18、先锋3/6护甲6/14、四/六异能及其他已恢复的累计与受益范围。树妖、雷暴、福音等独立能力继续保留。
- 两种异虫时，两枚同名一星合二星；四种时，两枚同名二星合三星。备战席计入种类，普通棋子仍需三枚。实际卡池份数单独累计，保留合星UID及最多三件装备，溢出材料回库存。
- `COMBAT_VERSIONS`统一版本顺序、类型与存档合法值，能力判断按引入顺序继承。羁绊与进化使用共享判断，后续版本无需再复制一份“允许版本”名单。
- 0.54已经生成的战斗仍按其实际旧行为重算，包括当时的回退；新版本明确保留这个历史例外。没有把修复后的结果套到已完成的旧战报上。

## 存档与准备阶段

schema53→54仅在准备阶段切换`continuity`，校验原存档后用正常合星流程补合遗留对子。持有金币、经验、随机数、共享池和整局价格目录保持；星级、合并后的阵位及库存会按实际进化变化，装备不丢弃。重复加载不会再次发放装备或份数。

战斗、结算和终局继续旧版本及播放位置，下一准备阶段再切换并补合。中间52→53迁移固定`jungle`和0.54字面值，避免当前常量跨越历史阶段。旧目录仍保留其价格/卡池容量；迁移不重置商店或对局。已有终局和历史截图保留为当时证据。
