# 招募决策信息与可搜索图鉴

本增量改善单机准备阶段的信息与操作，不改变 singleplayer-0.12 战斗数值、商店概率或存档格式。

## 招募与交易

商店卡片下方显示持有棋子的真实星级数量，例如“一星 ×2、二星 ×1”，不再把二星仅表述为持有三枚。购买前列出全部升星结果、购买后备战占用，以及跨越十金边界时的利息变化。利息仅按当前余额估算，不预测随后消费、胜负奖励或出售收入。金币不足或合成后仍超备战容量时禁用招募，并保留原因与详情入口。

`src/engine/recruitment.ts` 的 `previewPurchase` 克隆玩家、追加该商店棋子并调用现有 `mergePieces`，支持普通连锁升星、新异虫种类触发其他棋子进化、部署位置保留及装备溢出归还。预览不改金币、随机种子、卡池、UID 或正式阵容；实际 `buy` 复用同一投影，在合法时提交。AI 的购买仍走同一接口，未改变经济规则。

招募 HTML 已从 main.ts 提取至 `src/ui/recruitment.ts`。键盘购买后，原卡消失时焦点转到可购买卡片，随后回退刷新或锁店按钮；弹窗关闭恢复来源。移动端改为两列排列，避免卡片提示需要嵌套横向滚动。

## 图鉴

- 名称、羁绊、定位、技能名称及描述关键词搜索；空格分隔多个关键词时全部匹配，支持英文 ID、大小写及全角字符归一化。
- 费用、羁绊、星级之外，增加近战、远程、飞行筛选，以及费用、攻击、生命、射程排序。数值排序针对基础属性，不推测羁绊和装备加成后的战力。
- 结果计数和无结果提示；一键重置搜索、筛选、星级及排序。搜索只刷新卡片与计数，不替换输入框或打断输入焦点。
- 输入写回 HTML 属性时转义，不把搜索内容当作标记执行。筛选在当前页面会话内保留，刷新恢复默认；不写入对局存档。
