# 0.71 长生鹿多目标双防

长生鹿改为四费远程辅助：850生命、87攻击、5甲、4格、1.8秒。满能量且25秒个人冷却结束时，锁定4格内生命比例最低的3／5／7名其他友军，蓄灵0.5秒后维持5／6／7秒，给予15／20／25护甲和40／50／60个百分点法术减伤，最终法术减伤最多75%。技能本身不治疗、不补盾、不造成伤害；自身不受自己的庇护。

S04原始玩家表第30行支持四费、850生命、79–95攻击、5甲、4格、1.8秒及25秒；攻击取均值87。S05七月原作者评测支持重做后的防御定位，并记录一星15护甲、40法抗。没有取得完整同版本客户端卡，其余星级梯度、目标数、范围、起手、维持时长、法抗到当前百分比公式的换算和交互均为本地适配。技能名继续使用项目已有“长生庇护”，不冒称确认了2019原卡名称。[逐字段资料与边界](../research/spirit-ward-history.json)。

蓄灵与维持期间暂停普攻、移动及新施法，成为需要保护的辅助位。来源受眩晕、沉默、魅惑、阵亡、残魂或阵营变化会立即撤回全部连线，能量和冷却不返还。目标死亡、成为敌军、化为火种／残魂或走出4格时只断开该条，不再补选；全部失效则收束。友方隐蔽不阻挡防护，灵鱼的负面驱散保留这项增益。多个来源不叠加，只采用最强的有效连接；弱连接还在维持时可在强连接结束后接替。

护甲与法术减伤共用战斗、详情和飞行切换的真实计算，不覆盖装备、护甲增益、海神或减甲。法强不放大双防或时长，AI不再计算旧治疗收益，改用短时双防、开场能量和实际队友的折扣估值。重叠长生鹿的队伍保护估值取最高，不直接相加。

战报新增保护人次、断线、中断和“防护减伤”，主界面贡献卡也显示这个值。减伤比较同一包伤害在有无庇护时对现有生命与护盾的消耗，排除闪避、免疫和过量部分；真伤不减免，只归功给本次最强来源。它独立于生命伤害、治疗和护盾吸收，不将预计收益记成实际贡献。

菜单“战斗演示 → 灵鹿庇护”提供同一三对三、非等预算的混合伤害局面。4秒开始蓄灵，4.5秒连线成形；6.75秒已有227防护减伤，其中102物理、125法术。全局累计666，其中541物理、125法术，治疗与补盾均为零。此时受保护盾兵在庇护、盾阵与敌方步兵减甲共同作用下显示38护甲和70%法术减伤，鹿自身仍是原防御。沿用既有ImageGen鹿形象，新增鹿角蓄灵、双线流光与受护轮廓；减少动态效果时保留静态连接。

`spirit-ward`为第44个战斗版本，规则`singleplayer-0.71`、schema70。43版旧鹿身板、补盾治疗技能和两个修改前小回放SHA保持。新局四费；旧局保留两费目录和池总份数，旧战斗在下个准备阶段才升级能力，缺目录的0.70存档补为`bulwark`。已有0.70盾兵改动继续保留。
