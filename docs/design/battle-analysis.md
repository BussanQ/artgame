# 双方战斗分析

0.48保留贡献行的aurora/qi战斗标记，修复空蟹完整分析回退旧图，并支持新版罗汉。新增“中断”和“目标丢失”计数，仅来自已播放帧的明确效果；中断可能包含施法、普攻蓄力或连击，不是推断的全部失败技能。见[气波掌](qi.md)。
战场的简报保留快速查看用途；新增“战斗分析”列出双方全部参战棋子，支持按生命伤害、生命承伤、有效治疗和护盾吸收排序。重复同名棋子分开统计，双方条形使用同一最大值，避免两边比例产生误导。

## 入口与交互

- 战场右下方“战斗分析”：暂停当前播放，统计上限限制在已播放帧，不提前显示未发生的伤害、死亡或最终胜负；关闭后手动继续。
- “本局战报”每轮的“战斗分析”：通过既有 Worker 按该回合保存的战斗版本重算，直接查看最终结果，无需先看完整回放；支持从头播放。
- 时间滑块可检查截至任意可见帧的累计贡献。它只改变分析时间，不移动战场播放位置。
- 0.8 起，演示和历史回放可点击“查看此刻战场”定位所选时间并保持暂停，再手动继续；实时对局仍只允许查看已播放片段的统计。召唤物出生后独立列入双方贡献。
- 桌面左右比较，窄屏纵向显示双方；键盘可选择指标、使用滑块和关闭弹窗。历史分析只在准备或终局开放，与历史回放共用取消、失败重试及存档冲突保护。

## 统计口径

`src/engine/battle-analysis.ts` 是只读聚合器。普攻/技能伤害与生命承伤来自 CombatEvent.amount，排除护盾及过量伤害；破盾与护盾吸收来自 absorbed，分别归属攻击者和承受者。治疗使用选定帧的实际 healing，含技能、吸血及支援阵亡治疗，不含溢出或直接恢复生命的自然再生。施法次数按 cast 事件计数，范围技能不因命中多个目标重复计次。

分析不改变结算规则、不新增存档字段、不保存战斗帧；终局排名与胜负仍由原规则决定。实时打开会保存暂停状态，刷新后仍可恢复本轮。分析页面本身不持久化。
