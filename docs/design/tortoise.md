# 0.72 玄龟双形态

新局玄龟改为五费灵能／护卫，1500生命、40攻击、10护甲、1格近战、1.6秒攻击间隔。满能量蓄势0.5秒，在完成时按双方当前存活棋子数决定龟缩或破壳，随后维持该形态。60秒冷却从起手计算；本地战斗上限40秒，因此每场最多一次成形，蓄势被打断也不返还冷却。

S04原始玩家表第43行实际印有五费灵能者／护卫、1500生命、34–45攻击、10甲、1格、1.6秒、60秒技能冷却和备注技能防御20%。攻击均值39.5取整40，技能防御映射为当前20%基础法术减伤。相邻的雷震子才标为被动，不能把那一格读成玄龟的字段。S69发行方提供的2019年7月介绍确认两种形态、比较双方棋子数、龟缩群体嘲讽与破壳群体攻击。S05七月原作者评测记录变形后不实时变化，并解释提前回能的价值。未取得同版本完整客户端技能卡；“玄武双相”为项目命名，不冒称恢复了原技能名。[逐字段证据与适配边界](../research/tortoise-history.json)。

人数在蓄势完成时计数，按当前阵营，包含已有召唤物，排除阵亡、残魂和涅槃火种。我方严格更多时破壳，否则龟缩，平局取防御是本地选择。初始能量0、0.5秒起手、具体计数与判定时点、变形交互及下列数列均属适配，并非已查到的原卡数值。

| 形态 | 一／二／三星效果 | 行为 |
| --- | --- | --- |
| 龟缩 | 护甲+20／35／50，法术减伤+20／30／40个百分点，总上限75% | 停止移动与普攻，持续引导敌方后续普攻指向自己 |
| 破壳 | 护甲降低10，普攻200／250／300%当前攻击 | 同一普攻打击主目标及其曼哈顿1格内的可见敌人 |

龟缩持续接纳新入场的敌人，不将每次刷新都算成一次嘲讽。武僧和盾兵的短嘲讽暂时优先，失效后守御重新接管；多枚守御按星级、距离、编号选择。眩晕或沉默不会关闭已形成的防御与引火，阵亡、残魂、失去可攻击性或阵营变化会重新校验来源，魅惑后对当前敌方生效。狂舞免控、残魂和火种不受引火。

持续嘲讽只改后续普通攻击与追击，允许敌人照常施法，已开始的技能和攻击不撤销。此处是针对现有引擎的明确交互适配，避免把永久引火变成全场永久禁止新技能。蓄势受眩晕、沉默、魅惑、阵亡或残魂打断；打断帧不偷出普通攻击，控制解除后仍须等待冷却。

破壳每次群攻属于一个普通攻击动作，目标分别读取护甲、闪避、护盾、吸血和反伤，不受法强放大；反伤击杀来源会停止剩余接触。范围不包括友军、远处或不能被普通攻击选中的目标。多目标命中不会重复发放攻击回能，成形后也不再积能。装备和其他防御增益保留，不直接修改永久身板。与长生鹿双防重叠时，鹿只领取自己的边际防护贡献，不能把龟缩的法术防御重复计入。

新战斗版本`tortoise`为第45个；schema71迁移0.71存档。为保持每局固定的系列禁用与卡池，旧目录的玄龟整体保留四费野兽／护卫、62攻击、9甲、1秒与渐减玄甲，新购买和已有棋子都固定`definitionVersion: spirit-ward`。其他单位照常升级规则。战斗／结算／终局中的旧版本与旧报告不改，进入下一准备阶段才固定旧玄龟。保存校验只允许这一个替换版本，不能给任意单位注入旧定义。图鉴、详情、真实羁绊、AI身板与开场连携都读取这项定义。

新增内置ImageGen原生透明PNG，两种形态各自使用独立贴图，并加入低伏守御、蓄势压身、破壳重击与落点冲击圈。旧图保留，初始形态及旧回放继续使用旧图；这不是取得原客户端模型。[完整提示词、模式和透明校验](../research/tortoise-assets.json)。

菜单“战斗演示 → 玄龟守御／玄龟破壳”是两个小局面，分别展示人数劣势与优势，不是等预算平衡结论。守御在1.5秒显示我2／敌3、引火3人次、42甲与50%法术减伤，其中护甲为10+35−敌方步兵3；普攻为0。破壳在2.25秒显示我3／敌2、0甲、20%法术减伤，群攻1轮、额外命中1人，358生命伤害都属于普攻。回到0.25秒仍是10甲、20%基础防御、变形0次与蓄势中，不提前显示未来形态。分析中的承盾来自护卫连携，不是变形生成护盾。
