目标：完整实现单机模式，逼近原版的可玩性和丰富度，优化整体游戏功能。

## 实施顺序

1. 独立技能与战斗状态：完成真实结算、表现、说明和定向验证。
2. 版本化存档与对局记录：为后续长局体验提供恢复基础。
3. 野怪回合和装备奖励：丰富单局节奏与构筑选择。
4. 羁绊梯度、棋子阵容、AI 经济与布阵：增加战略深度。
5. 对手侦察、战报、图鉴、设置、移动端交互与性能完善。
6. 全目标逐项审计：只在上述交付均有证据时标记完成。

原作公开资料存在版本冲突，不把自主平衡或推断标成官方数值。开发方向是提高单机可玩性及丰富度；不以增加线上多人替代本目标。
