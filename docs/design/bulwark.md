# 0.70 盾兵护甲盾阵

盾兵改为两费前排：750生命、57攻击、5甲、1格、1秒。满能量且15秒个人冷却结束时，获得8／16／24额外护甲，持续4／5／6秒，同时嘲讽横纵相邻的可见敌人1.5秒。举盾后仍可移动和普攻，护甲不会被沉默或眩晕撤回；没有重复补盾、即时盾击或眩晕。

此前蜂群二对二中，两枚原型盾兵40秒内开盾19次，结束时仍未分胜负。同一站位和装备在新规则下19秒结束，两枚盾兵各举盾一次。这是针对重复补盾的局部修正证据，不代表所有阵容的平衡或时长已经完成验收。

S04七月玩家原表第4行提供二费、750生命、30–84攻击、5甲、1秒和15秒冷却；攻击区间在这里取均值57。S05七月原作者评测支持重做后的护甲与1格嘲讽。项目“盾兵”与这些历史名称仍是本地对应，尚无同一构建的完整原卡；护甲数列、时长、嘲讽秒数、几何与交互均是公开的单机适配。“刺盾之阵”技能名仅由S67的2020公告交叉确认，该公告新增的技能防御和受击增伤没有混入。[逐字段出处与适配边界](../research/bulwark-history.json)。

嘲讽只在举盾时施加一次，后续普攻和移动转向盾兵，不能开始新技能；已经释放的飞弹或维持技能继续结算。来源阵亡、成为友军、失去可选中状态、盾阵或嘲讽到期时释放目标，灵鱼也能驱散。免控狂舞、残魂和涅槃火种不受影响。独立护甲状态与装备、连携、减甲共用真实伤害计算；法强不增加护甲或控制，AI按短时保护与先手估值，不再将原型盾击计作输出。

画面沿用现有ImageGen白金重盾兵，增加举盾姿态、蓝色盾徽与护甲环、指向来源的嘲讽线。详情展示实际护甲、持续时间、冷却、举盾和嘲讽人次；战报使用历史帧统计。菜单“战斗演示 → 盾阵护卫”的同一个二对二在2.25秒首次举盾，3.25秒可看到火焰兵的后续普攻转向盾兵，而已承诺的喷火仍伤害原射手。
