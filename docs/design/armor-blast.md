# 0.29 装甲再生与六爆破

0.46按S03与S51更新前对照将当前六爆破改为50点，旧armored至lineages仍保留本页60点方案。见[空援协同](coalitions.md)，本页数值和采样为0.29历史记录。

规则 `singleplayer-0.29`，战斗版本 `armored`，存档 schema28。54种棋子不变，本轮补齐装甲的持续作战和爆破的后期成型目标。

## 史料与适配

- [S18 第二期评测](https://www.taptap.cn/moment/15217028512090333)记述装甲从护甲转为生命恢复，门槛2/4，总值15/50；作者明确各档数值已经取和。因此四装甲采用50，不再次加上15。S39五月十六日公告转载的搜索正文支持门槛3/5改2/4，但直接访问失败，不作为完整公告核对。
- [S14 第五期评测](https://www.taptap.cn/moment/15201495997744121)记述六月爆破3/6的总量由15/40改为20/60。[S05 第六期](https://www.taptap.cn/moment/15216144952591652)交叉支持S1后期20/60，并另述S2强化；本轮未采用S2加强。
- S03更早图表继续保留原始装甲3/5护甲4/8及爆破20/30单元格，不用后期数值覆盖历史转录。

这不是同一客户端版本的完整复原。每秒恢复、0.25秒步进、负法抗公式、最低减伤−25%、召唤与驱散交互均为网页适配。当前六种装甲为铁狗、铁猿、投石车、巨神炮、铁巨神、暗影刀，可选四种成型；包含原型成员，不能视为历史装甲名单。历史铁鸡仍未补入。

## 当前规则

| 羁绊 | 低档 | 高档 | 作用范围 |
|---|---|---|---|
| 装甲 | 2种：每秒15生命 | 4种：每秒50生命 | 开场上阵装甲棋子 |
| 爆破 | 3种：减抗20个百分点 | 6种：减抗60个百分点 | 全体敌人，含后续召唤物 |

按不同上阵种类计数，重复、升星和备战不增加种类；最高档替代低档，不重复叠加。开场锁定整场效果，提供者阵亡不撤销。装甲移除原型护甲加成，不改变兵种基础护甲和装备；每步恢复3.75/12.5，保留小数，不将15每秒四舍五入成16。只有实际恢复计入自身治疗，满血不累积，阵亡不复活；不传给召唤物，残魂与涅槃火种沿用不可再生规则。

爆破先与目标基础20%减伤、装备和召唤防御相抵，再应用最低−25%的网页限制。因此裸目标被六爆破降至−25%，100法伤结算125；三召唤的25个百分点防御使目标从45%减伤降至−15%，结算115。不是所有目标都额外承受60%伤害。物理伤害与真实伤害不受减抗影响。

AI候选搜索能识别四装甲和六爆破。对装甲成员额外估计最多6秒受伤恢复，信用不超过单体强度20%；不把自疗扩散到全队，不估计无限存活。爆破仍用通用羁绊档位评分，挑战候选模拟才处理实际施法与目标。

八对八装甲爆破演示包含四装甲与高档爆破，对面配置召唤与治疗；再生光环和速率标签在战场显示，实际自疗进入贡献统计。减少动态效果模式下光环不闪动。

## 兼容与验证

旧 `infantry` 保留原装甲2/3护甲3/6、爆破3种减抗10个百分点。0.28准备阶段升级为新规则；battle/result/finished维持原战斗与结算，下一次准备再切换。经济、卡池、棋子、AI风格、历史和播放位置不重置。

新增11组修改前冻结的完整回放SHA，覆盖全部54种棋子；另保留更早20组冻结样本。模块验证覆盖阈值、重复与备战、小数恢复与死亡、装备/召唤防御、后续幼狼与傀儡、快速结算/Worker、四阶段迁移及旧回放。截图统一保存在根目录 `tmp/`。

本轮192项相关模块检查通过：新装甲/爆破33、步兵编队38、铁猿22、铁狗20、AI风格23、策略9、备战7、计算14、存档9、分析11、视觉6；不是全量测试。`npm run build`（TypeScript与Vite）和 `git diff --check` 通过。`npm run test:armor-blast` 可复跑核心相关模块。
