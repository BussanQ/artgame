# 0.34 刀奴：零时突进

0.42新增的刺杀职业暴击不改变刀奴的傀儡/先锋分类和独立10%被动，也不将六刺暴击发给全队。下文是0.34历史接入记录；其特定回放使用明确的旧版本验证，当前职业规则见[刺杀](assassins.md)。

新增三费傀儡/先锋刀奴，以概率暴击补充傀儡物理输出路线。当前58种棋子，23近战/35远程、22类羁绊；四月名单对应48/53，仍缺盾奴、棍奴、灵鹫、巨齿象、猛毒兽五项，分类差异仍有八项，完整单机目标继续推进。

## 战斗机制

每次合法普通攻击作一次10%判定，暴击是3/4.5/6倍总普攻伤害，仍按普通攻击处理护甲、闪避、护盾、破甲、吸血与反伤。攻击装备及攻击强化进入倍率，技能强度和法术减伤不影响物理暴击。真伤普攻若存在，仍可暴击并按真伤处理；技能免伤不阻挡普通攻击，不朽残魂免伤仍有效。伤害统计只计实际扣血，破盾另列。

不积累、消耗或接受辅助能量；没有主动技能，沉默和封能不阻止被动。眩晕、阵亡、目标隐蔽/阵亡/同阵营或超出射程时没有合法攻击，不进行暴击判定。魅惑期间仍可暴击原队友。已出手但被闪避或免伤的攻击消耗本次判定，不补发、不叠刀；这些边界属于本地适配。

`src/engine/bladethrall.ts`从双方开场阵容派生战斗种子，再按棋子UID与攻击次数生成独立序列，不消耗商店或战役随机数。不同对阵会改变序列，同一阵容的完整模拟、快速计算、Worker和回放一致。每场重建攻击与暴击计数，不保存到持久棋子，也不把10%描述成“每十次保底”。第一版仅用UID的诊断采样发现跨回合重复序列，因此在交付前改为双方阵容种子；[早期诊断](../analysis/bladethrall-v034-uid-stream.json)保留作过程证据，其源码哈希不是最终实现。

## 美术、界面与接入

ImageGen生成深靛陶甲、白色双角、单刀及刀鞘的傀儡形象，与剑奴双刀和斧奴斧刃区分。文件为 `public/assets/units/bladethrall.png`，具有真实透明通道；完整提示词、尺寸及哈希见[资产记录](../research/bladethrall-assets.json)。使用内置image_gen生成，属于重新设计的形象。

普攻为压身拔刀瞬斩，暴击增加突进幅度和刀光，使用较高优先级的刀刃音效。战场显示10%概率与已触发次数，不绘制会暗示保底的充能进度。战报单列“暴击命中”，闪避或免伤不计为命中；暴击伤害归入普攻，施法次数保持0。

新增「傀儡战刃」六对六演示。刀奴携带堡垒甲、不屈之心、超频引擎，17次攻击中在5.75秒和14.5秒发生两次暴击，造成2192生命伤害、810破盾，整场26.25秒，己方失败。装备明确写在演示阵容中，暴击来自同一真实模拟，没有额外触发脚本或提高概率；演示不影响当前比赛资源。

招募、普通三合一、出售、装备、AI均已接入；傀儡禁用时退出卡池。AI按概率期望计入20%/35%/50%额外攻击收益，攻击/攻速/吸血装备评分同样计入暴击收益；能量和技能强度装备不为该被动加分，童子辅助估值也排除刀奴。

schema33接续schema32：只补缺失刀奴卡池，允许招募时25份，傀儡禁用时0份；保留既有资源、商店、阵容、装备、禁用结果、AI风格与历史回放。旧战斗仍用 `armored`，14组0.33回放逐帧哈希不变。
