# 树妖丛林之怒（0.54）

后续发现：0.54的连携表和异虫进化版本枚举漏接jungle，影响该轮经营与战斗；已由[0.55继承修复](continuity.md)处理。下文保留当时能力、原图、测试与采样证据，不再将0.54经营变化仅解释为树妖或AI估值。旧jungle战斗按原结果冻结。
树妖由高攻击、两格震荡并加自身护盾的原型，推进为五费大范围两段控制位。当前采用950生命、45攻击、5甲、1格、1.7秒普攻及每秒5点自然回复；圆形半径4格、伤害100/200/300、击飞后再眩晕1/1.5/2秒，冷却30秒。独立压身蓄力、树根范围波、落地束缚、图鉴、片段统计和菜单“丛林震荡”演示已接入。用户要求的装备工坊在左侧、阵容连携在底部右侧继续保持。

## 依据与取舍

[S55发行方署名文章及内嵌客户端卡](https://news.17173.com/z/zzq/content/12182019/120501054.shtml)确认五费、名称、圆形4格、100/200/300技能伤害、30秒冷却和落地眩晕1/1.5/2秒。归档原图已实际目视，未从不清晰画面猜数值。[S04七月玩家测量](https://www.taptap.cn/moment/15213091339897518)第38行提供身板及每秒回血5，40–49攻击取整均值45。

七月测量与十二月文章不视为同一客户端。初始能量50、1秒可打断前摇、1秒击飞、冷却起点、法术分类、技能强度、星级生命/攻击翻倍、欧氏格距和免控/驱散交互均明确为单机适配；原卡没有给出全部这些字段。字段、SHA、真实WEBP归档及读取边界见[研究记录](../research/jungle-history.json)。

## 结算与表现

- 满能量、冷却完成且圆内有可见敌人时，在原地开始1秒蓄力。圆心锁定施法时棋格；释放时按当前敌方位置判定，敌人可走出范围，新进入者及隐蔽目标也会被范围波及。普攻与移动仍使用各自原有寻敌规则。
- 前摇禁止移动/普攻，眩晕、沉默、魅惑或肉身死亡中断未释放的技能，能量与冷却不返还。死亡中断沿用现有伤害结算；本次额外清理的是待发生的落地控制，避免复活/驱散后补控制。
- 释放后先结算每名目标的护盾/生命伤害，再给合格存活目标1秒击飞；实际落地时追加星级眩晕。已释放的波不因反伤杀死施法者而漏掉其余目标；待落地控制保留原来源统计，来源死亡或换阵营不会撤销已承诺的控制。
- 技能免伤、残魂、火种不受控制。死亡、进入残魂或化蛋清除待落地记录；灵鱼驱散同时清除击飞及待落地眩晕。多次击飞按实际落地时刻处理，眩晕取最晚结束时间，不累计时长。战斗终止后不再补发剩余动作。
- 树妖自身不再获得原型20%护盾。自然回复只恢复存活肉身的缺失生命，计入实际治疗；不会给残魂续命。图鉴与棋子详情显示基础法术减伤和自然回复，未把装备/连携加成冒充基础值。
- 预告与命中复用同一4格圆形几何，并裁在棋盘内。独立压身姿势、根刺波和落地根环分开；减少动态模式保留静态范围提示。攻击/击飞插值仅改变画面，不推进结算。
- 战斗详情与分析分列释放波数、范围接触、击飞和落地眩晕。范围接触包含碰到免伤目标，不能当成实际伤害或成功控制；零时刻和片段查询不泄漏未来计数。

新轮廓通过内置ImageGen参考客户端树石巨兽与既有绘画风格生成，透明输出原样复制到`public/assets/units/treant-jungle.png`，保留旧`treant.png`。完整提示词、输入角色、原始输出、尺寸、透明通道和SHA见[资产记录](../research/jungle-assets.json)。原游戏卡仅作研究参考。

AI/推荐选阵去掉原型护盾估值，按有限首波伤害、覆盖与控制估价，不假定第二次30秒施法；没有隐藏加成。正常经营的新树妖覆盖不足仍是待诊断项，没有为获得好看的样本而强制上阵或调回原型身板。

## 经营与界面边界

标准付费玩家代理，灵能偏好/种子173与野兽偏好/种子311，各覆盖完整/随机禁用池和三档对手，修改前12局313轮，修改后12局318轮。标准平均名次5→3.75，挑战6.5→6.25，休闲仍1；自然三星从2局变为0局。旧版玩家树妖在3局16轮出场，新版12局没有玩家部署树妖；只在一局遇到的对手记录到2轮、2波、11次接触/击飞/落地。全部AI阵容准备快照从48降至5个树妖单位轮次，不能和玩家对战的2轮混算。

费用未变，身板、技能、估值与随机经营路径同时影响样本；两个种子不能证明整体平衡，也不能把名次变化归因于树妖。旧报告没有新控制计数，比较保留null，不伪填0。初版和最终两份0.54报告的完整经营轨迹一致，是同种子的复验，不能当成额外独立样本。[配对原始数据与限制](../analysis/jungle-v054-comparison.json)保留三星期望落差和树妖覆盖退步。

独立5176预览已保存蓄力1秒、击飞1.75秒、落地2.25秒、零时刻分析及完整演示证据；完整演示40秒平局，两枚树妖分别完成1波、6/4次击飞及6/4次落地。它是不同预算的6对6表现夹具，不是正常经济比赛或强度比较。390px分析和390/320px战场无横向溢出，截图在根目录`tmp/jungle-v054-*.jpg`；[界面记录](../analysis/jungle-v054-ui.json)说明哪些来自已保存截图和此前直接观察。

后续浏览器连接连续超时，新局图鉴、退出演示后的旧终局复核及新增图鉴行的最终窄屏画面尚未补验；没有使用旧截图冒充这几项完成。现有用户5174服务继续提供当前源码，未因观察超时重启或清空对局。

完整单机目标继续进行。下一项优先诊断高费控制位的选阵：在相同可用阵容、装备与预算下，对比评分选择和真实对战结果，区分范围控制收益未被估价、身板偏弱与队形不合适，再决定实现调整。总体难度/多构筑长局、其余历史能力与不确定公式、真实触屏及弱设备仍缺最终证据。
