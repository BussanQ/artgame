# 0.30 铁鸡：远程刺杀与范围协同

规则 `singleplayer-0.30`，schema29，沿用 `armored` 战斗版本。55种可招募棋子，20近战/35远程、22类羁绊；四月53名基线对应45项、仍缺8项，现有分类差异8项。名称对应不代表全套历史机制已经复原。

## 来源与适配

[S04属性表](https://www.taptap.cn/moment/15213091339897518)第一张表第12行给出四费、装甲/刺杀、750生命、90–110攻击、1.2秒间隔、5护甲、射程3及13秒冷却。[S18](https://www.taptap.cn/moment/15217028512090333)支持装甲刺客阵容定位；[S40六刺客介绍](https://www.9game.cn/news/3107101.html)支持提高友军攻击和防御的辅助定位。S40页面时间为2019-05-09，作者标互联网、来源琵琶网游戏；标题虽然写更新简报，正文主要介绍六刺客，不当作官方完整更新公告。

基础攻击取均值100，1.2秒适配到0.25秒战斗步为1.25秒，生命和攻击沿用每星翻倍。史料没有给出完整技能参数：技能名“战术协同”、初始50能量、15/25/35%攻击、3/5/7护甲、3格范围、6秒持续与叠加边界均为单机适配。机器可读区分见[历史记录](../research/ironrooster-history.json)。没有混用经典RTS防空铁鸡的数据。

## 结算与表现

满100能量、冷却结束且3格内有可见敌人时瞬发，以自身为中心给曼哈顿3格内存活友军增攻加甲，包括自身和当时已在范围内的召唤物。没有直接伤害或治疗，不受技能强度加成。眩晕、沉默、魅惑、阵亡、无合法敌人时不施放、不扣能量。13秒冷却从施放时计，期间仍能普攻和回能。

协同按施法来源记录到期时间；同类攻击强化与临时护甲分别取最高值，不相乘或相加。较弱铁鸡后施放不会延长较强铁鸡的增益；强效果到期后可退回尚未到期的弱效果。与维修机攻击强化、长生鹿等临时护甲分别取高；不改变维修机自身旧有刷新规则。永久护甲、装备、装甲再生和玄龟衰减甲仍按各自规则结算。

这是一轮脉冲，后来进入范围或新召唤者不获得增益，离开范围或施法者阵亡不撤销。受益者转为敌方时暂停，回到原阵营且未到期时恢复。残魂、火种和正在被魅惑者不接收新协同；化为残魂或火种会清除已有协同。

双足稳架、两次错开的后坐和侧倾、双炮交替曳光及命中火花形成独立普攻动作；两条曳光仍对应一次实际普攻，不额外造成两次伤害。协同有金色范围脉冲、连接受益者的短线与六边形标志、增益及冷却标签，配合提示音。减少动态效果设置保留信息提示。

沿用“装甲爆破”八对八演示，加入铁鸡和幽灵机，形成四装甲、六爆破、二刺杀、二空军。铁鸡开场跳至后排，2.75秒强化自身和幽灵机；二星对同一神枪手的实际普攻从214提高至268，符合25%增攻。演示18秒己方胜利，铁鸡施法1次、普攻2008、技能伤害0；装甲再生675单独计入有效治疗。

## AI、经济与存档

共享卡池增加15份四费铁鸡，正常购买、三合一和出售回池。AI不给辅助技能虚构直接伤害信用；阵容评分只取最高星铁鸡，为最多三名可能受益者估计协同收益，每名上限18%，不按重复铁鸡叠加。回能装备有价值，技能强度不增加协同收益。

schema28/0.29→29只补缺失卡池，四阶段的金币、生命、商店、棋子、装备、AI偏好、历史与播放位置不变，战斗版本不变。中间迁移固定写入各自规则版本。11组覆盖原54种棋子的0.29完整回放哈希未改变。
