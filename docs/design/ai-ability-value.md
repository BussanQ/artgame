# AI 技能与装备估值

规则仍为 singleplayer-0.18 / schema 17。本轮改善准备决策与推荐布阵，并修复新种子采样发现的声波致死化蛋崩溃；不调整技能数值、基础资源、卡池或存档格式。

## 问题证据

原 pieceStrength 以生命、攻击、攻击间隔和护甲为主，仅对不死鸟重生、真人和须弥鲨召唤作额外估算。46 种棋子 × 三个星级的138组审计中，132组的单体评分在装备聚能法杖前后完全相同。两枚同名同星的幻鲸或方舟竞争一个人口时，即使后者有法杖，也会因为UID较大留在备战席。

[修改前估值](../analysis/ai-valuation-before.json)记录单位、星级、空装/法杖/合金刃评分及源码哈希；它描述当时旧代码，不要求与当前源码匹配。

## 当前估算边界

- 常规技能按攻击倍率、有限命中数量估算首轮收益；范围技能按1.8个目标估算，控制按秒数和有限覆盖计入。
- 技能强度和初始能量提高相应估值，初始能量在100封顶；轰炸机按当前规则的50初始能量计算。
- 轰炸机、电蛟、不死鸟仅按两次脉冲、有限目标估算；方舟与罗汉计入蓄力落空风险。
- 幻鲸只按三次脉冲、两个生命量级相近目标估算，不假定十次命中全队；三星百分比收益不同于单纯倍增攻击。
- 玄龟的固定护甲忽略法杖；血鹰回血/落地、蛤蟆吞噬和蜘蛛魅惑不把技能强度当成伤害倍率，但可考虑更早满能量。
- 落箭虎的箭雨替代一次普攻，因此扣除被替代的那次普攻估值；其初始能量不产生虚假收益。
- 鬼狼、真人、须弥鲨统一计入部分第一次召唤的战力，使用真实召唤物基础数据、星级和技能强度；不假设无限召唤或占位必然成功。
- 队友治疗和童子供能沿用 lineupScore 的独立估算，不在新 abilityCredit 中再次叠加。辅助装备仍通过团队评分反映；童子的供能量本身不受技能强度加成。
- 新技能系数最高0.6，增加到原单体估值上；星级、永久属性、完整羁绊和队伍构成仍参与选择。

这些是可检查的决策启发式，不是对战胜率，也不是额外战斗增益。挑战仍用真实轻量战斗试算比较候选阵容和站位，标准/休闲仍遵循各自原有策略。没有调低挑战AI金币或伤害，没有赠送玩家资源。

## 采样解释

首轮137/307用于回归观察，并非最终交付参数。第二轮809/1619在补齐鬼狼估值之前完成，不能当作最终版本证据。两份报告保留各自源码哈希供追溯；没有把中间报告重命名成最终验证。

最终种子2027/4093的首次运行暴露声波化蛋崩溃，修复后使用相同种子完整重跑；没有因失败更换种子。采样使用正常付费购买、卖出、刷新、升级和奖励流程，7种偏好 × 3档难度 × 2种子。最终结果和源码一致性见下文追加记录。跨种子的名次差异不能直接归因于本次调整，也不能把高费上场率的少量变化当作总体平衡结论。

真实弱设备、历史分类映射与最终人工完整体验审计仍未完成，整体目标保持进行中。


## 采样发现的整场战斗崩溃

首次2027/4093采样在挑战档终止，错误为 advanceSonic 读取 undefined.filter；失败日志保存在 [原始失败记录](../analysis/ai-credit-sonic-egg-failure.txt)。

根因是不死鸟被声波致死后，enterPhoenixEgg 清除 sonic 负面列表；advanceSonic 仍在遍历原数组，并在结尾直接读取已删除属性。多只蝙蝠的同批剩余声波还可能错误伤害新火种。

修复时保存当前列表身份。每次伤害后检查目标是否死亡或列表已被清除/替换；若生命周期发生变化，立即停止旧列表处理，不把它过滤后重新挂回新形态。普通声波、施法者阵亡后持续伤害与其他单位流程不变。

新增回归先在旧代码上复现失败，再验证：两只蝙蝠同时施加声波，第一条造成致死化蛋；800生命火种保持完整、旧声波全部清除、后续战斗步不再受旧声波伤害，孵化恢复2000生命。完整/快速/Worker、野怪与四组长局相关回归通过。这个修复只消除原本会崩溃的路径，不重算存档中的历史胜负。
