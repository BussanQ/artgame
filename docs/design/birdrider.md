# 鸟骑兵与骑射编队（singleplayer-0.26）

新增一费骑兵/狙击 `birdrider`，通过普通攻击累积触发强力箭，提供低费骑射过渡选择。当前53种可招募棋子、19近战/34远程、22类羁绊。历史四月53名名单中已有43项同名或本地映射，仍缺10项；总数相同不等于名单或玩法完整复原。

## 史料与本地适配

[S38：5月30日更新公告转载](https://news.17173.com/z/zzq/content/05302019/085535417.shtml?_platform=PC)标注作者、来源均为官方。Web直读超时后，成功取得公开HTML并检查正文。鸟骑兵由振翅改为信仰之箭：先进行6/5/4次普通攻击，下一箭经过短蓄力，造成300%暴击伤害；攻击间隔改为1.5秒。[S04属性表](https://www.taptap.cn/moment/15213091339897518)支持一费、400生命、5护甲、4格射程和一星51–57攻击。

结构化字段见[birdrider-history.json](../research/birdrider-history.json)。本项目采用一星攻击均值54，生命/攻击沿用逐星翻倍，因此二/三星攻击108/216与S38区间均值109/218.5略有不同。使用固定伤害而非每次随机抽取攻击区间。

**0.5秒蓄力、攻击快照、计数包含落空、取消不返还计数、沉默无效、允许普攻闪避与吸血，均为明确的本地适配。** 原文未提供这些细节，不能将“必定暴击”扩展为“必定命中”。箭的飞行采用表现层弹道，实际伤害在蓄力结束时确定性结算，不额外模拟飞行延迟。

该公告还包含摩托骑兵改为焦油弹等改动，与当前三连发实现属于不同时间切片。当前全部配置仍是有出处的历史方向和单机适配的组合，不宣称完整复原5月30日客户端。

## 实际规则

| 项目 | 配置 |
|---|---|
| 招募/卡池 | 1金、45份、通常三枚同星合成 |
| 一星属性 | 400生命、54攻击、5护甲、4格、1.5秒普攻 |
| 触发 | 一/二/三星先普攻6/5/4次，再用下一次攻击机会拉弓 |
| 蓄力 | 0.5秒，不移动、不另行攻击；普攻冷却正常流逝 |
| 强力箭 | 开始拉弓时攻击力的300%，包含当时攻击增益；不受技能强度加成 |
| 能量 | 不获取、不消耗，开战能量装备也不转为额外攻击计数 |
| 防御交互 | 仍是普攻：护甲、飞行闪避、护盾、攻击破甲、吸血、免伤及反伤正常生效 |

按实际普通攻击机会累计，打在护盾或被闪避也累计；走位、等待、眩晕和魅惑期间不累计。蓄力绑定目标UID，范围内移动不改选目标。目标死亡、隐藏、变成友方或离开4格射程会取消；施放者眩晕、魅惑或阵亡也会中断，不返还累计次数。沉默和封能不会关闭普通攻击被动。

`src/engine/birdrider.ts`独立处理计数和蓄力，`CombatEvent.empowered`仅为强化普攻增加表现标记，`skill`仍为false。旧棋子不会创建鸟骑兵状态或强化标记，不改变旧事件结构。战报将强力箭计入普攻伤害，非主动施法；蓄力不产生额外伤害事件。

## 选阵、装备、表现与恢复

AI沿用远程后排站位，评分按强化攻击周期给出有上限收益，并为可被打断留折扣；不因能量或技能强度装备提高被动评分。晶体/法杖对鸟骑兵的装备评分为0，攻击、攻速与吸血仍有收益；童子的队伍能量收益估算不把鸟骑兵当受益目标。

普通攻击采用跨鞍张弓、振羽、释放与回稳的独立动作；强力箭以更粗的箭矢、环光、金色暴击数字区分。蓄力有持续拉弓姿态、弓弧与倒计时，计数条显示0至6/5/4的进度。使用弓箭音效，无蓝条充满施法表现。

新增“战斗演示 → 骑射编队”：鸟骑兵、摩托骑兵、马骑兵、蜻蜓骑兵配护卫与军医，对抗装甲阵地，六对六、普通装备规则、无需改变实际对局。默认十对十及其他主题演示保留原阵容。该场21.25秒，鸟骑兵在第27/28和58/59步蓄力，第29和60步射出强化箭；每个战斗步0.25秒。

存档schema24→25仅补缺失的45份鸟骑兵卡池和规则标记，保留四阶段的资源、商店、棋子、装备、历史、combatVersion与播放状态。前序迁移固定写入0.25后再继续升级；射击计数和蓄力由确定性回放恢复，不进入持久阵容。
