# 野怪与装备构筑

规则版本 `singleplayer-0.3`。关卡、装备名称、配方与数值均为单机自主平衡；野怪使用当前棋子形象，不宣称是原作野怪资产或历史配置。

## 对局节奏

新局第 1、2、3、10、15、20、25、30 回合为野怪：荒原斥候、幽影狼群、狮王营地、遗迹守军、狂兽围猎、铁壁防线、灵能暴潮、终焉巨神。其他轮次保持玩家防守战。每位存活玩家分别对抗同一支野怪阵容，野怪不占卡池。

左侧显示本轮敌人、形象与战术提示。野怪具有固定星级与强度系数，系数只影响野怪生命和攻击；参战快照携带此系数，保证存档恢复和历史回放一致。

野怪不改变连胜/连败，也不提供 PvP 的胜利额外 1 金；基础收入、利息、既有连胜/败收入和经验照常结算。失败按敌方存活单位扣生命。非终局野怪战后，存活玩家胜利三选一基础装备、失败二选一；AI 也获得一件并按阵容评分选择。终局没有待领取奖励。

战果特效结束后停在奖励选择，选择即进入下一回合准备。待选内容随结算原子保存，不会因刷新重新抽取；领取清除待选状态并写入战报，重复领取无效。

## 装备

基础件 6 种：合金刃、装甲片、生命核心、加速线圈、灵能晶体、汲能獠牙。成装 10 种：破军战刃、堡垒甲、不屈之心、超频引擎、聚能法杖、吞噬之牙、饮血战刃、守护壁垒、疾风利刃、贤者核心。数值与配方集中在 `data/items.ts`，界面直接使用相同配置。

- 准备阶段选择棋子后点击库存穿戴，每枚最多 3 件；卸下免费。战斗中不可变更。
- 合成从库存精确消耗 2 件材料；同种材料配方需要 2 份。成装不拆分；已穿戴材料需先卸下。没有自动合成以避免误消耗构筑材料。
- 升星优先保留场上棋子，合并三枚的装备，前 3 件保留，其余回库存。出售归还全部装备；淘汰清空库存和阵容。
- 装备增加的固定生命/攻击不随星级倍增；羁绊在战斗组装时生效。攻速缩短合计上限 55%、普攻吸血上限 60%、额外法术减伤上限 50%。
- 技能强度增加技能伤害、主动技能护盾和治疗，不增加控制时长。普攻吸血按实际生命伤害计算，不把护盾吸收量当作可吸血伤害。
- 装备初始能量与开战羁绊相加，上限 100。基础法术减伤 20%，装备提供额外减伤。
- AI 每轮重新分配装备：回收备战装备、合成可用成装，再按坦克/输出/施法定位和星级给上场单位分配，每枚同样最多 3 件。

## 工坊装备总览

工坊直接显示背包与已穿戴数量，并列出所有穿戴装备的己方棋子及其装备。棋子以名称、星级和位置区分；备战席按当前编号显示，场上按棋格坐标显示。

点击“全部装备”可查看全部 16 种装备的属性、合成配方、背包数量和持有人，也可筛选“已持有”。同一棋子穿戴多件同类装备时合并显示数量；备战席装备也计入统计。点击持有人返回工坊并选中对应棋子，手机同步切换到装备页。准备阶段可继续穿戴或卸下，战斗中保持只读。

总览直接读取当前己方库存和棋子，不缓存归属，也不包含对手装备；穿戴、卸下、升星溢出、出售、合成和调位后自动更新。对手装备仍由侦察查看。本次仅新增展示和选择入口，不变更装备规则或存档格式。

必要模块验证：`vitest run tests/equipment.test.ts tests/equipment-overview.test.ts`。覆盖全部装备空态、重复装备计数、备战席和同名棋子归属，以及穿戴、卸下、调位、合成、升星与出售后的归属变化。

界面验收：1440px、390px、320px 均无横向溢出。通过实际对局领取生命核心并穿戴至藤妖，总览显示“场上 D5”；撤回后显示“备战席 1”，点击持有人正确返回工坊并选中棋子。卸下后更新为背包 1 件、装备中 0 件。桌面与手机截图保存于根目录 `tmp/`，不纳入 Git。

## 存档兼容

格式升级为 schema 2。识别 schema 1 + singleplayer-0.2 存档，补充库存、奖励和历史战斗类型。旧存档若正在战斗/结算，则从下一回合接入野怪；不会在中途将原 PvP 对手替换成野怪。旧历史标记为 PvP，使用原参战快照重放。新字段纳入存档校验：未知装备、超出槽位、非法待领奖阶段、野怪强度混入玩家阵容均拒绝。

模块：`data/encounters.ts`、`engine/equipment.ts`、`ui/equipment.ts`。验证入口：`npm run test:equipment`；历史阶段/卡池变化验证 engine 与 persistence 模块，战斗属性验证 abilities，详情展示验证 visual。
