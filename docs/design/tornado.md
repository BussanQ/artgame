# 翔龙：龙卷风（0.63）

翔龙从目标周围的一次眩晕原型改为移动路径控制。龙卷沿起手锁定的方向前进，逐个接触敌人，先击飞，再于实际落地时眩晕。玩家可通过站位、打断蓄风、走出路径和驱散应对；翔龙释放后能恢复普通攻击，已经发出的龙卷和已施加的击飞不依赖施法者存活。

## 当前规则

| 项目 | 实现 |
|---|---|
| 施法条件 | 初始能量0；满能量、20秒冷却结束，4格内存在可见敌人 |
| 起手 | 原地蓄风0.75秒，锁定起点及目标当时的方向；冷却从起手计算 |
| 移动 | 直径1.5格的圆形头部，每秒3格，中心最多前进8格；出界部分无效 |
| 接触 | 圆形头部扫过线段的胶囊范围，包含边界；同一龙卷对同一UID只接触一次 |
| 伤害 | 一／二／三星150／200／250，按起手时法强冻结；不取普通攻击力 |
| 第一段 | 接触时击飞0.5秒；死亡、火种、残魂及狂舞免控不施加控制 |
| 第二段 | 实际落地后再眩晕1.5／2／3秒；其他更久击飞会推迟落地 |
| 驱散 | 位面观测可清除当前击飞和待落地控制；落地前处于技能免控时取消第二段 |

起手、初始能量、几何、速度、空中时间及具体结算时序属于本地适配；卡面的“技能伤害”在当前引擎中按法术处理。8格为头部中心行程，端点仍带0.75格圆形半径，避免把实际胶囊范围说成平头矩形。

龙卷用当前目标位置判断接触，可波及隐蔽和飞行敌军，不伤发射阵营的友军。目标可离开原路径，其他敌人也可进入路径；既不追踪最初目标，也不会漏过两个采样点之间的敌人。所有伤害独立经过当前魔抗、护盾、技能免伤和反伤。接触次数包括免伤接触，不能当成有效生命命中。

蓄风期间不能移动或普攻，眩晕、沉默、魅惑或阵亡取消未释放部分，不退还能量和冷却。发出后可恢复行动，龙卷保留原阵营和伤害；施法者变成该原阵营的敌人且位于路径内时，也可能被自己的旧龙卷波及。反伤击杀翔龙不会取消其余路径或已施加的落地控制。整场战斗结束即停止，不增加等待时间。

树妖与龙卷共用已有落地队列，新队列项只对龙卷追加可选来源标记；旧树妖数据形状和统计保持。两种能力同时击飞时，先等较晚的空中结束，再分别施加各自眩晕，取更晚的控制结束时刻。真实树妖施法与位面观测交互均已在模块中核对。
