# 0.46 空援协同与连携规则

当前 `singleplayer-0.46`、战斗版本 `coalitions`、存档 schema45。校正空军、猛禽、支援、召唤、攻城、陆行者、熊猫及爆破八项规则；随机禁用补入骑兵，按13个种族选3个。63种棋子与四月53名分类对应保持；同版本的属性、费用、技能和完整伤害模型仍未恢复，整体单机目标继续推进。

## 证据与选择

[S03原图](https://www.taptap.cn/moment/15202528882852517)提供早期门槛、印刷增量与受益对象；[S50原作者攻略](https://www.taptap.cn/moment/15203671482564780?group_id=42979)说明累计方式，其客户端卡确认攻城3/6和“唯一一种陆行者”；[S51五月28日评测](https://www.taptap.cn/moment/15220462338441888)区分召唤回能→技能防御、爆破20/50→15/40的前后版本。本轮选择其更新前机制，不继续混入旧原型的2/3召唤防御和更晚的六爆破60。详见[原图、指纹及解释边界](../research/coalitions-history.json)。

## 实际结算

空军闪避与猛禽对地增伤惠及其他种族的飞行棋子，按当前飞行状态判断。血鹰变身落地失去两者，凤凰化蛋暂停、孵化恢复；地面召唤物不借用主人的飞行身份。巨神炮对空必中、护盾、技能与闪避的既有规则保留。跨连携仍按现有乘法处理，例如对地普攻同时享受35%猛禽和25%攻城时，在减伤前为1.35×1.25倍，不宣称这一乘法是已恢复的官方公式。

三召唤映射到本地25点普通攻击基础回能：每次攻击首次造成正生命伤害时补40%的差额，通常为额外10；同次多目标命中不重复补。基础攻击回能仍沿用原模型，未命中也可得到基础部分；护盾全吸收、免伤或闪避不补额外部分。技能、反伤、持续伤害、受击10点、支援、童子和初始能量不放大。原版基础回能公式及技能获能细节未恢复，这些是明确的本地结算边界。

额外部分按`recoveredMana(25×1.4)−recoveredMana(25)`计算，骑兵的平减只作用于整次攻击一次：正常35，两骑压制后32，而不是拆成两次各扣3。封能、满能量、被动、变身后无能量技能与召唤物均遵守原有获能限制；事件只记录实际补入量。后续幼狼、灵木傀儡和镇海盾卫可以携带团队元数据，仍不能获得能量或施法。

支援只有该职业自身死亡才触发；全体存活友军和召唤物可以被治疗，实际回复受缺失生命、能量封锁和无能量技能限制。不能复活，每名支援只触发一次；召唤物不继承支援身份或死亡触发。每场开战锁定档位，提供者阵亡不撤销其他连携。陆行者冲突也按开场阵容锁定，不在另一种死亡后临时启用。

攻城针对装甲、空军、傀儡、海神、异虫、不朽，多重种族只乘一次。原文没有严格拆分所有伤害类别，本轮参考原作者的技能流描述，选择增幅普通攻击与直接物理/魔法/真实技能，排除反伤和持续伤害。爆破沿用法术减伤最低−25%的本地边界，装备和海神先叠加、再扣爆破；后续召唤同样受影响。

## 随机禁用与阵容界面

原图13个种族包含骑兵；此前12系列名单遗漏了这一行。新局禁骑兵同时移除鸟骑兵与摩托骑兵，商店、共享卡池、AI和图鉴统一过滤。旧局原禁用不重抽、不增删已有棋子或卡池。

新门槛下若继续要求“每个残留职业都达到第一档或归零”，旧12系列只剩67种有效组合，三召唤会排除大量合理阵容。本轮改为保障早期商店、费用梯度、近战/远程和多条构筑：至少30种、6近战/8远程；1至5费分别至少4/3/3/3/2种；有一费近战，以及至少三种可达职业，包含护卫/先锋之一和狙击/刺杀/爆破/攻城之一。未形成某条连携的棋子仍能凭自身技能使用，不从卡池再删除。

当前63种名单下13选3的286组合都满足条件；512个固定种子覆盖243个不同组合，所有种族均出现。不可达档位继续在禁用说明和图鉴标出。种族扩充与筛选变化会改变新局相同种子的禁用及后续偏好；已有存档不受重抽影响。

陆行者冲突直接显示在连携面板，带“2种 / 冲突”标识，不藏在未激活折叠列表里。同名两枚仍显示1种生效。面板提取为可复用的`src/ui/synergies.ts`，保持展开状态键。作战指南移除海神命中回能、灵能20/30和猛禽2/3等过期数值，指向对应本局规则的连携详情。

## 兼容和验证

schema44仅准备期切换coalitions；在途战斗、结算、终局及历史保留lineages或更早版本，下一准备阶段才更新。中间0.44→0.45固定lineages与0.45。`hasLineageRules`保留0.45八项职业修正，新版本不会退回旧分类；旧空军45%、猛禽2/3、召唤防御、熊猫额外加成、六爆破60继续按原版本重建。资源、装备、棋子、商店、卡池、禁用、随机数和播放不重置。

`npm run test:coalitions`只跑31个相关模块，777项通过，其中本轮115项。修改前冻结58组0.45回放，逐帧SHA保持；包含八种阶段/禁用迁移、伤害和能量边界、飞行变化、召唤继承、冲突、13系列过滤、完整/快速/Worker一致及真实九对九。旧迁移测试使用真实历史版本，旧召唤防御和猛禽用例固定lineages；保留所有既有回放期望哈希，没有重写期望值来隐藏变化。未运行全量测试，未提交Git。
