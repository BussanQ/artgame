## 能力

能量上限 100，普攻回能 25，受到一次攻击回能 10（含护盾吸收）。满能量且满足施法位置时，下一次行动施放技能并清空能量；技能代替本次普攻。禅师熊猫没有可治疗的友军时保留能量并普攻。刺杀技能找不到落点且当前敌人不在攻击范围内时保留能量并继续寻路。

## 状态与计时

- 固定 tick 0.25 秒。普通攻击间隔不变，加速使用带小数余量的冷却，避免逐次取整让快攻单位加速失效。
- 物理伤害先扣破甲、再算穿透，最终护甲最低 0；法术基础减伤 20%，装备与召唤羁绊可提高减伤；真实伤害无减伤。技能说明与代码共享 `data/skills.ts`。
- 独立护盾先吸收伤害，溢出扣生命。伤害贡献只统计实际生命损失，承盾单独统计。护盾到期清除；重复护盾取较大剩余量并刷新时间，不无限累加。
- 护卫羁绊从额外生命改为 250 点开战护盾，不增加最大生命。技能护盾会刷新该护盾的持续时间。
- 治疗不超过最大生命，不复活死亡单位；治疗贡献只统计实际恢复量。
- 眩晕禁止移动、普攻和施法；已有冷却继续流逝。1 秒控制保证后续 4 个 tick 不行动，当前 tick 受交替行动先后顺序影响。
- 破甲、加速同类型刷新而不叠加。闪现只落在棋盘内未占据的邻格；击退不能覆盖存活单位。

## 模块与表现

`engine/abilities.ts` 负责结算；`battle.ts` 负责行动与快照，持久阵容不保存临时状态。`CombatEvent` 记录实际生命伤害、护盾吸收和伤害类型；`CombatEffect` 记录施法、治疗、护盾、控制和位移。一次范围技能的主目标驱动攻击动作，其他命中仍分别显示伤害数字。

战场显示技能名称、治疗绿字、法术紫字、护盾蓝条与护罩、眩晕星标、加速/破甲状态。突袭使用瞬移与残迹，不跨棋盘滑行。贡献面板同时显示伤害、治疗与承盾。图鉴支持费用/羁绊筛选和 1–3 星属性查看，备战悬浮信息使用同一技能说明。

验证入口：`npm run test:abilities`；涉及回放协议时运行 `test:visual`，涉及战斗结果时运行必要的引擎模块测试。存档、装备与野怪已接入；完整羁绊和扩充棋子继续按单机实施清单推进。装备技能强度作用于伤害、护盾与治疗。
