# 0.27 铁猿：装甲前排与范围爆发

规则 `singleplayer-0.27`，schema26，继续使用 `infantry` 战斗版本。新增可招募铁猿，54种棋子、20近战/34远程。四月53名基线已有44项同名或本地映射，仍缺9项；数量与名称对应不是全套机制复原。

- [S05 2019-07-15评测](https://www.taptap.cn/moment/15216144952591652)：高护甲和范围输出，与装甲爆破阵容相关。

这些是不同日期的玩家资料，不能拼成官方完整技能表。未找回可靠的技能名、分星伤害、精确范围和施法边界。技能名“重装震爆”、250/500/1000法伤、初始25能量、0.75秒蓄力、曼哈顿2格范围和打断处理均为单机适配；未混用经典RTS铁猿的技能。机器可读区分见 [ironape-history.json](../research/ironape-history.json)。

基础攻击取66–72均值69，生命和攻击每星翻倍；护甲6/8/10。1.7秒攻击间隔适配到0.25秒战斗步为1.75秒。史料的10秒技能冷却保留，从施法开始计时。

## 实际行为

满100能量、冷却结束且有相邻可见敌人时原地蓄力；0.75秒后，对施法者当前位置周围曼哈顿2格全部存活敌人各造成一次法伤。技能强度在施法时快照，不使用随后变化的攻击力。没有眩晕或其他控制，不打断普通受害者的施法。

命中时重查距离、阵营和生命；原目标离开或死亡不会取消，新进入者、隐蔽者和空中单位也能被范围命中。友军、范围外与阵亡单位不命中。范围无人也会结束施法，不等待目标回来。

蓄力期间不能移动或普攻，攻击冷却正常流逝。眩晕、沉默、魅惑或阵亡中断蓄力，不退能量和技能冷却。法抗、护盾、不朽免伤、反伤正常逐目标结算；致死反伤会停止后续目标伤害。冷却期间可以正常移动、普攻和回能。

## 集成与表现

共享卡池增加30份二费铁猿，正常招募、三合一升星、出售回池。战斗、图鉴、备战详情与AI共用永久护甲公式；装备评分把铁猿视作前排，技能估值保守考虑范围目标与被打断的可能性。

schema25/0.26→26仅补缺失卡池，保持各阶段金币、生命、阵容、商店、装备、战报和播放位置。旧鸟骑兵迁移固定写入0.26，再顺序迁移。新增能力不修改旧棋子的结算路径，20个旧回放哈希继续一致。

独立动作“双拳举臂震地”具有抬身、双拳下压和回弹轨迹。施法时单独维持蓄力姿态，不提前出现落拳；范围格预警、蓄力倒计时、双拳冲击和碎片、回充提示与爆破音效跟随实际战斗状态。

新增六对六“装甲爆破”演示，左侧铁猿/铁狗/投石车/摩托骑兵/军医/童子，形成3装甲、3爆破、2支援。沿用正常属性和装备规则，旧主题阵容不变。

## 正常经济采样与发现

[种子173，21局](../analysis/balance-ironape-v027-after.json)和[种子47/311，42局](../analysis/balance-ironape-v027-validation.json)均使用现有七种指挥偏好、三档难度、正常付费操作与奖励，逐回合验证资源、占位和卡池。三个种子合计63局，休闲/标准/挑战平均名次分别1.00/3.81/6.43，前四分别21/21、13/21、2/21；样本不支持难度平衡已经完成。

铁猿在默认七种偏好中只在1局、2个回合以一星上阵。检查AI_PROFILES发现没有装甲或爆破偏好；不能只凭这批结果判断铁猿技能弱或招募不可达。

追加[装甲构筑诊断9局](../analysis/balance-ironape-v027-armor-diagnostic.json)：同三个种子与三难度，只把玩家代理偏好设为装甲/爆破/攻城，不改变七名对手、经济、装备、卡池或兵种数值。铁猿在7/9局、52回合上阵，其中5局升至二星，44枚二星出场（可跨回合重复），17次为20回合以后；15个包含铁猿的回合同时激活3装甲与爆破。证明正常经济下可购买、合成并进入后期构筑，未出现三星。

这组诊断标准平均名次6.00、挑战6.67，尚不能证明装甲流有足够竞争力，也不能将失败单独归因于铁猿。下一步需处理AI构筑覆盖和装甲/爆破完整梯度，再校准强度；本轮不为了样本而临时提高伤害。诊断偏好仅在审计脚本生效，**没有加入正式七名AI对手**。
