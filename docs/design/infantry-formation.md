# 0.23 步兵编队与历史规则对齐

2026-11-04，规则 `singleplayer-0.23`，战斗版本 `infantry`，存档 schema 22。棋子仍为50种，本轮改变阵容功能而非增加名单数量。

## 历史依据与适配边界

采用已逐图录入的 [S03 2019-05-09 羁绊表](../research/historical-tables.md)：2/4/6种步兵，敌方护甲降低3/6/9。原始字段和图片出处见 [historical-tables.json](../research/historical-tables.json) 的 S03/步兵。这次移除旧原型2/3/6档增加200/300/600生命的效果，步兵改为帮助全队物理输出对付护甲。

资料没有证明各档累加方式、负甲公式及召唤/驱散交互。本项目明确选择以下单机规则，不称为完整原版复原：

- 按上阵的不同棋子种类计数，同名重复、不同星级和备战不增加计数；采用最高档，六步兵减9而非18。
- 开战确定双方减甲档位，作用于对方全部棋子，包括飞行单位。步兵阵亡后持续至战斗结束，不因临时魅惑重新分配原属队伍的编队效果。
- 后续幽狼、灵木傀儡、镇海盾卫继承召唤者所受的敌方步兵减甲。它是独立编队效果，不占临时破甲槽；灵鱼驱散、不死鸟化蛋/重生不清除。
- 装备、装甲羁绊、玄甲和技能护甲增益正常抵消减甲；临时破甲可继续叠加。护甲减伤仍在零处封底，不产生负甲增伤，法术和真实伤害不受此项影响。
- 每枚单位仍可从自己的先锋羁绊、装备等获得生命；本轮仅移除步兵生命加成。当前六名步兵身份仍有历史映射缺口，不代表原版六步兵名单已全部复原。

AI及推荐布阵按新阈值选阵，并给予全队减甲有限估值；陆行者普攻为真实伤害，不计入这项物理收益。该估值是启发式，不是胜率预测。图鉴、备战/招募详情、演示阵容连携同步新规则；战斗棋子显示“步兵减甲 −3/−6/−9”。

## 旧存档和回放

`CURRENT_COMBAT_VERSION` 统一新局、默认推演、演示及下一回合的版本入口。原 `metamorph` 及更早的羁绊表保留；新表使用独立步兵数组，不覆盖旧对象。

schema21/0.22 → schema22/0.23：准备阶段进入新规则；战斗、结算和终局保留旧 combatVersion，未结算战斗仍按旧版本重建及结算。进入下一次准备阶段才切换。历史战报始终按各自保存的版本重放；金币、商店、卡池、棋子、装备、历史、播放位置和暂停状态不重置。0.21之前的迁移顺序保留，0.21→0.22中间版本使用固定字面值。
