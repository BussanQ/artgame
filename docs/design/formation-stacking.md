# 0.43 连携累计与高阶阵容

此前步兵、先锋、野兽和傀儡只取最高一档的原始数字，削弱了收集后续成员的收益。现在按已解锁档位累计，并分别保留本族、全军两种受益范围。当前63种棋子、22类羁绊和既有独立形象不变。

## 史料与推导边界

[S50原作者攻略](https://www.taptap.cn/moment/15203671482564780?group_id=42979)明确说明各档累计；[S18同期评测](https://www.taptap.cn/moment/15217028512090333)直接给出先锋护甲总量6/14、步兵减甲总量3/9/18。S03五月九日图表的原始增量与这两组总量一致。本轮再次目视核对S03图和S50野兽客户端提示，图片指纹与已有记录一致。

野兽提示的第一档只给野兽15%，第二/三档分别给全体25%/35%；因此本项目推导四野兽自身40%、其他友军25%，六野兽自身75%、其他友军60%。傀儡10%/15%的个人部分与最高档20%的团队部分同理，六档自身45%、其他友军20%。这两组分对象总量是**按原始范围累计的推导**，没有同版本客户端实测日志，不把全军也写成75%或45%。

S18野兽段有35/65与括注40/75两种全军写法，不能消除受益范围歧义；S50先锋图仍是旧回血，而正文已改护甲。保留这些版本冲突，不将整篇攻略当作统一配置。S20四月发行方傀儡字段与五月表一致，但四月野兽数字不与五月拼接。原始字段、来源、指纹和本地选择见[研究记录](../research/formation-stacking-history.json)。

表中已经是总量，不再相加。同名不同星、备战和后生召唤物不增加这四条的人数；异虫仍保留包含备战的两枚进化规则。增益按开战阵容锁定，不因提供者阵亡、临时魅惑而重算；玩家与AI使用同一规则。

攻击装备先进入基础攻击，再应用个人与团队攻击比例一次。攻速使用已有频率公式，包含棍奴疾风与装备，不把75%解释成缩短75%间隔。团队增益传递给后续幼狼、真人傀儡和须弥盾卫；个人25%傀儡攻击、个人15%野兽攻速与先锋护甲不传递。变身、化蛋、重生和驱散沿用既有边界；负甲增伤仍未实现，护甲减伤在零处封底。

图鉴、招募/备战详情、禁用可达性和阵容面板使用同一版本表。战场分别显示“野兽攻速+75% / 全军攻速+60%”以及“傀儡攻击+45% / 全军攻击+20%”，避免把个人总量误标成团队总量。已有装甲15/50回复、刺杀10/20概率等表已存总量，本轮没有对全部表盲目重复求和。

## 兼容与演示

规则为`singleplayer-0.43`、schema42，新增`formations`。schema41仅准备阶段切换；battle/result/finished及历史继续按`ambush`或更早版本重建、播放和结算，下一次准备才更新。中间0.41→0.42迁移固定写入ambush。金币、生命、经验、商店、卡池、棋子、装备、禁用、AI风格、随机数、历史及播放不重置。

修改前冻结27组0.42逐帧回放，保留原始期望哈希。`hasAmbushRules`统一穿山甲定义、遁地、灵鹫说明和单刺跳跃的继承边界，避免新增版本退回旧先锋或旧技能。当前演示继续采用正常星级、棋格和最多三件装备，没有隐藏属性或指定胜者。

累计减甲使旧疾风棍阵的二星棍奴在第九层后阵亡。该演示现在使用正常三星棍奴，对方仍有三星盾兵；实际9秒达到十层，整场32.75秒。调整用于展示满层动作与护甲，不改棍奴技能或额外授予增益。旧存档回放保存的二星阵容保持原样。
