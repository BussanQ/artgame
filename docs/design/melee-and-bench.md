# 兵种动作、备战详情与自动推进

更新：2026-11-03。

## 近战表现

`src/render/melee.ts` 定义 8 种动作轨迹及武器表现，`scene.ts` 按最近一次真实攻击事件采样动作。朝向由攻击目标坐标确定，动作最长不超过当前单位攻击间隔，死亡时停止攻击动作。播放速度影响采样时间，伤害和命中仍由原引擎结算。

| 棋子 | 动作 |
|---|---|
| 盾兵 | 后撤蓄势、持盾前顶、盾击冲击线 |
| 穿山甲 | 蜷缩、旋转滚撞、尘迹 |
| 忍者熊猫 | 两段错身斩、反向双刀弧光 |
| 狂狮 | 蹲伏起跳、前扑、三道爪痕 |
| 禅师熊猫 | 沉身蓄力、前推掌、层叠气环 |
| 鬼狼 | 隐化前扑、拉伸残影、咬合轨迹 |
| 棍奴熊猫 | 旋身、长棍横扫、环形棍风 |
| 铁巨神 | 抬升蓄力、重拳砸地、落地震波 |

实现采用现有透明精灵的独立动作曲线与程序化武器效果，不是新生成的骨骼动画。动作回到待机姿态，技能触发会增强幅度与亮度。

## 远程表现

`src/render/ranged.ts` 定义全部 4 种远程动作、弹道与命中特效，沿用真实攻击事件驱动。动作时长受攻击间隔限制，支持倍速播放，强化攻击会增强后坐幅度与特效亮度。

| 棋子 | 动作与弹道 |
|---|---|
| 神枪手 | 三段后坐点射、枪口火光、弹壳抛出、三道短曳光 |
| 神射手 | 压低身形瞄准、目标准星收束、单发高速弹道、强后坐 |
| 投石车 | 炮身仰起、车体回弹、带烟迹的高抛炮弹、范围爆炸光环 |
| 巨神炮 | 聚能粒子收束、炮身沉压、蓝色轨道光束、强震退与能量环 |

神枪手三连射为一次攻击的表现，不追加伤害；伤害数字在各自命中阶段显示。普通攻击的投石车爆炸为视觉效果；满能量技能现已接入真实范围法术伤害，见 skills.md。战斗尾部保留 5 个逻辑 tick（1 倍速约 1.25 秒），让最后的抛射及爆炸播完再进入胜负特效与自动结算流程。

## 备战席详情

`src/ui/bench-tooltip.ts` 对非空备战格提供 pointerover 和键盘 focusin 详情。详情固定定位，优先向上显示并在视口边缘避让；鼠标可移入详情继续阅读；移出、Escape 或界面重绘时关闭。战斗中通过外层容器仍可查看备战信息。

信息包含形象、名称、星级、近远程与动作名称、生命、攻击、护甲、射程、攻击间隔、出售价格、当前原型技能效果及两种羁绊。生命/攻击按星级倍率计算，明确标注未计上阵羁绊；技能说明由 data/skills.ts 共享配置生成，显示独立能力的真实作用；不再使用统一强化攻击说明。

## 自动回合推进

战斗回放结束 → 自动 settle → 展示胜负特效与战报约 2.6 秒 → 自动 nextRound → 刷新非锁定商店并进入准备阶段。仍可点“下一回合”提前进入；重开或手动推进会取消旧计时器。玩家淘汰、最后一人或 30 回合终局停留在最终战报。六对六演示不会结算真实对局。

## 必要验证

`npm run test:visual` 覆盖 64 格投影落点、事件伤害一致、全部近远程动作覆盖及轨迹合法性、直射/抛射落点、备战属性星级换算和远程动作名称。生产构建使用 `npm run build`。浏览器检查详情展示及战斗回放；不执行全量测试。
