# 不朽卫阵 / singleplayer-0.13

新增藤妖、骨龙、树妖与不朽羁绊。当前共 35 种可招募棋子、19 类羁绊、16 近战 / 19 远程。三枚棋子已进入商店、共享卡池、AI、推荐布阵、图鉴与战报；顶部“不朽阵容演示”可直接观看。

## 资料与改编边界

S20 英雄互娱在小米游戏发布的 2019-04-24 羁绊表确认：不朽由藤妖、骨龙、树妖组成，2/3 种分别延续战斗 4/6 秒。S23 的 2019-05-13 社区攻略提供灵能不朽的组合背景；S24 的同期社区文章描述藤妖单控、树妖瞬发范围控制、骨龙小范围伤害。来源入口见 [来源索引](../research/sources.md)。

只有名称、羁绊成员与 4/6 秒使用上述历史依据。费用、生命、攻击、护甲、技能名称及倍率、控制时长、护盾、残魂免伤/免治疗和结算口径均为本项目明确配置，不能称作完整历史复刻。骨龙暂配不朽/爆破；历史猛禽与灵能尚未补齐，不将当前分类冒充原作完整分类。

## 残魂生命周期

- 仅上场的不同不朽棋子计数，备战和重复同名不计。2 种提供 16 tick，3 种提供 24 tick，每 tick 为 0.25 秒。
- 第一次致命伤害先完成真实生命扣除、伤害贡献及既有死亡事件，随后原棋子进入残魂，每场仅一次。保持原 UID、位置、能量和控制状态，没有额外召唤物。
- 残魂继续占格、被选作目标、移动、普攻与施法。后续伤害为零，记录“不朽”反馈；不会为攻击者提供吸血或由生命伤害触发的回能，也不凭免疫命中生成破甲效果。
- 残魂不能治疗、自然恢复或获得护盾；友军主动治疗选择会跳过它。不会将阵亡转成满血复活。
- 眩晕和魅惑仍可限制残魂行动；不会延长期限。魅惑期间按原归属判断胜负与贡献，到期照常消散。
- 到期在该 tick 行动前消散，不能再攻击。消散不再触发一次死亡续战。
- 残魂存在时本方仍可继续战斗；若提前清空敌方可以获胜，但残魂不增加胜利后的星级扣血。基础 2 点扣血保留。
- 引擎内部 HP=1 仅用于既有寻敌和占位协议；战报将其展示为 0 生命、“残魂作战中”，另计残魂数，不伪造治疗或活体存活数。

实现分布：immortality.ts 管理进入/到期；abilities.ts 管理免伤、治疗与技能；battle.ts 管理行动/结算；battle-analysis.ts 独立统计残魂。临时状态不写入玩家 Piece，不改变持久阵容、卡池或下轮生命。

## 表现与操作

藤妖使用双藤甩鞭，树妖使用抬根重踏，骨龙振翼吐冥焰，具备各自弹道/技能光效。残魂显示半透明青色轮廓及剩余秒数；生命条替换为残魂倒计时。唤醒和消散有独立特效/音效，减少动态模式沿用静态提示。
