# 铁巨神：终结者（0.61）

铁巨神从近战范围眩晕原型改为远程炮击核心。新技能分两轮发射，各自飞行和爆炸；控制可以阻止未发出的大弹，已发出的导弹继续落地。加入远程普通攻击、新ImageGen炮击机甲、固定范围提示和分弹统计，保留旧版的近战属性、动作、形象与回放。

## 战斗与反制

- 满100能量且冷却结束，锁定5格内可见敌人的当前位置。起手后发射小弹，再装填并发射大弹；同次施法只消耗一次能量，冷却从起手计算。
- 两弹分别在固定位置爆炸，每弹对圆形半径3格内的每个存活敌人至多结算一次。小弹和大弹可以分别命中同一单位；每次独立经过魔抗、护盾和技能免伤。技能强度放大固定伤害，攻击力不放大导弹伤害。
- 目标移动可避开后续爆炸，进入范围的隐蔽或飞行敌人仍可被波及。友军不受伤；导弹保留发射阵营，之后魅惑改变的阵营按落地时重新判断。
- 架炮及两弹之间不能移动或普攻，普通攻击冷却照常流逝。眩晕、沉默、魅惑和阵亡取消未发射部分，不退还能量和冷却；已经飞出的导弹继续落地。
- 第一弹爆炸的反伤即使击杀铁巨神，该弹尚未处理的其他目标仍会结算，未发出的大弹会取消。第二弹发出后恢复行动。整个战斗结束就停止，不延长等待剩余导弹。

新技能的定位是范围伤害；原型天坠的1.5秒眩晕只保留在历史规则中。保护架炮、提前回能、控制发射间隔与分散站位因此有不同价值。
