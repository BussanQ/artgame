# 特种兵：七格锁定狙击（singleplayer-0.25）

新增独立棋子 `specialist`，补足步兵/狙击的三费长射程选择。当前52种可招募棋子，19近战、33远程、22类羁绊；四月53名基线中已有42项同名或本地映射，仍缺11项。同名覆盖不等于原版玩法复原完成。

## 历史依据与适配边界

[S04玩家属性表](https://www.taptap.cn/moment/15213091339897518)将特种兵与神射手分行，列出三费、步兵/狙击、450生命、97–127攻击、5护甲、7射程、1.7秒攻击间隔、10秒技能冷却。结构化原始字段见[历史图表](../research/historical-tables.json)。本项目采用攻击区间均值112，攻击间隔按0.25秒战斗步适配为1.75秒；生命和攻击沿用本项目逐星翻倍规则。

[S18玩家评测](https://www.taptap.cn/moment/15217028512090333)支持七格射程与后排定位。[S36五月攻略](https://shouyou.3dmgame.com/gl/128572.html)支持三费远程单体输出方向；[S37玩家攻略转载](https://news.17173.com/z/zzq/content/05152019/155428285.shtml?_platform=PC)提及控制与回能装备价值。上述材料日期不同，不视为统一客户端版本；S35公告目前只有前序检索摘要，直接页面不可用，不用它证明技能细节。

**定点狙击的名称、300/600/1200伤害、法术结算、0.75秒瞄准与眩晕、初始25能量、锁定和取消规则均为本地设计。** 尚未恢复原版完整技能参数。当前 `sniper` 神射手继续保留，不通过直接改名覆盖旧棋子身份和历史回放。现有步兵共七种，其中神射手身份仍待核对。

## 实际玩法

| 项目 | 配置 |
|---|---|
| 招募 / 卡池 | 3金，25份共享卡池，通常三枚同星合成 |
| 一星属性 | 生命450、攻击112、护甲5、射程7、普攻间隔1.75秒 |
| 启动 | 初始能量25；满100能量、冷却结束且当前目标可见、存活、属于敌方并在7格内 |
| 锁定 | 绑定目标UID，瞄准0.75秒；目标在范围内移动会更新准星，不改选更近目标 |
| 命中 | 单体300/600/1200法伤，使用开始瞄准时的技能强度；命中存活目标后短眩晕0.75秒 |
| 冷却 | 从开始瞄准计10秒，取消不退能量或冷却 |

瞄准时不能移动或普攻，普攻冷却继续流逝。瞄准结束后的技能冷却期间可以正常移动、普攻和回能。眩晕、沉默、魅惑、阵亡均可中断；目标阵亡、隐蔽、变成友方或离开射程也立即取消，不转火或无限等待。

伤害沿用护盾、魔抗、反伤和免伤规则。致死反伤不继续施加后续控制；不朽残魂与涅槃火种不会被眩晕。控制使用现有引擎的命中步加后续三个完整战斗步计时，与其他控制效果一致。一次锁定只计一次施法，战报仅累加实际扣除生命的伤害，溢出不计。

## AI、表现和存档

AI使用现有远程后排部署和技能装备评分，控制收益按0.75秒估计；技能输出评分计入瞄准可能被打断或目标丢失的折扣。该评分是选阵估算，不是战斗伤害公式。

普攻独立动作为半跪锁定、重狙后坐、拉栓复位，配有长曳光线和命中准星。技能瞄准显示跟踪虚线、收拢准星和锁定倒计时；命中显示青色射线，随后显示装填时间。单体锁定不绘制范围伤害区域。

schema23→24只补入缺失的25份特种兵卡池和新规则标记；四个阶段的资源、商店、棋子、装备、历史战报、combatVersion与播放状态保持原样。旧迁移先写入固定0.24，再继续升级，避免跳步。沿用infantry战斗版本，原有棋子不创建specialist施法状态。

十对十默认演示以二星特种兵替换原神射手的位置，带一件现有能量法杖，以便演示锁定和射击；其他主题演示保留。演示使用正常技能与装备规则，不写回实际对局经济或阵容。
