# 0.68 眼虫凝视

眼虫转为廉价的远程控制位：满能量且15秒冷却结束时，随机选择4格内可见、可受控制的敌人，施加4／5／6秒眩晕并每秒削减最多10能量。技能本身不造成伤害；护盾不能抵挡控制或削能，控制结束时结算最后一跳。基础身板采用原始实测表的500生命、0甲、4格、1.5秒，48–53攻击取均值后取整为51。

原始表、繁体玩家测量和七月评测分别支持基础属性／15秒冷却、随机四秒控制、控制时减蓝。尚无完整早期客户端卡，二／三星时长、每秒削能量、技能名、能力射程、零直接伤害和是否维持等细节均属于本地适配，不能把跨期材料合称同一版本复刻。[逐字段资料与边界](../research/gaze-history.json)。

这次施放为立即施加标记，来源随后可正常攻击；受控者头顶眼纹与紫色束环显示真实控制，详情显示剩余秒数。已施加的标记不要求来源持续施法或存活；灵鱼驱散会终止控制和余下削能。多个标记不重复扣能，只保留较晚到期的一次。削能按实际可扣量计数，不产生负能量、不转给眼虫，也不封锁后续普通回能。无能量被动仍可受控制，但没有可扣能量。

法强不放大控制或削能；AI不再将原型技能当作输出，仍识别初始能量装备的先手价值。战报增加控制人次和实际削能，早期时间点不会显示未来统计。菜单“战斗演示 → 凝视压制”提供同一个二对二局面，沿用已有眼虫形象。

`gaze`为第41个战斗规则版本，规则为`singleplayer-0.68`、存档schema67。40版旧身板和两个修改前的小回放SHA保持；进行中的旧战斗继续使用原能力，到准备阶段再升级，旧目录、资源、历史和播放进度保留。神枪手图鉴同步修复为共用星级间隔：三星0.5秒，与实际战斗一致。

45项相关模块检查和生产构建通过；桌面1280×720与390px已核对控制、详情、回看、图鉴、滚动关闭和退出资源。同一局面在6.75秒实际削能20、13.75秒为50；完整模拟两次凝视累计100。没有新增整局或批量采样，也不将响应式预览当成真实手机性能验收。[验证清单](../analysis/gaze-v068-validation.json)。
