# 巨鲸之眼、海雾与装备回能

`singleplayer-0.81`，战斗版本 `sea-fog`，存档schema80。新增巨鲸之眼，装备共19件（6基础、13成装）；兵种仍64种。复用现有ImageGen棋子形象，用Canvas绘制海雾预告和引爆，没有新增棋子位图。

## 原卡与适配

[发行方2019-04-19文章及客户端原图](https://game.xiaomi.com/viewpoint/1103968488_1555665047389_16)明确：巨鲸之眼增加100%造成伤害时的能量回复、30最大攻击；海雾冷却45秒，延迟6秒对全体敌人造成200技能伤害，装备技能不随数量叠加。[研究记录](../research/whale-eye-history.json)保存原始PNG、校验值及未知字段。

合金刃＋生命核心合成，沿用野怪基础材料、库存合成、穿戴／卸下、升星与出售归还和持有人查询。材料配方和下述时序／继承细则为本地适配。

## 战斗行为

- 独立装备技能在开战1秒后就绪，无需能量，不替换本体普攻或引导。释放前眩晕、沉默、魅惑、死亡、残魂、化蛋时等待；没有敌人时也保留就绪。
- 释放后预告6秒，再对全场其他存活敌人结算。按释放时阵营辨敌，引爆时检查当前阵营；可命中隐形和期间新出现的召唤物，不伤释放者。全场预告、滚动雾带和引爆均来自实际战斗状态，低动态模式保留静态范围和倒计时。
- 已释放的海雾在持有人阵亡、受控或改变阵营后继续；反伤击杀持有人也不会漏掉余下目标。它沿用其他已释放技能的战斗结束规则，不延长已经结束的战斗。
- 200为基础法伤，不随星级、攻击或法强变化；魔抗、护盾、技能免疫与团队伤害规则照常计算。实际生命伤害、破盾和有效命中分别统计。同名装备只有一道海雾；不同持有人的技能独立。
- 原卡“最大攻击＋30”映射为本项目确定攻击＋30。基础攻击和回能可以叠加；装备技能与回能不复制给召唤物。刑傀保留既有战斗属性快照，但不复制海雾或额外回能。

## 回能与AI

伤害回能沿用现有普攻动作入口：普通攻击造成生命损失时，额外放大同一次25基础回能，每个普攻动作最多一次。纯破盾、闪避、技能、反伤、持续伤害、受击和其他供能不产生该装备的额外回复；无能量棋子、封能、魅惑和死亡状态不制造回能。

与召唤连携的回能加成相加，再应用敌方倍率和骑兵固定扣减，固定扣减不会重复收取。100能量上限、旧连携优先归因后，只记录装备实际增加的部分。装备自身回能单列“巨鲸额外回能”，不再被通用战报误计为辅助“供能”；旧版本效果的归类保持。

AI可合成并分配巨鲸之眼，给予实际使用能量的棋子回能估值，一次性变形／召唤等只计开场价值，重复持有不再重复计算完整海雾收益。旧0.80规则不提前合成它。估值是有界启发式，不是总体胜率证明。
