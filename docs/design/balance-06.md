# 0.6：阵容反制、终局野怪与守军情报

本次是单机自主平衡，不是原作官方数值恢复。规则版本 `singleplayer-0.6`，战斗版本 `balanced`，存档 schema 5。

## 实际调整

| 项目 | 0.5 | 0.6 |
|---|---|---|
| 三步兵 | 对应棋子生命 +400 | +300 |
| 四狙击 | 对应棋子攻击 +35%，普攻破甲 2 | 攻击 +25%，破甲不变 |
| 终局两枚铁巨神 | 3 星 / 2 星，关卡倍率均 1.2 | 星级不变，倍率均 1 |
| 终局投石车 | 3 星 | 2 星 |
| 终局巨神炮 | 3 星 | 不变 |

未改变棋子的基础属性或技能系数。旧规则保存在 `TACTICS_TRAIT_TIERS`、`TACTICS_ENCOUNTERS`；存档迁移不改进行中的战斗、结算和历史记录。准备阶段采用新规则，旧战斗在下一轮才切换。详见 [存档说明](persistence.md)。

## 等预算对照

六种阵容均为六人口、全二星、45 金币购入份数、无装备；每对阵容各用分散和抱团，交换双方。共 168 场（含镜像），非镜像每个阵容 40 场。

| 阵容 | 0.5 获胜 | 0.6 获胜 |
|---|---:|---:|
| 射手防线 | 40/40 | 35/40 |
| 突袭猎杀 | 30/40 | 34/40 |
| 荒原兽群 | 18/40 | 18/40 |
| 治疗支援 | 8/40 | 8/40 |
| 范围轰击 | 10/40 | 11/40 |
| 熊猫先锋 | 10/40 | 10/40 |

[0.5 原始对照](../analysis/formation-v05.json)、[0.6 原始对照](../analysis/formation-v06.json) 记录完整棋子、站位和源文件哈希。阵型结果有双向变化，例如范围轰击对抱团射手时，分散换边取得一胜，抱团为零胜；并非抱团总是更好。合成阵容只用于隔离战斗因素，不能作为真人对局胜率。

进一步枚举所有六种不同棋子、基础费用总和 15 的组合：4,818 种。每种两种阵型，对固定射手阵容的两种站位并交换双方，共 38,544 场。每个“组合 + 阵型”有四次对战：旧版至少一胜的有 540 个，至少三胜的 7 个；新版分别为 1,063 和 31 个。

新版出现一个不依赖四狙击的四战全胜组合：盾兵、忍者熊猫、狂狮、鬼狼、暗影刀、牛魔，采用分散站位。该反制已加入必要模块验证。旧版唯一四战全胜组合仍是四狙击变体。

[旧采样](../analysis/sniper-counter-sweep.json)、[新版完整计数与最佳组合](../analysis/sniper-counter-balanced.json)。这说明反制选择增加；不代表六种流派强度相等，装备、经济、升星概率也未包含在等预算实验中。

## 长局与后期野怪

同一固定玩家策略，以种子 137、307、809、1619，七种购买偏好 × 三档敌方难度，共 84 局。全部正常消费、逐轮校验卡池、经济与落位。

| 难度 | 平均最终名次 | 前四 | 第一 |
|---|---:|---:|---:|
| 休闲 | 2.61 | 25/28 | 6/28 |
| 标准 | 5.18 | 10/28 | 3/28 |
| 挑战 | 7.25 | 1/28 | 1/28 |

[完整记录](../analysis/balance-balance-v06.json)。到达第 15 / 20 / 25 / 30 回合的野怪胜场分别为 52/84、65/68、36/43、6/25。此前 0.5 同种子终局胜场为 1/24；存活阵容也受羁绊调整影响，不能把差异全部归于守军改动。终局仍是高难度试炼，失败后按既有生命与终局规则结算。

另以四局标准难度中实际持有的棋子和装备，比较原站位、分散、抱团及左右镜像。替代方案只在克隆状态计算，不改变正式对局。种子 809 的第 30 回合，原阵型失败，抱团镜像可获胜；种子 137 的终局五种方案均失败。[阵容、装备与结果](../analysis/pve-position-v06.json)。站位有实际收益，但不保证弥补阵容强度不足。

84 局本机 Node 采样每轮计算平均 19.17ms、最慢 94.82ms；该数字不是浏览器帧率，也不是弱设备表现。

## 可见情报

修复旧 CSS 隐藏野怪预览的问题。野怪回合在棋盘上方显示关卡、守军星级和提示；“查看守军属性”展开生命、初始攻击、护甲和开战护盾。数值直接使用与战斗相同的 `army` 初始化，包含关卡强化与该局版本的羁绊。

桌面采用全宽情报条，手机将属性排成两列。浏览器检查了 1280px、390px、320px，无横向溢出；属性折叠不消耗资源。

## 复现与必要验证

```sh
npm run test:balance
npm run survey:formations -- v05 tactics
npm run survey:formations -- v06 balanced
npm run survey:counters -- balanced
npm run audit:pve
npm run survey:balance -- balance-v06 137 307 809 1619
```

报告按标签覆盖同名文件；后续规则改变后，只有显式保留的历史战斗版本可以复现旧战斗。formation 报告中的 PvE 附加实验使用运行时的当前关卡表，不用它比较历史野怪版本；正文的 PvE 对照来自长局报告。

必要模块执行范围：strategy、roster、persistence、engine、abilities、tactical-ai、campaign 共 59 项通过；补充 balance-migration、equipment、campaign 共 19 项通过（campaign 重复覆盖，非 78 个独立测试）。新迁移模块包含五项：准备阶段迁移、旧战斗与历史逐帧一致、两版羁绊隔离、两版终局隔离、非狙击反制。生产构建通过，未跑全量测试。

剩余限制：固定策略不是玩家研究；尚未验证真实弱设备性能、所有装备构筑及所有种子。当前数据足以支持本次数值修正，不宣称全量历史复刻或全面平衡。
