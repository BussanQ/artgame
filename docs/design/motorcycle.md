# 0.21 摩托骑兵与历史图表恢复

新增三费骑兵/爆破摩托骑兵：三次独立法术射击，每发重新选敌，目标阵亡后转火。当前50种可招募棋子、18近战/32远程、22类羁绊。四月名单已有40项名称或本地设计对应，缺13项，仍有8项分类差异；同名不代表技能和数值已完全复原。

## 来源与采用范围

[S34发行方文章](https://game.xiaomi.com/viewpoint/1103968488_1555665047389_16)确认“三连发”名称及三星每发400；[S18玩家评测](https://www.taptap.cn/moment/15217028512090333)支持法伤和三发可命中不同敌人的方向。[S04玩家测量表](https://www.taptap.cn/moment/15213091339897518)提供三费、骑兵/爆破、500生命、55–60攻击、护甲5、射程3、普攻间隔1.5秒、技能冷却10秒。

一/二星每发100/200、初始50能量、0.5秒射击间隔、曼哈顿三格范围、逐发最近选敌及打断边界是本项目配置。三星400与已找到的发行方数据一致，但不据此宣称整个技能完全还原。技能不额外添加后期版本的溅射或骑兵装备加成。

初始采用500生命、平均攻击四舍五入58、1.5秒普攻的方案，在42局正常经济采样中没有进入玩家方阵容。最终单机属性改为**750生命、72攻击、1秒普攻**，护甲5、射程3、费用3和技能冷却保持；这是为了适配当前原型环境的平衡调整。历史原值单独保存在[图表数据](../research/historical-tables.json)，没有覆盖为原型数值。

## 实际结算

- 满100能量且冷却结束、存在射程内可见敌人时消耗能量开始施法。第一发在0.5秒后，随后每0.5秒一发，总三发。
- 每发按当前阵营、生命、隐蔽、距离重选目标；距离相同时UID较小者优先。不会攻击友军、阵亡单位或射程外敌人。射程内无可见敌人立即取消余弹。
- 每发100/200/400法伤乘以施法时技能强度；攻击装备不会提高这部分伤害。护盾、技能减伤、不朽免伤、反伤逐次结算。发射者被反伤击杀后不会继续发射。
- 施法期间不能移动或普攻，普攻冷却正常流逝。眩晕、沉默、魅惑或阵亡中断。10秒技能冷却从开始施法计算；取消不退能量、不清冷却。冷却中可以正常移动、普攻和积攒能量。
- 伤害由每发真实事件结算；一发事件对应一次枪口光、弹道、后坐和命中特效。三发是一次施法，战报分别累计三次生命伤害和破盾。

复用现有可打断施法生命周期，新增motorcycle施法类型和可选skillReadyAt字段。旧棋子没有该字段，不改变旧棋子技能与旧回放；没有增加combatVersion。

## AI、存档与表现

AI按两发成功命中的保守估计计算技能价值，仍按后排配置站位。规则0.21 / schema20从schema19只补25份摩托骑兵共享卡池，保留玩家资源、阵容、商店、战报和回放；schema18先迁移到字面0.20，再进入新迁移。

独立动作“压车架炮后坐”，普攻实心曳光弹、技能较粗弧线炮弹。连发时显示三格弹药指示与剩余发数，结束后显示装填倒计时；没有画成范围伤害预警。顶部“战斗演示 → 十对十兵种”已加入二星摩托，与马骑兵组成两骑兵。

使用内置image_gen生成透明完整骑手/摩托形象，保存至`public/assets/units/motorcycle.png`。未修改生成图，1536×1024，alpha范围0–254，899926个全透明像素，四角透明；[完整提示词、原始路径与SHA-256](../research/motorcycle-assets.json)。

图鉴筛选为唯一结果时，桌面改用整行详情，避免长技能挤在窄卡片中；手机保留单列可滚动布局。
