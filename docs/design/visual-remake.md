# 视觉与战斗表现重制（2026-11-03）

## 本次交付

使用内置 image_gen 生成 12 个独立透明棋子 PNG 和 1 张云海遗迹环境背景，已复制到项目 `public/assets/units/` 和 `public/assets/arena/`。原始生成文件仍保留在生成目录。完整逐图提示词、文件路径和生成方式记录在 [generated-assets.json](../research/generated-assets.json)。

形象包括神枪手、盾兵、穿山甲、忍者熊猫、神射手、狂狮、投石车、禅师熊猫、鬼狼、巨神炮、棍奴熊猫、铁巨神。统一采用东方科幻、半写实三维微缩模型观感、透明背景和俯视三分之四视角。商店、备战席、图鉴、伤害列表、战场共用同一份形象。

## 表现层

- 新增 Canvas 2D 的 2.5D 战场渲染器 `src/render/scene.ts`，将平面逻辑格子投影到梯形石质棋盘。
- `projection.ts` 提供棋格到屏幕坐标、指针到棋格的双向映射，画布缩放时按实际尺寸归一化。
- 角色按纵深排序，使用独立直立透明图片绘制；带投影、阵营底圈、生命/能量条、星级和名称。
- 连续帧插值移动，待机轻微起伏、攻击前倾、受击闪光、死亡倾倒淡出。
- 引擎 `Frame.events` 显式输出攻击者、目标、实际伤害、起终点、远程/技能标记。表现层据此显示弹道、炮击弧线、近战挥击、冲击光环、火花和伤害飘字。
- 逻辑模拟与播放速度分离，1×/2×/4×和暂停不改变战斗结果；仅局部更新战斗计时与伤害列表，战斗每帧不再重建整个界面。
- 六对六演示使用独立阵容及结果，不花费金币、不修改真实对局。演示可循环、暂停和退出。
- HUD 改用青铜/金色边框、玉绿阵营色、云海遗迹背景；窄屏保留战场优先与横向商店。

## 参考与复刻边界

参考入口：[2019 实机评测](https://games.sina.cn/wm/2019-05-06/detail-ihvhiqax6883923.d.html)、[游戏画面检索来源](https://m.qmdown.com/pgyx/212.html)。检索显示原版科技感单位、棋盘布阵与实时战斗界面。部分图片直链超时或 TLS 连接失败，因此本次没有宣称完成逐像素比对。

本次是以赤潮的题材和战场结构为方向的视觉重制，使用生成形象与 2.5D 精灵动画，并非提取的原版资产、真实骨骼动画或原版 3D 模型。技能效果依据真实攻击事件绘制，但数值层仍为统一原型技能；视觉光环不代表额外范围伤害。原版兵种差异化技能、装备、野怪仍按后续计划推进。

## 胜负结算特效（2026-11-03）

新增 `src/ui/battle-result.ts`，根据实际 `Battle.winner` 展示金色胜利冠冕/放射光芒、红色失败破盾/轻震动或蓝色平局徽章。覆盖层保留最终战场作为背景，显示结算前后计算出的生命损失与金币收入，并用进度条提示自动进入下一回合。展示时间统一为 2600ms，不受战斗倍速影响。

终局展示最终排名并保留战报，不安排下一回合。正常对局的手动推进与重开会清理旧计时器及特效状态；演示模式展示自身战果后重新播放，不修改真实对局。开启系统减少动态效果时禁用装饰动画但保留结果文字。代码原生 SVG/CSS 负责徽章与粒子，继续共用已有 ImageGen 角色资源。
