# 0.39 野兽前排：巨齿象与猛毒兽

新增一费巨齿象、二费猛毒兽，均为野兽 / 先锋。当前62种可招募棋子，27近战、35远程，均有独立生成形象。按四月53名单计算已有52项对应，尚缺灵鹫；9项分类差异保持可见。

## 资料与实现选择

基础属性采用S04七月玩家测量：巨齿象650生命、34–58攻击、5护甲、1格射程、1.2秒攻击间隔；猛毒兽650生命、87–125攻击、5护甲、1格射程、1.5秒间隔。攻击取中值46与106，巨齿象间隔量化为1.25秒。

[S35五月9日更新公告](https://www.taptap.cn/moment/15209355339104422?group_id=42979)本轮读到正文，确认酸性污染冷却20秒改为10/8/6秒，页面修改日期为五月8日。该公告也再次揭示野兽、先锋、装甲等历史梯度差异，留待独立版本对齐。

[S46五月3日官方图鉴转载](https://news.17173.com/content/05032019/080728972.shtml)的图片搜索索引给出巨齿象单体伤害与击飞候选值，但原图获取失败，不能当作完成视觉转写。伤害100/200/300仍明确列为本地参数。[S47九月28日公告](https://www.sohu.com/a/421209278_100204787)确认技能名“獠牙冲”，但它属于2020年，不能把其10/8/6秒冷却套到2019；本轮使用S04的20秒。完整字段与未核实项见[研究记录](../research/beast-frontline-history.json)。

## 战斗规则

巨齿象初始25能量，满能量、相邻可见敌人、冷却结束时单体法伤100/200/300，附原地击飞1秒。击飞以眩晕限制行动并打断蓄力/引导，逻辑棋格和飞行种族保持原值；独立抛物线只负责视觉。伤害受技能强度加成，控制不受加成。冷却20秒从施放时计。剑奴旋转免伤免控，残魂与火种不追加击飞。

猛毒兽初始25能量，3格内可见敌人为施法锚点，将其所在九宫格敌人的护甲降低7/14/21，持续6秒，冷却10/8/6秒。范围包含空中和隐蔽单位，不影响友军，后进入区域者不会补挂。减甲没有直接伤害或持续毒伤，技能强度不提高效果，也不会提高近战普攻射程。

同类污染取当前最高值，各施法者独立计时；弱效果不会延长强效果。同一施法者重施替换自己的记录，与步兵减甲和普攻破甲分别计算，物伤结算护甲最低为零。灵鱼可驱散；残魂、火种、旋转免控中的剑奴不受新污染，化蛋/转残魂会清除已有污染。施法者阵亡不提前结束，阵营变化不追改已施加目标。

双方技能受满能量、眩晕、沉默、魅惑、阵亡、合法目标和冷却限制；受阻时不扣能量。冷却期间仍能普攻、移动与回能。初始能量、技能范围、控制时长、伤害类型、减甲幅度与持续时间等未有同版本直接图鉴的字段均属本地适配。

## 表现、AI 与存档

巨齿象普通攻击为踏步扬鼻挑牙，猛毒兽为压肩横甩撕咬；酸液轨迹、落点、减甲环和击飞弧线分别绘制，减少动态效果仍保留状态提示。战报按当前所选片段统计实际“击飞N次”和“酸蚀命中N次”，不把减甲虚算为直接伤害或泄露未来效果。

正常野兽与刺杀AI自动纳入新成员；巨齿象按一次单体伤害与控制估值，猛毒兽只计有上限的辅助价值，不假设全军覆盖。猛毒兽的法杖回能仍有作用，技能强度部分不加分。装备数量、升星与共享卡池规则沿用正常交易接口。

规则`singleplayer-0.39`、schema38，战斗版本继续`puppets`。schema37仅补缺失的巨齿象45份、猛毒兽30份；本局禁用野兽时两池为零。旧随机数、资源、棋子、商店、装备、AI风格、历史和播放进度保留；已有新池不重复追加。污染与击飞是战斗状态，不写入永久Piece，回放从参战阵容重建。

两张形象通过内置ImageGen生成，真实RGBA透明通道原样保留；图像不是原作模型。提示词、来源路径与SHA记录见[资产清单](../research/beast-frontline-assets.json)，项目文件为`public/assets/units/elephant.png`和`public/assets/units/venombeast.png`。

## 验证记录

181个不同必要用例覆盖11个受影响模块文件，其中62项野兽专项包含八种阶段/禁用迁移与18组0.38旧回放。旧回放校验值在修改运行代码前捕获；低费迁移样本在AI准备前排除新兵种，以模拟真实旧版本名单，不修改期望回放哈希。完整/轻量/Worker结果、控制/免控/驱散、独立减甲计时、物伤与法伤、三格喷吐和合法付费AI均通过。TypeScript与生产构建通过，未运行全量测试，未自动提交Git。

新增“野兽破阵”六对六演示，使用正常星级与装备，不注入战斗属性或指定胜负。完整目标继续推进：灵鹫、统一历史切片、其他羁绊与能力对齐、整体难度、真实弱设备和最终人工体验验收尚待完成。
