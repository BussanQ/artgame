# 0.44 狙骑、海神、灵能与战斗详情

狙击从固定加攻击/目标破甲改为本人的物理甲穿，骑兵从普攻破甲改为敌方回能压制；海神恢复早期空中防御，四灵能改为同期累计50反伤。配合新的战斗详情，构筑收益和反制状态可以直接在实战中查看。当前仍为63种棋子、22类羁绊。

## 史料和版本选择

重新目视核对[S03五月九日图](https://www.taptap.cn/moment/15202528882852517)。[S18第二期原作者评测](https://www.taptap.cn/moment/15217028512090333)明确三/六狙为4/12总甲穿，骑兵段同时保留减3与后续减5的写法；本轮采用S03明确的减3。

新增[S51第三期评测](https://www.taptap.cn/moment/15220462338441888)，页面显示2019-05-28。作者明确按累计总量报告，更新前海神为2/4档空中单位技能防御20%/40%，灵能为2/4档全军反伤20/50；更新后才转为海神回能和低档15反伤。本轮选用更新前切片，避免同时获得回能和防御。

S03灵能人数印为2/3，S20四月发行方及S51均为2/4，当前采用2/4。S20本族范围和后续六月版本的低档本族/高档全军也与五月不同，保留冲突。没有采用“灵能抵扣原受伤害”的传闻。研究原值、来源及适配边界见[counterplay-history.json](../research/counterplay-history.json)，不称为取得统一客户端完整配置。

## 实际战斗规则

| 连携 | 不同上场成员 | 当前总效果 |
|---|---|---|
| 狙击 | 3 / 6 | 狙击自身物理伤害无视4/12护甲，不额外加攻击、不让目标减甲 |
| 骑兵 | 2 | 敌方全军每次回能在倍率后扣3，最低零；初始能量不变 |
| 海神 | 2 / 4 | 所有空中友军法术减伤额外20/40个百分点，不再命中回能 |
| 灵能 | 2 / 4 | 全军受击反弹20/50真实伤害，包含残魂与后生召唤物 |

狙击甲穿不共享给其他队友或后生召唤物，也不写入目标破甲状态。本地计算将它作用于普攻和物理技能，放在护甲增益/减益及临时破甲之后、技能百分比穿透之前，仍采用零甲封底；法术和真实伤害不受它影响。这些公式与物理技能边界属于单机适配。

骑兵覆盖普攻回能、受击回能、童子充能和支援恢复等正向回复事件，与既有异能倍率一起生效。无倍率时25回能变22、10变7；封能、被动无蓝条资格和能量消费保持原规则。后生召唤物继承对方压制字段，但依然不能积累或使用能量。初始能量与永久棋子不被扣减。

历史“技能防御”映射到当前引擎的法术减伤：与装备及召唤防御相加后最多75%，再应用爆破减抗，最低−25%。非海神的飞行友军也受益，地面单位不受益。血鹰落地失去海神防御；不死鸟化蛋时失去、孵化时恢复，按开战未加海神的基础值重算，避免截顶后直接加减造成错误。地面幼狼、灵木傀儡与盾卫不复制主人的空中防御。

反伤保留原有命中/护盾、不朽、闪避、死亡及不递归边界，不触发吸血和额外回能；被打者仍完整承受原始结算伤害。人数与其他连携一致采用开战不同上场种类，提供者阵亡或临时魅惑不重算。

AI与推荐阵容的通用评分加入有限的甲穿、团队法抗及回能压制收益，继续使用真实价格、卡池和资源，没有额外属性或指定胜负。

## 战斗画面与查看方式

所有棋子旁最多显示两个短状态，优先击飞、眩晕、魅惑、沉默等关键控制；护盾、光环、满层动作、弹道和伤害数字继续呈现。攻击、攻速、甲穿、反伤、减甲和冷却等完整说明进入棋子详情，避免每枚棋子横向堆叠整行文字。

鼠标悬停可查看，点击棋子固定详情；手机点击同样固定。命中范围包括人物身体，重叠时选择前景活单位；使用已绘制的插值位置。详情显示当前帧生命、能量、攻击、间隔、护甲、法术减伤和状态，不读未来总伤害。固定选择在播放/暂停、菜单与屏幕尺寸变化后保留，换场或退出战斗清空；关闭按钮、空处点击和Esc可收起。关闭按钮不随数值更新重建，完整状态由原绘制收集逻辑提供。

“狙骑反制”演示使用正常八对八：己方六狙两骑，对手四海神四灵能，含正常星级、站位和最多三件装备，没有隐藏数值。实际12.25秒结束、己方获胜，该结果不是预设。六狙中的部分成员仍是本地分类，不能据此宣称历史名单已全部复原。

## 兼容与必要验证

当前`singleplayer-0.44`、schema43、战斗版本`counterplay`。schema42仅准备期切换；在途战斗、结算、终局与历史继续按原`formations`或更早版本重建，下一准备阶段才更新。中间0.42→0.43固定为formations和0.43规则。金币、生命、经验、商店、卡池、棋子、装备、禁用、AI、随机数和播放均不重置。新局可玩性筛选会使用三狙门槛，可能改变同种子的随机禁用组合；已存在的禁用不重抽。

`npm run test:counterplay`覆盖32个受影响文件，785项全部通过，含本轮63项战术专项与4项详情/命中/短状态专项。修改前冻结的35组0.43回放逐帧保持。原26/32棋子的早期SHA也保持原值；修复旧测试从扩充名单直接切片、导致输入身份改变的问题，改为明确原名单，没有重写期望哈希。旧迁移测试使用真实历史战斗版本；六刺统计按实际击飞事件核对，不把致死技能也虚计为成功击飞。

必要模块覆盖真实伤害/回能/防御、护盾与技能、召唤、变身/化蛋/重生、两方效果、八种阶段/禁用迁移、完整/快速/Worker一致和AI。详情交互修正后另复验4项对应模块，TypeScript与Vite生产构建通过。未运行全量测试，未提交Git。
