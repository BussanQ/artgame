# 方舟：集团轰炸（0.60）

方舟从蓄力贯穿光束改为派出机群进行矩形轰炸，同时恢复低普攻、远射程的技能输出定位。机群逐步推进，起手可以打断，出动后的飞机会在方舟阵亡后继续完成攻击。完整单机目标仍在推进，本次只做技能模块、小型演示和兼容验证。

## 资料与适配

已归档并目视[S55原始客户端卡](../research/images/ark-bombardment-client-dec2019.jpg)，采用四费、空军/攻城、集团轰炸、250/400/650法伤和一星14秒冷却。[S35五月公告](https://www.taptap.cn/moment/15209355339104422?group_id=42979)的既有原始HTML另给14/12/10秒梯度，[S04实测表](../research/images/s04-skytoad-attributes.jpg)第17行与之相符，并提供650生命、30–34攻击、5甲、5格与1.2秒普攻间隔；攻击取均值32。

[S11六月机制报道](https://shouyou.gamersky.com/news/201906/1191090_2.shtml?tag=wap)说明机群出现后方舟阵亡仍继续结算；该报道由游民星空整理、作者未知，作为定性旁证。十二月文章的当前网页含第三方AI摘要，本次采用此前无摘要原HTML及实际重新下载的原始客户端图。首个伪装为JPG的HTML响应已排除，另一个玄龟配图实际是经典模式，也已移出资料目录。

这些材料跨期，未证明来自同一客户端构建。精确范围、飞机数量、速度、起手和碰撞边界没有史料数值，[来源、SHA和本地选择](../research/bombardment-history.json)分开记录。

## 战斗行为

- 满100能量且冷却结束时，选择5格内可见敌人，冻结方向与技能威力，消耗能量并开始1秒聚能。聚能时不能移动、普攻或覆盖施法，普通攻击冷却继续流逝。
- 出动三架小型战机，沿宽3格、长8格的矩形推进，每秒2格；每0.25秒结算新扫过的条带。范围在棋盘边缘裁切，不会追踪已移动的目标。
- 同一机群对每个敌人最多结算一次固定星级伤害，三架飞机仅表现覆盖宽度。法强增加伤害，攻击力不增加轰炸威力。命中时按现有法术减伤、护盾、技能免伤、攻城与反伤规则独立处理。
- 范围可波及隐蔽与飞行敌军，友军不受伤。目标移出路径可躲避；进入已经扫过的地面不会补受伤害，反复跨越也不会被同一机群重复命中。
- 眩晕、沉默、魅惑或死亡会打断起手，不退还能量或冷却。出动后方舟恢复行动，机群保留原阵营和起手伤害；反伤中途击杀方舟也不取消其他命中。
- 机群没有人口、生命、寻敌和独立选中状态，不进入商店、装备工坊、共享卡池或召唤物列表。整场战斗结束就结算，不等待出界的飞机或追加胜负伤害。

这让保护方舟聚能、提前回能装备、对空集火、控制时机和分散站位产生不同取舍。

## 画面、演示与战报

沿用既有ImageGen方舟形象，小型飞机复用已生成的幽灵机画面，通过共享256像素缓存加载。聚能有双舷发光、起手姿态和虚线矩形；机群有三路飞行、落弹、地面爆点及剩余路径。贴图未就绪时暂用飞机轮廓，减少动态效果时保留飞机和实际范围。

备战详情、图鉴和技能名称均显示集团轰炸。场上只放起飞短标签，详情显示出动次数、实际命中和冷却；战报按所查看时刻累计，不读取未来命中。旧版本仍显示原来的光束说明与原型属性。

入口为“菜单 → 战斗演示 → 集团轰炸”。六对六演示通过正常引擎与合法装备运行，不改变当前比赛资源；为观察机群而配置的阵容不是等预算平衡样本。敌军巨神炮优先攻击飞行方舟，回能装备让方舟有机会先出动，再展示阵亡后的轰炸。

## AI与存档

AI按一次轰炸、有限目标数和躲避折扣估算首次收益，不假设全队命中或三个全额伤害包。仍保留星级、费用、阵容与装备的权重；本次没有通过批量对战调参，也不据此宣称总体平衡提升。

`bombardment`为第33个战斗版本，继承已有连携和技能。此前32版本的方舟本体和光束不变。schema59将57→58固定为0.59/secret-orb，再由58→59仅升级准备阶段；正在战斗、结果、终局和历史仍用原版本，下一准备阶段再升级。比赛价格目录不改，方舟仍为四费15份。
