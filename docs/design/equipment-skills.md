# 装备独立技能

`singleplayer-0.80`，战斗版本 `equipment-skills`，存档 schema79。装备总数由16增加到18，原有装备属性与配方保留。战斗演示增加“装备主动技能”。

## 资料与实现

[发行方2019年4月19日资料](https://game.xiaomi.com/viewpoint/1103968488_1555665047389_16)提供原始客户端卡面：狼牙坠增加10%吸血，呼号每30秒召唤一个傀儡；灵魂之晶增加30%技能伤害，鞭笞每10秒随机对一个敌人造成500技能伤害。两张卡面均注明技能效果不随装备数量叠加。原图、校验值与适配边界见[逐字段记录](../research/equipment-skills-history.json)。

- 狼牙坠由 `fang` 与 `crystal` 合成；相邻无空格时保留就绪状态。装备召唤不占用真人的两只本体傀儡额度，鬼狼仍可召两只幼狼。
- 灵魂之晶由 `crystal` 与 `coil` 合成；选择可见敌人，计算魔抗与护盾，分别记录实际生命伤害和破盾。选择过程可重放，不消耗经营随机数。
- 两件装备在开战1秒后首次触发。装备技能不消耗能量，不替换普攻或本体引导；持有人眩晕、沉默、魅惑、死亡、残魂或化蛋时暂停，无合法目标时等待。同名装备只有一套技能和冷却，基础属性仍受原有叠加与上限约束。
- 呼号傀儡固定一星、380生命、48攻击、3护甲、0.75秒普攻；不继承持有人星级、装备或法强，保留全军与召唤增益。召唤当帧不行动，持有人死亡不删除已有傀儡，使用现有 ImageGen 傀儡形象。

合成材料、首次触发时间、控制交互、固定法伤的法强规则、傀儡属性与继承规则均为本地适配，原始卡面未提供这些字段。这里只恢复两件装备的已核实技能，未声称完整复原原版装备库或总体平衡。

## 构筑、显示与兼容

AI 按上场棋子的合成收益选择装备，避免先按目录顺序耗掉新配方材料；已覆盖的唯一技能不重复计入完整收益。旧战斗版本继续使用原配方顺序。装备工坊沿用合成、穿戴、卸下和持有人显示，棋子信息与战斗分析增加独立装备贡献。

schema78→79：准备期升级当前战斗规则；进行中的战斗、结算与终局保留 `dream`，旧目录、资源、历史和播放状态不变。装备规则按整场战斗版本启用，旧目录棋子也可在新战斗中使用装备技能。52代旧兵种定义、呈现和一个旧召唤回放保持。

## 验证

[必要验证记录](../analysis/equipment-skills-v080-validation.json)：29项装备技能模块检查通过，随后补验9项工坊、4项交易／旧AI与3项迷梦迁移，并复验扩展后的新AI检查；185模块生产构建通过。仅使用固定小局面验证录制、快算和Worker一致，没有完整经营局或批量对战。

浏览器画面、演示入口与手机布局尚未验收，此前存档恢复的实际刷新／下载验收也待补。
