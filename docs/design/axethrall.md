# 0.32 斧奴：低费傀儡刺杀与飞斧

新增一费斧奴、独立透明形象、侧身引斧斜劈动作和旋转飞斧特效，提供“傀儡刺杀”六对六演示。当前56种可招募棋子，21近战/35远程、22类羁绊。规则 `singleplayer-0.32`，schema31，战斗仍为 `armored`。

## 资料与本地适配

[S04玩家属性表](https://www.taptap.cn/moment/15213091339897518)第一张第44行给出一费、傀儡/刺杀、550生命、80–113攻击、5护甲、射程1、1.8秒间隔和5秒技能冷却。[S41的2019-05-10攻略与客户端截图](https://www.8090.com/news/gonglue/article_328648.html)说明“飞斧”对单个敌人造成300/500/700技能伤害并短暂眩晕。资料日期不同，不能据此宣称统一官方版本已完整复原。

普攻取区间均值后四舍五入为97，间隔适配0.25秒步长为1.75秒，生命/攻击仍每星翻倍。飞斧保持300/500/700，不随普攻翻倍。技能射程3格、0.5秒眩晕、魔法伤害、初始能量0、满能量100及具体交互边界为本地适配；史料未给这些字段。结构化字段与来源截图哈希见 [axethrall-history.json](../research/axethrall-history.json)。

## 战斗和运营

斧奴保持近战普攻，满能量且冷却结束时，可在曼哈顿3格内向当前最近的可见敌人投掷飞斧。沿用行动节奏：普通攻击间隔尚未结束时不会插入技能。技能按当前技能强度放大，正常结算法抗、护盾和反伤，不触发普攻吸血或破甲。眩晕可打断敌方持续技能，不缩短已有更长控制；残魂免疫本次伤害和控制，阵亡或化蛋不追加眩晕。

5秒冷却从施放时开始，期间可移动、普通攻击和恢复能量。眩晕、沉默、魅惑、阵亡、目标死亡/友方/隐蔽/超出范围时不施放，不消耗能量。伤害与控制即时结算，旋转飞斧、斜劈和回充标签属于表现，不产生额外命中。普通攻击与技能有不同的身体倾转幅度，配合独立月牙斧轨迹和刃击音色。

一费有限卡池沿用45份，普通三合一、出售返池与AI购买部署均接入；傀儡禁用时整局不出现斧奴。AI按实际300/500/700相对于同星普攻的比例估计技能贡献，不误认为技能也逐星翻倍。低费刺杀仍易被后排集火，升星和落点重要，不额外给予生存特权。

schema30→31仅补缺失斧奴卡池：允许招募时45份，禁用傀儡时0份。已有禁用组合、商店、阵容、金币、生命、装备、AI偏好、战斗版本、历史与播放位置不变；早于0.31的完整卡池旧局仍保持完整卡池。prepare/battle/result/finished的两类迁移共8种场景精确核对。
