# 0.7 兵种触发机制

当前规则为 `singleplayer-0.7`，战斗版本为 `signature`。触发条件集中在 `src/engine/triggers.ts`，技能执行、目标选择和图鉴说明分别接入现有模块。

| 棋子 | 当前实现 |
|---|---|
| 马骑兵 | 首次满足行动条件时冲锋，每场一次；路径受阻保留机会，不使用能量 |
| 玄龟 | 首次行动获得 12 点额外护甲，按星级在 8/12/16 秒内线性衰减；每场一次，与其他护甲强化相加，不使用能量 |
| 落箭虎 | 第 1、5、9……次攻击触发箭雨；攻速影响触发间隔，金色进度条显示攻击循环，不使用能量 |
| 灵鱼 | 曼哈顿距离 1 内有存活的非灵鱼友军时隐蔽，不能成为普通攻击目标；敌方灵鱼在距离 3 内可反隐，范围伤害仍可命中；治疗驱散继续使用能量 |

这些机制参考已收集的 2019 年攻略资料，见 [研究来源](../research/sources.json)。邻接距离、反隐距离、护甲数值及伤害系数属于本项目的单机设计；落箭虎采用第 1/5/9 次攻击的解释。灵鱼没有复原持续净化，仍使用主动治疗驱散，不能将本配置视为原作完整历史数值。

AI 装备评分不再为上述三种非能量棋子的回蓝属性加分，也不为玄龟的技能强度属性加分。战场显示玄甲剩余护甲、箭雨循环及隐蔽状态；旧战斗的棋子详情保留对应旧规则。

存档升为 schema 6，准备阶段启用新规则，进行中的旧战斗和历史回放保留原规则，见 [迁移说明](persistence.md)。

## 验证

新增 11 项触发模块测试，覆盖一次性技能、受阻重试、三星衰减护甲、攻速与箭雨、隐蔽与反隐、范围伤害、装备评分、快速计算一致性、三代旧规则快照及存档迁移。提交前运行触发、后台计算和视觉三个模块，共 26 项通过；TypeScript 检查和 Vite 生产构建通过。未运行全量测试。
