# 火焰兵与投弹手 / singleplayer-0.20

新增二费火焰兵（步兵/先锋）及四费投弹手（步兵/异能），当前49种可招募棋子、18近战/31远程、22类羁绊。两枚均有独立生成形象、普通攻击动作、技能效果、音效与AI估值。加入六步兵档位，不改变已有二/三步兵收益。原型中的神射手身份仍未核实，不将当前六步兵称为完整还原历史六步兵。

## 资料边界

[S20发行方种族表](https://game.xiaomi.com/viewpoint/1103968488_1556086391745_13)及[S25职业表](https://wap.gamersky.com/sygl/Content-1179303.html)确认两枚棋子的名称与分类。[S30四/五费盘点](https://news.17173.com/z/zzq/content/05272019/180953197.shtml?_platform=PC)描述投弹手的范围伤害与沉默、克制技能阵容的定位。

[S33官方公众号转载的2020年3月更新](https://news.17173.com/z/zzq/content/03202020/143602197.shtml?_platform=PC)记录火焰兵的“火龙爆射”名称；这是更晚版本，不作为2019年基础属性、范围或灼烧机制的证明。火焰兵当前锥形加持续伤害、投弹手九宫格范围、所有倍率/时长/费用/基础数值均作为本项目配置公开，不拼接为官方同版本数值表。

## 技能规则

| 项目 | 火焰兵 | 投弹手 |
|---|---|---|
| 费用/卡池 | 2金/30份 | 4金/15份 |
| 一星属性 | 820生命、44攻击、4护甲、射程2 | 850生命、66攻击、3护甲、射程4 |
| 普攻间隔/初始能量 | 1秒/25 | 1秒/50 |
| 主动技能 | 火龙爆射 | 高爆榴弹 |
| 直接伤害 | 200%攻击法伤 | 200%攻击法伤 |
| 范围 | 朝向当前敌人的锥形，最远3格 | 当前敌人所在格及周围九宫格 |
| 后续效果 | 1秒后开始，每秒35%攻击法伤，共3次 | 沉默2/3/4秒，按星级 |

喷焰范围使用目标方向的单位向量，前向投影>0且≤3、侧向距离≤min(1.5,前向距离×0.65)，裁剪至8×8棋盘；正向共7格，斜向按实际朝向判断。战斗和范围特效复用同一函数，八个方向均可命中近距离主目标，不会因为横向优先规则漏掉斜角。

灼烧按施法时攻击与技能强度锁定，后续装备增益不追溯。每次结算使用目标当前防御，护盾先吸收，不朽残魂免伤。同一施法者刷新自己的灼烧、不同施法者可叠加；已附着的灼烧在施法者死亡、目标移动或随后改变阵营后仍持续。阵亡目标不再结算，涅槃化蛋清空旧灼烧列表；同一步其他火焰兵的旧灼烧不能伤害新火种或把列表写回。反伤导致喷焰者阵亡后，不再处理本次喷焰其余目标；已附着的灼烧保留。

沉默是独立状态：不清空或封锁能量，仍能移动、普攻和回能；阻止新的能量技能，并立即取消主动引导/蓄力。马骑兵、玄龟等开场被动和落箭虎攻击循环不受影响，血鹰已开始的普通连击不会被当作主动技能取消。重复沉默刷新至较晚结束时点，不累加持续时间；到期恢复，灵鱼可驱散，涅槃化蛋清除。火种不接受沉默。

## 阵容与AI

当前步兵梯度是2/3/6种分别+200/300/600生命，采用最高档效果，不叠加；不同名字计数，备战棋子不参与。六步兵以神枪手、盾兵、神射手、军医、火焰兵、投弹手组成。保留三步兵是本项目现行平衡，**与S20的2/4/6并不相同**，不宣称历史梯度已经复原。

0.19最多四种步兵，因此新增六步兵档不会改变旧阵容回放；继续沿用metamorph，不伪装迁移旧战斗。后续若改动旧三步兵或其他已有分类/伤害，需要另立战斗版本。

火焰兵计作近线保护单位并优先前排落位，避免射程2被统一放到最后一排；技能估值计入有限目标及两次灼烧。投弹手按范围法伤与沉默时长提供有界技能价值，能量/技能装备参与评分。没有增加金币、卡池或战斗属性优待。默认十对十演示加入新兵种和神射手，左方实际可达六步兵。

## 资产与表现

火焰兵普攻压肩横扫、短距离橙色火流；投弹手后仰扬臂、紫色榴弹高抛及冲击环。技能范围有棋格高亮，灼烧有橙色火舌与状态标签，沉默使用紫色反馈与状态文字。低动态模式保留技能文字。

内置image_gen生成两张全身透明PNG，原件保留、直接复制入项目，未用程序抠图。火焰兵1200×1310，完全透明像素763879；投弹手1199×1312，完全透明像素1087409，右下角单像素alpha为1，其余角为0，页面无矩形底色。完整提示词、来源路径和SHA-256见[资产清单](../research/infantry-assets.json)，总资产清单已收录。生成形象不等于原作模型。
