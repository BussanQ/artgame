# 0.41 野兽攻速与先锋护甲

0.43已按逐档范围修正累计：六野兽自身75%、其他友军60%，六先锋14护甲；证据与边界见[连携累计](formation-stacking.md)。本页保留0.41最高档规则和当时采样，供旧回放对照。

0.42穿山甲已改为刺杀，为保持当前“荒原先锋”八格六野兽/六先锋演示，原穿山甲位置改用牛魔。下面的0.41记录对应旧版本与修改前阵容，继续用于历史回放。新增S50的累计说明及混期配图仍需逐字段审计，本节的最高档规则不是已证实的原版全量累计配置。

此前野兽只有2/3档固定缩短攻击间隔，先锋只有两名成员时增加生命和回血。恢复的五月资料提供了更完整的收集路线：野兽2/4/6档逐步从本族增速扩展到全军，先锋3/6档增加护甲。本轮将两种效果接入真实战斗、召唤继承、AI、图鉴、禁用可达性和存档版本。

## 原始证据与版本边界

重新取得并目视核对[S03五月九日更新图](https://www.taptap.cn/moment/15202528882852517)，图片SHA与原记录一致。野兽栏后两档的25%/35%指全队**攻速**，旧结构化转录漏了“速度”二字，已更正。[S35五月九日公告](https://www.taptap.cn/moment/15209355339104422?group_id=42979)正文确认四野兽起对全体友军生效，并将先锋回血改成护甲6/8；未核验作者官方账号标识，不提升来源等级。

[S20发行方四月资料](https://game.xiaomi.com/viewpoint/1103968488_1556086391745_13)写的是10/10/15%本族攻速，属于较早切片。本轮选用五月表，不将两者合并。完整事实、指纹和本地选择见[研究记录](../research/wildfront-history.json)。

| 羁绊 | 不同上场成员 | 当前效果 |
|---|---|---|
| 野兽 | 2–3 | 野兽攻速 +15% |
| 野兽 | 4–5 | 全队攻速 +25% |
| 野兽 | 6及以上 | 全队攻速 +35% |

取最高档总量，不把15+25+35或6+8相加；历史材料没有充分证明累计方式，此为公开的单机选择。同名不同星级只计一种，备战席和后生召唤物不凑人数。先锋不再由该羁绊额外获得100生命或每秒32回血，装甲再生、技能治疗和装备保持各自效果。

## 攻速、召唤与状态

攻速是攻击频率的百分比，不能直接把35%当作减少35%的间隔。装备调整后的基础间隔除以`1 + 羁绊攻速 + 棍奴疾风攻速`，再应用已有临时加速与减速，最低一战斗步。模拟步长0.25秒，实际出手时点存在离散化；该公式、最低间隔及与其他加速的结合为本地适配。

四/六档对非野兽、空中友军以及后续生成的幼狼、灵木傀儡和镇海盾卫生效，不复制主人攻速装备。两野兽个人增速不传给召唤物；召唤物不继承先锋护甲。开战时锁定的团队增速不会因为提供者阵亡而消失，血鹰变身、不死鸟化蛋重生保留增速；魅惑沿用已有开战属性规则。

棍奴更换或失去目标时清空疾风，剩余攻击冷却按失去的疾风速度比例恢复，保留野兽全队增速，避免将两种加速一起清空。战斗状态显示“野兽攻速”或“全军攻速”，图鉴、棋子详情和禁用面板按当前局的战斗版本显示档位。

AI在既有档位和组合搜索之外，对个人/全队攻速及本族护甲计算有上限的团队收益，能够保留可达档位候选；不获得额外金币、棋子或属性。“荒原先锋”八对八演示使用正常二/三星和最多三件装备，己方八枚棋子形成六野兽、六先锋，展示击飞、酸蚀、疾风、变身与后续幼狼，无预设胜负。

规则为`singleplayer-0.41`、schema40，新增战斗版本`wildfront`。schema39/0.40仅在准备阶段切换；战斗、结算、终局及历史记录继续使用原版本，下一轮准备再更新。金币、生命、商店、卡池、棋子、装备、禁用、AI风格、随机数和播放状态不改写。

旧`puppets`继续保留野兽2/3档固定减间隔和先锋两名时的生命/回复，避免更新改变在途战果。此次修改前已冻结22组0.40逐帧回放，新增两组专门覆盖旧野兽和先锋；不在修改之后重算期望哈希。

额外用正常一星穿山甲、长生鹿和无主动控制的棍奴验证连续普攻：无野兽增速时，穿山甲前四次普通攻击在tick3/6/9/12；两野兽15%时为tick3/6/9/11。引擎保留每次冷却的小数余量，增速能实际改变出手时点，不会每次向上舍整后完全失效。
