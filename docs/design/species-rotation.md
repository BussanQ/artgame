# 0.31 每局随机禁用三个种族系列

0.46按原图补入骑兵，共13个种族随机禁3个；骑兵禁用同时移除鸟骑兵与摩托。当前286组合均满足费用、前排、输出和多条构筑条件。允许残留职业暂未达到第一档，继续标记不可达档位；不因三召唤门槛把大量可用棋子和合理组合排除。已存禁用不重抽，详见[空援协同](coalitions.md)。下面保留0.31最初12系列及更严格筛选的历史方案。

按用户选择，每场新比赛由系统随机禁用三个不同的种族系列，玩家无需手选。禁用在开局商店生成前确定，玩家和七名 AI 共用，整个比赛不再更换。此机制是本项目的玩法扩展，不作为原版历史规则陈述。

## 关联与抽样

候选为步兵、装甲、野兽、熊猫、傀儡、异虫、空军、海神、不朽、灵能、猛禽、陆行者十二类。护卫、狙击、刺杀等职业不直接禁用，仍可连接不同种族。双种族棋子命中任一禁用系列便退出本局招募池，关联职业也随之减少可用成员。

从全部三种族组合中筛选能正常运营的组合，再按独立种子随机抽取：至少保留30种棋子、6种近战、8种远程；1–5费至少分别保留4/3/3/3/2种，且有一费近战。每个仍有成员的职业至少能组成最低羁绊档。独立抽样不消耗商店随机流，同种子得到相同禁用。不同种族的边际禁用概率不保证相等，因为组合经过可玩性筛选。

部分未被直接禁用的种族、高档职业羁绊仍可能因为关联成员被移除而无法凑齐。禁用详情和图鉴会明确标注这些档位，不悄悄降低羁绊要求。1000个种子的检查中，剩余棋子为33–46种；这不是永久固定区间，后续兵种调整会改变结果。

## 卡池与概率

禁用棋子剩余份数为零，不出现在任何玩家商店，也不能通过购买接口进入阵容。可用棋子的初始份数、各等级费用档概率、刷新价格、普通三合一与异虫进化规则均不变。锁店、出售、淘汰返池继续遵循共享有限卡池守恒。

同费棋子初始份数相同时，某张可用棋子在该费用档中的占比从 `1 / 原候选数` 增加为 `1 / 剩余候选数`。实际每格概率还要乘费用档权重，并按当前剩余份数分配；其他七人的商店和持有也会占用卡池。费用档耗尽时沿用原有剩余权重归一化。因此卡池收缩增加同名获取机会，但不直接提高商店星级，也不保证某个阵容一定升到三星。

AI从首要核心羁绊至少还有两种可用棋子的风格中分配，候选不足七种时允许重复偏好。野怪、召唤物、战斗演示不受招募禁用影响。

## 页面与存档

- 主页面显示本局三个禁用系列与剩余棋子数，展开后可查看被移除棋子、同费初始占比变化、受影响羁绊及可达档位。
- 图鉴增加全部棋子、本局可招募、本局禁用筛选；禁用棋子保留参考说明和明确标记。
- `Game.bannedSeries` 随存档与 Worker 状态传递，刷新页面、战后结算、下一轮不会重新抽取。
- schema30 / singleplayer-0.31 接续 schema29。旧比赛仅迁移封套，继续完整卡池，不删除已买棋子、不改商店、不改历史回放；新开比赛才启用禁用。
- 内部 `createGame(seed, "classic")` 仅供历史测试和对照采样使用，页面默认均为随机禁用模式。

## 正常经济配对采样

执行 `npm run survey:rotation`，六个种子、三档难度、完整卡池与随机禁用各18局，共36局908回合，逐轮校验状态与卡池。每对比赛的代理指挥官使用同一个可用风格、标准经济策略，所有购买、经验、刷新和装备奖励遵循正常流程。原始记录与14个源码SHA-256见 [rotation-v031.json](../analysis/rotation-v031.json)。

| 指标 | 完整卡池 | 随机禁用 |
|---|---:|---:|
| 出现三星的比赛 | 6/18 | 12/18 |
| 每局累计三星棋子均值 | 0.72 | 1.17 |
| 首次三星平均回合（仅已出现三星的比赛） | 17.33 | 13.08 |
| 平均最终名次 | 4.22 | 3.89 |

三星按不同棋子UID累计，出售后仍计入本局已获得数量。首次三星均值来自不同大小的成功子样本，不能解释为每位玩家固定提前4.25回合。卡池改变也会改变随机选择和AI风格分配；这只是小样本代理策略对照，不是人类胜率或全局平衡结论。最终难度和长局体验仍需后续验证。
