# 0.50 摩托骑兵焦油弹

2026-11-06。仍为63种棋子，本轮将摩托骑兵从三连发推进到延迟范围爆破，加入黏附倒计时、分批投弹、死亡落弹和打断交互。独立 `tar` 战斗版本保留历史；本轮不宣称完整同版本复原。[研究记录](../research/tar-history.json)区分原文与适配。

## 来源与采用值

[5月30日官方署名公告S38](https://news.17173.com/z/zzq/content/05302019/085535417.shtml?_platform=PC)确认焦油弹名称、1/2/3个目标和3秒倒计时。[6月13日公告S53](https://news.17173.com/z/zzq/content/06132019/183201371.shtml)给出溅射80→120，以及摩托生命和攻击区间。S53的Web缓存含第三方AI摘要提示，本轮另取无参数原始HTML核对正文并保留SHA-256，未将AI摘要当原始依据。

公告未给中心伤害和完整黏附边界，采用值如下：

| 项目 | 当前规则及依据 |
|---|---|
| 目标 / 延迟 | 一/二/三星最多1/2/3名不同敌人；每枚投放后3秒引爆 |
| 投放 / 冷却 | 首枚0.5秒后，此后每0.5秒一枚；冷却10秒从施法开始计。10秒沿用既有表格，投放节奏为本地配置 |
| 中心伤害 | 300/400/500法伤，单机暂定值，未恢复到原版参数 |
| 邻格伤害 | 120；数值来自六月公告，所有星级应用、法伤分类及曼哈顿一格为本地适配 |
| 身板 | 沿用0.21校准的750生命、72攻击、1秒普攻、5甲、3格；不将其称为原表500生命、55–60攻击、1.5秒 |
| 黏附 | 跟随活目标移动，真正阵亡后留在最后位置，同UID复活不重新黏附；这是对粘性与脚下计时的本地解释 |
| 阵营 | 爆炸时按施法者当前阵营判敌，魅惑会改变后续敌我关系 |

五月技能、六月公告、七月测量表和单机平衡字段分别保留，没有混写成统一客户端配置。复用既有内置ImageGen摩托形象，[资产记录](../research/motorcycle-assets.json)保持，本轮未重新生成或编辑位图。

## 真实结算与表现

每发重新选取三格内可见、尚未被本次施法选过的敌人，按距离和UID排序。目标不足就停止余弹，不重复向同一目标补满；能量不足、冷却中、被控制或没有合法目标时不开始施法。

投放期间不能普攻和移动。眩晕、沉默、魅惑、阵亡取消未投出的弹，保留已消耗能量和冷却；已黏附的弹继续倒计时，施法者死亡后仍能引爆。单方全灭已经结束战斗时，不延后结算等炸弹。

伤害和技能强度在施法时固定。爆炸按当时位置、阵营、护盾、技能减伤、免伤、反伤和攻城直接伤害规则结算；同次反伤击杀施法者不会把已经提交的爆炸取消一半。范围可伤隐蔽和飞行敌人，不附带减速或灼烧。分散站位能减少被黏附单位附近的溅射。

临时炸弹保存在战斗快照，永久棋子不携带残留。完整模拟、快速结算和Worker使用同一生命周期。AI按有上限的首次施法估计计入能力，允许目标死亡、射程不足和打断，不预读战果或强制发牌。

菜单新增“焦油爆破”六对六演示，投放有抛射轨迹、弹药指示和音效，爆炸显示橙色脉冲。预警在单位下方、倒计时在上方，避免被形象遮挡；同阵营在同一目标上的多弹合并显示弹数及最早爆炸时间，减少动态效果时仍保留计时。图鉴、完整战场详情和贡献分析接入新名称与定位，分析显示投弹/引爆数且只统计已播放部分。旧规则继续显示三连发。

## 从失败采样改进

初版同时采用原表身板和固定落点，12局309回合没有玩家代理部署摩托；9组含摩托的冻结对阵只产生1次中心伤害事件。保留[初版装甲](../analysis/tar-v050-initial-armor.json)、[舰队](../analysis/tar-v050-initial-fleet.json)和[受控对阵](../analysis/tar-v050-initial-combat.json)，不当作当前结果。

最终保留已有单机身板，采用黏附移动，仍保留延迟、控制打断与分散反制。两项因素同时变化，未做单变量实验，不能把全部差异归于其中一项。

玩家使用标准代理，正式对手使用相应难度，均遵守正常付费交易与共享池。两种子不等于12个独立种子，也不是人类胜率。标准代理名次回落，不能宣称整体难度改善；本轮结果是增加构筑机制并保持自然使用。
