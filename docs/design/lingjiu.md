# 0.40 灵鹫与海神刺杀

0.42刺杀改为3/6档职业暴击，并将起跳与连携人数分开：单名灵鹫也可跳后排，技能本身不暴击；三格普攻和近身音波保持各自范围。以下保留0.40首次接入时的规则及验证记录，当前变化见[刺杀](assassins.md)。

新增二费远程灵鹫，海神 / 刺杀，飞行海兽，生命550、攻击101、护甲0、射程3格、攻击间隔2秒。当前63种可招募棋子，27近战 / 36远程；四月53名基线都有同名或明确本地设计对应，仍有9项分类差异。这是名单缺口补齐，不代表属性、技能、羁绊和版本已经全部复原。

## 来源和版本边界

S04七月测量表记录96–105攻击、550生命、0护甲、3格射程、2秒间隔和6秒技能冷却；攻击取四舍五入中值101。S20四月海神图鉴原图本轮取得有效JPEG并实际查看，确认浅色分节腹部、尖角和紫色鳍翼的海兽形象，未按普通猛禽设计。

[S48 2020年7月30日公告](https://news.17173.com/z/zzq/content/07302020/182340097.shtml?_platform=PC)明确“死魂曲”伤害150/250/350改为200/300/400。当前选用后者作为标明日期的适配，不把2020参数冒充2019原始值。S46五月表的索引与该值相同，但原图未取得，不能据此消除日期差异。完整字段、图片指纹和未核实项见[研究记录](../research/lingjiu-history.json)。

## 战斗行为

初始25能量，满能量、冷却结束、1.5格圆形范围内有可见敌人时，以自身为中心释放一次音波，造成200/300/400法术伤害，受技能强度加成。圆形按欧氏距离，包含斜邻格，排除两格直线目标；范围及中心为本地适配，1.5不是已验证的历史单位换算。

技能覆盖圆内全体敌人，含隐蔽及飞行单位，不影响友军；没有额外控制、减甲或持续伤害。每名敌人单独经过技能免伤、法防、护盾、反伤与生命结算，主命中只标记一名合法敌人；反伤使施法者阵亡时停止后续命中。效果几何与战场绘制共用同一个函数。

圆内可见敌人按欧氏距离和UID确定主命中锚点，避免普通选敌的曼哈顿同距排序选择圆外目标后错误地阻止施放。圆内无可见敌人时保留能量，仍可3格普通攻击。眩晕、沉默、魅惑、阵亡、能量不足或冷却未结束均不施放、不扣能量；冷却6秒从施放时计，期间可正常移动、普攻与回能。

灵鹫接受现有空军对飞行友军的闪避、海神回能，但不获得额外空军或猛禽种族。音波多目标生命伤害每个战斗步只触发一次海神额外回能，不能按命中人数重复赠能。开场跳后排沿用当前两刺杀规则。初始能量、伤害类型、近身触发和这些边界均为本地规则；本轮没有重做全局行动节拍。

## 表现、AI和存档

新增展鳍俯身鸣击、普通攻击的弯曲音刃和技能的紫色同心音波，冷却显示回充时间；减少动态效果时保留技能名称和状态。形象通过内置ImageGen生成，原始RGBA透明通道保留，提示词与最终路径见[资产记录](../research/lingjiu-assets.json)。

现有海神/刺杀策略自动纳入灵鹫，AI按约1.6个目标估计一次技能价值，不假设全体敌人都被覆盖。回能、技能强度、攻速、生命等装备通过现有真实属性参与估值。正常招募仍付费，三合一升星、共享卡池和本局禁用没有例外。

规则`singleplayer-0.40`、schema39，战斗版本继续`puppets`。schema38只补缺失灵鹫卡池30份，海神被禁用则为零；已存在的池不重复追加。经济、阵容、商店、装备、随机数、AI风格、历史与播放原样保留，战斗恢复不重新进行AI准备。
