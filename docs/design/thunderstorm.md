# 天师雷暴（0.53）

天师由三费原型范围雷球改为一费穿行削能单位。新局45份共享卡池，400生命、40攻击、5甲、4格射程、1.1秒攻击间隔；一/二/三星雷暴伤害150/250/350，沿一格宽的固定路径飞行，受损敌人最多减少20能量。独立蓄力动作、路径预告、逐帧光球、削能浮字、图鉴、实际战斗统计及菜单“雷暴削能”六对六演示均已接入。装备工坊保留用户最新要求的左侧位置，阵容连携位于下方信息区。

## 史料与适配

[S55发行方署名文章与内嵌客户端卡](https://news.17173.com/z/zzq/content/12182019/120501054.shtml)确认一费、雷暴、伤害150/250/350、宽1格、20削能和5秒冷却。已实际目视清晰的客户端原图，伤害梯度与宽度不是估算。[S04玩家测量表](https://www.taptap.cn/moment/15213091339897518)第39行提供身板及5/4/3秒冷却，36–44攻击取均值40。原图归档、字段、SHA和读取限制见[研究记录](../research/thunderstorm-history.json)。

[S56文章内嵌的客户端角色图](https://news.17173.com/z/zzq/content/12032019/183708432.shtml)显示尖顶头盔、宽肩甲、裸露蓝色晶核、金属爪臂和悬浮分节下身，没有原型的白须人脸。其二手攻略提到蓄力、弹道难命中和命中后大量回能；自回能的数值与公式没有原始客户端字段证明，未新增无依据的能量转移。

七月测量与十二月配图没有被认定为同一客户端。初始能量0、1秒前摇、每秒3格球速、最多10格、法伤分类、星级生命/攻击翻倍、碰撞与控制边界均为明确公开的单机适配。童子三星供能末位仍被原卡遮挡，暂定10的缺口没有因此解决。

## 战斗与表现

- 起手需要满能量、冷却结束、4格内有可见敌人。蓄力时锁定目标当前方向，消耗能量并开始5/4/3秒冷却。蓄力期间不能移动或普通攻击；眩晕、沉默、魅惑、阵亡取消尚未发出的球，不退款。
- 球按真实战斗tick前进，采用半径0.5格的扫掠碰撞，避免跨帧漏过单位。敌人可以移动避开固定方向；每球每UID最多接触一次，友军不受影响，范围能接触隐蔽与飞行敌人。
- 发射时固定阵营，施法时固定伤害强度。已发出的球不因天师死亡、控制或变阵营而消失；不会追踪改道。最后一方清空后战斗结束，未完成蓄力和剩余球不在战后补伤害。
- 伤害与护盾先结算，再从目标现有能量中扣最多20。实际生命或护盾受损才削能；免伤、死亡、残魂、火种与无能量棋子不扣，不生成负能量，不放大20点，不封锁后续回能。正常普攻、受击、福音回能继续采用单机规则。
- 胸前晶核聚能、前倾推波、回收姿态独立于旧拂袖动作。地面预告与扫掠采用同一宽度；蓝色光球的位置来自真实战斗帧。插值只影响画面，不推进结算；减少动态模式保留按帧更新的光球与静态提示。
- 战斗详情和双方分析分别列出施法次数、已发球数、路径接触次数和实际削能。施法可能被打断或在胜负已定时未释放，接触可能遇免伤或空能量，不能把这些计数当作相同指标。零时刻不带未来数据。

新形象由内置ImageGen生成，原输出透明通道直接复制到`public/assets/units/stormcaller-thunderstorm.png`。完整提示词、生成输出、尺寸和SHA见[资产记录](../research/thunderstorm-assets.json)，已并入总资产清单。旧`stormcaller.png`保留；原作图片仅作研究参考，没有成为正式运行资产。

AI与推荐选阵按当前身板、星级技能伤害和削能价值估价，并对覆盖/打断/躲避做有限折扣。估价不赋予战斗加成，也不证明后排位置或阵容已最优；所有购买、追星与升级继续付费。

## 兼容与验证

战斗版本`thunderstorm`继承福音及此前规则，schema51→52仅准备期升级。50→51固定`gospel`/0.52字面值；在途战斗、结算、终局和历史继续旧版本，下一准备期再升级。整局价格目录独立冻结：旧局仍三费25份，新局一费45份。资源、阵容、商店、随机数、装备和播放位置不重置。旧战斗保留700生命、65攻击、3甲、3格、1秒普攻、旧范围雷球和人形。

必要的11个模块共360个不同用例通过，包含111组改动前0.52完整逐帧SHA一致、三档伤害/冷却、扫掠宽度、路径穿透、移动避让、控制打断、死亡后弹道、实际削能/免伤/护盾、施法强度快照、非法目标不消费、一费实际买卖与45份守恒、两代四阶段迁移、快速结算/Worker和片段分析。命令为`npm run test:thunderstorm`；TypeScript/Vite构建与差异空白检查另行通过，未运行全量测试。

标准付费代理，两组种子/偏好（173灵能、311装甲）各比较完整/随机禁用卡池与三档对手：0.52为12局300回合，0.53为12局313回合，逐轮准备/结算合法。新规则8局自然部署天师，共95轮，星级轮数3/85/7，135次施法、120个发球、125次接触、实际削能1480；遇到的AI天师7轮、13个发球、14次接触、削能150。不含全部AI内战。
