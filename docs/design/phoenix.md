# 不死鸟 / singleplayer-0.17

新增四费不死鸟：主动定向喷火与二星起的被动化蛋重生，补充后排持续输出与可集火反制的第二条生命。当前 45 种棋子、22 类羁绊、18 近战 / 27 远程。商店、卡池、AI、图鉴、备战详情、战报及“猛禽陆行演示”共用同一配置。

四费、1000 基础生命、85 攻击、4 护甲、射程 3、普攻间隔 1 秒、初始能量 25，以及下文的伤害倍率、范围格数、孵化时间和每战一次限制均为自主单机配置。蛋生命 800/1600 采用 S27 的文字方向；该文章属性段存在其他棋子名称笔误，未直接采入其完整属性。

## 燎原

满能量且能行动时，朝当前目标的主要坐标轴方向锁定前方 5 格长、3 格宽的矩形，越界部分裁剪；不包括自身所在行或列。对角方向以纵轴打破平局。施法时冻结方向、起点、攻击力及技能强度，目标后续走位不会改变矩形。

施法后第 1、2、3、4 秒各结算一次，每段 90% 施法时攻击力乘技能强度的魔法伤害。每段重新检查敌方当前占位，未处于区域内的敌人不受伤；每次按共享护盾、魔法减伤、不朽和灵能反伤规则结算。

引导期间不移动、普攻或再次施法，普通攻击冷却继续流逝；眩晕、魅惑、阵亡立即取消剩余段数，不返还能量。如果在一段多目标喷火中被反伤打成火种，立即停止该段剩余目标，不利用新生命继续攻击。范围预告与特效直接使用引擎的同一格子集合，避免显示范围与伤害范围不一致。

## 涅槃

- 一星正常死亡。二/三星首次致死时在原格转为地面火种，分别具有 800/1600 最大生命；过量伤害不在同一次命中里穿透第二条生命。UID、星级和占位保持不变。
- 清除当前引导、负面持续伤害、减速、破甲、眩晕和封能；魅惑解除并回归原队伍。火种不能移动、攻击、施法、回能、治疗、加盾或自然再生，不能再次被蜘蛛魅惑。
- 火种可被普攻与技能选中，保留本体护甲、魔法防御和装备防御。飞行关闭，因此不再享受空军闪避；巨神炮对空额外伤害不生效，敌方猛禽对地伤害生效。既有非飞行队伍效果依旧适用。
- 化蛋 12 tick（3 秒）后，若仍存活，恢复本体最大生命、飞行属性和零能量；生命装备仍生效。恢复不计作治疗，战报保留累计实际承伤。每场只化蛋一次，重生后的第二次死亡不能再次化蛋。
- 火种被击碎后永久死亡，不会在计时结束时复活。火种存活时仍算本方存活单位，避免最后一枚火种被提前判负；仍占据原格，不允许其他棋子重叠落位。
- 战斗若已结束不为剩余孵化等待额外时间；胜方火种按原棋子星级计算一次存活扣血，没有额外生成一个持久棋子。40 秒战斗上限仍适用。

生命周期在 src/engine/phoenix.ts。形态与计时只存在于战斗快照，由确定性模拟重建，不写回持久阵容或卡池。

## 表现与信息

内置 ImageGen 生成不死鸟和涅槃火种两张透明形象，凤凰主体另做一次去除背景光晕的编辑。文件位于 public/assets/units/phoenix.png 与 public/assets/units/phoenix-egg.png；完整提示词见 [资产清单](../research/phoenix-assets.json)。

普攻为扬翼、抬身、甩出弧线焰羽；持续技能使用固定棋格预告与火焰脉冲，化蛋和重生使用独立光环与名称。火种无攻击姿势，状态显示孵化倒计时；战斗分析更换头像并标记“涅槃火种”或“已重生”。减少动态效果保留静态形态、范围和文字，不以动画触发伤害。

现有猛禽陆行演示以不死鸟替换盾兵，并交换翔龙和不死鸟位置。该阵容能展示一次喷火与破蛋失败，并非保证获胜或保证重生的教学配置。成功孵化及最后一枚火种继续战斗另由确定性完整战斗验证。
