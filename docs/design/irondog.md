# 0.24 铁狗：低费装甲前排与分段控制

规则 `singleplayer-0.24`，schema23，继续使用 `infantry` 战斗版本。新增可招募铁狗，51种棋子、19近战/32远程；四月53名基线已有41项同名或本地映射，缺12项。历史名称对应不等于整套玩法复原。

S05/S18为玩家分析、不同时间切片，不能拼成官方精确技能表。未找回可靠的完整技能名、分星伤害、初始能量、作用范围和打断参数。本项目技能名“震荡压制”及以下参数为明确的单机适配，不标成原版数值。未将经典RTS的“战术铁狗”“穿甲铁狗”技能混入自走棋。

## 配置和实际行为

| 项目 | 实现 |
|---|---|
| 费用/分类 | 1金，装甲/爆破 |
| 生命/普攻 | 700/36；36为史料32–39均值四舍五入，生命攻击每星翻倍 |
| 护甲 | 一/二/三星5/7/9，另加装备和羁绊 |
| 普攻 | 近战1格，间隔1秒，初始25能量 |
| 主动 | 满100能量、有相邻可见敌人且冷却结束时原地引导 |
| 震荡 | 0.5秒后首发，之后每0.75秒一次，共3次；每次命中自身周围曼哈顿1格所有敌人 |
| 单次伤害 | 70/140/280法伤，按施法时技能强度快照，不随随后攻击增益变化 |
| 控制 | 每次命中短眩晕0.25秒；使用引擎的“命中步+下一完整战斗步”计时，下一次脉冲前留一战斗步行动窗口 |
| 冷却 | 10秒，从施放时开始计时；回充期间可正常普攻、回能 |

每次震荡重查敌方阵营、存活状态与距离，不绑定原先目标；新靠近的敌人也能被命中。范围效果可以命中隐蔽和空中单位；不能以隐蔽目标启动施法。范围里无人仍消耗次数，不无限等待。友军、阵亡、范围外不受影响。

眩晕、沉默、魅惑、阵亡立即取消剩余引导；不退能量或冷却。引导期间不移动/普攻，普攻冷却仍流逝。每个目标的伤害、护盾、免伤、反伤分别结算；致死反伤会停止该脉冲后续目标及后续脉冲。不朽残魂和涅槃火种不会被本技能眩晕；普通受害者的引导会立即被打断。三次脉冲算一次施法，战报按真实伤害事件累计。

## 跨模块集成

新增可选 `UnitDef.armorPerStar` 与 `unitArmor`，战斗建军、棋子详情、星级图鉴、AI单体与前排估值使用同一永久护甲公式。旧兵种没有此字段，护甲成长不变。装备选择将铁狗识别为前排，技能估值按两次脉冲、平均1.5目标保守计分。

沿用已有可中断施法状态，新增irondog类型与独立分支，旧棋子不创建该类型。schema22→23仅增加铁狗45份共享卡池，不改变金币、商店、当前阵容、装备、战报、战斗版本与播放状态；schema21→22固定写入0.23，再顺序迁移，避免跳过旧版本。

近战动作“液压前扑钳咬”包含压身、前扑和钳口闭合轨迹；震荡用金色脉冲和真实一格范围预警，显示剩余次数及回充计时。脉冲音效独立触发。十对十演示以二星铁狗替换忍者熊猫的位置，其他主题演示保留。

## 正常经济采样

[0.24报告](../analysis/balance-irondog-v024-after.json)，种子173、7种指挥偏好、3种难度，共21局。每轮使用正常付费交易与奖励，并检查卡池、资源和占位合法。25个源文件SHA-256包含新永久护甲模块和版本常量。可参考上一轮同参数 [0.23报告](../analysis/balance-infantry-v023-after.json)，但新增卡池会改变同随机序列对应的出牌，不能把所有战果差异都归因于铁狗强度。

铁狗在玩家方20/21局、256个回合上阵，共263枚二星出场（部分回合重复上阵），后期39回合有铁狗。证明它可以通过正常经济成型并进入选阵，不等于证明最优阵容或长期平衡。三档平均名次休闲1.00、标准4.71、挑战7.29，挑战档仍过难；标准档相较上次样本也回落。21局状态均合法，平均结束25.29回合、战斗13.82秒。更多种子、难度校准及多构筑人工体验继续保留为目标缺口。
