# 罗汉气波掌：singleplayer-0.48

罗汉改用客户端卡的独立星级技能伤害和10秒冷却，并补入可打断蓄力、释放波纹、目标丢失反馈及石晶形象。玩家、AI、快速试算、Worker与历史重算共用结算。仍为63种棋子，不新增卡池条目；完整单机目标继续进行。

## 战斗行为与反馈

- 满能量、10秒冷却结束且射程内有当前可见敌人才花费能量并开始蓄力。无效目标、眩晕、沉默或魅惑时不启动技能。
- 蓄力1秒期间不能移动或普攻，原有普攻冷却继续流逝。眩晕、沉默、魅惑或阵亡会结束蓄力，不返还能量或技能冷却。
- 完成蓄力后再次确认原目标仍存活、可见、敌对且在射程内；失效显示“目标丢失”，不换目标。合法时释放气波掌，按蓄力开始时技能强度计算固定星级法伤。
- 攻击力和临时攻击强化不提高技能伤害。陆行者只改变普攻伤害类型；气波掌仍走法术防御、护盾、免疫和反伤入口，不触发普攻吸血。
- 技能冷却期间仍可移动、普攻和回能。技能在普通行动时机检查，所以实战两次开始时间可能超过10秒，并非精确每10秒自动施法。
- 蓄力与冷却仅存在于战斗Fighter，不写回永久棋子，下一战重新创建。

普通攻击为晶核掌击，有独立收掌蓄能、厚重前推动作与青色掌波；技能用更强的推出姿态及三重能量弧。技能释放不再叠画一发通用远程弹，避免双重弹道。蓄力、释放对应不同声音时机，打断或目标丢失不播放释放光束。

固定战斗详情显示“晶核蓄力”和“气波掌冷却”，棋子附近仍最多两个短状态。减少动态效果保留状态文字。战斗分析增加已记录的中断与目标丢失次数；中断可能来自施法、普通蓄力或连击，不把它们统称为技能失败总数，也不反推尚未发生的事件。

同时修复完整战斗分析丢失版本标记的问题：原先空蟹贡献行会回退旧图，当前保留aurora/qi标记，使罗汉与空蟹的完整分析、战场及其他入口使用一致形象。旧回放仍按自己的版本取图。

## 浏览器验收

1440、390和320像素核对新形象、蓄力、冷却、图鉴和分析。猛禽陆行演示使用现有合法阵容及装备：二星罗汉为1100生命、320基础攻击、5护甲、2.20秒间隔；约4.8秒出现0.9秒剩余蓄力和9.9秒技能冷却，受到临时强化时实际攻击为432。5.75秒分析中已记录一次施法、359生命技能伤害及102总破盾；这些是当前阵容中的实际结果，不是卡片裸技能伤害。

详情在切换尺寸后保持固定，内容可内部滚动，标题/关闭按钮可用；390/320无水平溢出且所有可见元素仍为manipulation。三星图鉴显示2200生命、640攻击、5护甲、5格射程、2.2秒和完整技能说明。退出演示仍为第2回合、100生命、8金币、等级3且1经验、上场2/3、备战2枚、藤妖携生命核心，装甲/熊猫/海神禁用不变。
