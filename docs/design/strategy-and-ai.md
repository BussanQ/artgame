# 羁绊梯度、AI 与侦察

规则版本 singleplayer-0.6。采用单机自主平衡；当前 20 种棋子可达成全部已配置阈值，不配置暂时无法凑齐的梯度。

## 羁绊

同名只计一次，备战不参与；达到多档时只使用最高档，效果不叠加。

| 羁绊 | 阈值与效果 |
|---|---|
| 步兵 | 2：生命 +200；3：生命 +300 |
| 装甲 | 2：护甲 +3；3：护甲 +6 |
| 野兽 | 2：攻击间隔缩短 0.125 秒；3：缩短 0.3125 秒 |
| 熊猫 | 2：初始能量 +50；3：满能量且技能强度 +15% |
| 护卫 | 2：开战护盾 250；4：开战护盾 600 |
| 狙击 | 2：攻击 +15%；4：攻击 +25%，普攻破甲 2 点 / 3 秒 |
| 先锋 | 2：生命 +100，每秒恢复 32 |
| 刺杀 | 2：攻击 +20%，开战跳向敌方后排 |
| 骑兵 | 2：普攻破甲 3 点 / 3 秒 |
| 支援 | 2：支援阵亡时全体存活友军回复 200 生命 / 10 能量；3：350 / 20 |

除支援阵亡回复外，增益仅作用于对应羁绊棋子。跳跃优先敌方远程，寻找合法未占据的相邻格；没有空位时保留原位。普攻破甲不会把已有更强破甲降低。技能破甲、初始能量与装备仍按各自规则结算。

阵容面板显示当前档、计数与下一阈值；图鉴内可展开完整梯度；备战详情同步使用新说明。

## AI 决策

七位 AI 分别偏好步兵防线、幽影猎杀、荒原兽群、钢铁火线、熊猫宗师、精准齐射、不破铁壁。偏好影响购买、储蓄和阵容评分，但不是强制同一种阵容。

- 优先可升星组合、偏好兵种、能连接现有羁绊的棋子；不再只按费用购买。
- 随回合设定储蓄线，保留利息；低于等于 35 生命或第 25 回合后投入剩余金币。
- 人口升级受到目标等级、可上阵棋子数量和剩余金币限制。
- 阵容评分考虑星级战力、羁绊档位、前后排搭配与偏好。使用有宽度上限的组合搜索，不枚举全部组合。
- 站位区分近战前排、远程后排、治疗第二排与刺杀侧翼，保证不重叠。清理低价值备战并分配装备。
- 全部购买、卖出、刷新和经验操作使用与玩家相同的接口、金币和卡池；没有额外资源。

## 难度与辅助信息

首轮开战前选择休闲、标准或挑战；整局保留并存档。休闲 AI 按单体强度简单选阵，只靠自然经验升级；标准会购买经验和搜索羁绊组合；挑战额外针对当前可见对手试算最多 3 个阵容 × 2 种站位。各档不修改战斗伤害或赠送金币。详见 [战术难度校准](tactical-difficulty.md)。

战场情报提供侦察按钮，展示对手当前资源、人口、阵型、装备、激活羁绊与战略偏好。侦察不替 AI 执行准备；提示开战前 AI 仍会调整。玩家可使用“推荐布阵”分散站位，或“抱团布阵”保护后排，再自行换位；该操作只改部署，不出售棋子或移动装备。商店显示当前等级各费用概率。

## 旧战斗兼容

schema 3 在 Game 和每份 RoundReport 中记录 `combatVersion`。旧 schema 2 存档：准备阶段进入新规则；进行中的战斗/结算继续使用 `legacy` 羁绊，下一轮才切换 `tactics`；旧历史均按 legacy 回放。schema 1 先迁移装备/野怪字段，再迁移战斗版本。记录的历史胜负不因更新重算。

必要模块验证入口：`npm run test:strategy`。验证阈值可达、最高档不叠加、数值生效、开场跳跃占位、AI 资源守恒/确定性、阶段限制、旧战斗兼容。长期难度与更丰富棋子组合继续按单机实施清单验证。

schema 5 引入 balanced 战斗版本；0.5 使用的 tactics 数值保留，进行中的旧战斗和历史报告继续按原版本回放。详情见 [0.6 平衡调整](balance-06.md)。
