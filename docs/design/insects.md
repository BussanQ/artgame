# 异虫进化与控制战线（0.10）

当前爆裂虫已在[0.82自爆](detonation.md)替换为分星固定基础伤害及2格喷吐；眼虫、杀人蜂、蜘蛛分别见gaze.md、hive.md与dream.md。下列保留0.10原型规则及当时验收记录。

当前规则 `singleplayer-0.10`，战斗版本 `brood`，存档 schema 9。新增眼虫、爆裂虫、蜘蛛、杀人蜂，达到 26 种棋子、14 类羁绊、14 种近战和 12 种远程动作。所有属性和技能数值仍是自主单机平衡，不能视为完整历史版本复原。

## 资料与取舍

2019-05-05 与 2019-11-20 的 17173 攻略均描述异虫 2/4 阈值：两种异虫使一星升二星只需两枚，四种进一步使二星升三星只需两枚；备战席计入种类。11 月文章举出两枚一费眼虫合成后卖 3 金的例子，同时说明售价上限 5 金、蜘蛛在后续版本为三费。来源 S15/S16 记录于 sources.json；本次阅读的是搜索返回正文摘录，不把页面访问失败写成全文核验。

S17 支持爆裂虫自爆、眼虫单体控制和蜘蛛魅惑的能力方向；S18/S19 社区评测支持杀人蜂近身范围攻击。早期蜘蛛费用、控制时长等资料有版本冲突。本版蜘蛛三费、每战一次 2/3/4 秒魅惑、敌方回能降低 25% 以及技能倍率均为原型设计。爆裂虫暂未配置历史“爆破”职业，蜘蛛与眼虫暂归异能；不声明历史分类齐全。

## 合成、交易和持久化

- 异虫种类统计所有持有棋子，包含备战席，同名只算一次；其他羁绊仍只统计上阵。
- 通常三枚同名同星合成。持有至少两种异虫，一星异虫两枚升二星；至少四种时二星也只需两枚升三星。最高三星，其他兵种不受影响。
- `Piece.copies` 记录真实消耗份数。两份形成的二星与三份形成的二星可以合成，分别累加；例如混合升三星可能实际消耗五份。无该字段的旧棋子按常规 1/3/9 份处理。
- 合成保留优先上阵、再按 UID 排序的首枚位置；前三件装备保留，其余返回库存。购买先预演合成，因此满备战席也能买入新异虫种类并触发已有棋子的合并。失败不扣金、不取 UID、不消耗商店卡。
- 异虫售价为 `min(5, 费用 × 3^(星级−1))`；两枚眼虫升二星后可卖 3 金。非异虫沿用常规售价。本版只对异虫采用五金上限，与历史全局出售规则存在差异。
- 出售、淘汰只返还实际份数，不能因两枚升星而凭空增加共享卡池。存档验证检查份数区间、人口、装备与全局卡池守恒。
- schema 8 → 9 补入四种卡池。准备阶段升级为 `brood`；进行中战斗、结算、终局和历史回放保持原版本，下一轮升级。旧四代完整战斗快照哈希仍保持一致。

## 战斗规则

| 棋子 | 能力 | 边界 |
|---|---|---|
| 眼虫 | 满能量：130% 攻击法伤，单体眩晕 1.5 秒 | 目标阵亡不追加控制 |
| 爆裂虫 | 阵亡：自身周围 2 格，最大生命 35% 法伤，受法强加成 | 无能量；每场一次；先标记已触发再结算连锁，死亡伤害计入贡献 |
| 蜘蛛 | 初始 50 能量；满能量魅惑 3 格内攻击最高的合法敌人，攻击 +20%，持续 2/3/4 秒 | 每战一次；召唤物和已魅惑目标免疫；期间不能施法或回能；施法者死亡不解除；到期还原阵营和攻击 |
| 杀人蜂 | 满能量：自身周围 2 格，220% 攻击法伤 | 普攻射程 3 格；无近身敌人保留能量 |

两种不同异能棋子上阵使对方获得能量乘 0.75，包含普攻、受击与支援回能；能量封锁继续优先阻止获取。魅惑只改变当前战斗阵营，不改变原始归属 `homeSide`；胜负、剩余单位扣血、AI 试算和贡献分组使用原始归属。仅把最后敌人魅惑不会直接判胜。魅惑中的爆裂虫若阵亡，按其当时阵营选择爆炸敌人。状态、护盾等已有增益不因魅惑自动清除。

## 展示与操作

新增 ImageGen 透明资产 `eyebug.png`、`blastbug.png`、`spider.png`、`wasp.png`，提示词见 generated-assets.json。棋子由科幻甲壳、青铜饰件和玉色能量构成，为原创重制形象；未取得原作模型。普通攻击分别为凝瞳脉冲、鼓腹钳击、伏身吐丝、振翅甩针，技能含爆炸冲击、魅惑连线与蜂群震荡。被魅惑单位显示临时阵营光圈及剩余秒数；减少动态模式保留文字提示。

顶部“异虫阵容演示”可查看混编十对十实战，不影响当前对局。图鉴可筛选异虫并查看星级说明；备战详情、出售按钮和商店持有份数采用真实交易规则。AI 第六构筑改为异虫蜂群，并识别两枚升星机会。

## 验证与尚存限制

必要模块测试覆盖 13 项异虫规则用例：2/4 阈值、混合合成及装备、出售返池、满备战席购买、淘汰回收、伪造份数、连锁爆炸、眼虫及蜂群范围、魅惑目标和生命周期、胜负与完整/快速模拟一致、异能回能、三阶段迁移。另检查引擎交易、旧回放哈希、动作覆盖、Worker、AI、贡献统计、存档和单机循环相关模块；未运行全量测试。

42 局（7 构筑 × 3 难度 × 2 种子）报告见 [采样数据](../analysis/balance-brood-v010-validation.json)。全部准备、战斗、结算状态合法，26 种棋子都有后期出场记录。每难度仅 14 局，不能据此断言平衡完成；标准难度样本平均名次偏低，异虫低费前排的后期采用率也偏低，后续需要更大样本和真人试玩。计算耗时是 Node 模拟数据，不是浏览器帧率。

仍缺原作完整棋子和历史分类、更多原版能力与变身、弱设备性能验证及单机最终验收。0.10 是单机内容扩展的一步，不等于完整复刻交付。

本次模块分批累计 131 项通过，生产构建与 `git diff --check` 通过。42 局平均名次休闲 2.64、标准 5.29、挑战 6.36（各 14 局）；平均战斗 15.6 秒，平均整轮计算 28.36 ms、最大 154.08 ms。报告 16 个源码哈希与本次引擎一致。

浏览器验证：异虫图鉴四张透明形象正常；1.25 秒战场可见鬼狼的魅惑阵营圈与 2.0 秒剩余提示；完整演示爆裂虫施法 1 次、实际技能伤害 1053，杀人蜂施法 3 次、技能伤害 3847。演示退出后测试存档仍为第 7 回合、77 生命、47 金。390×844 图鉴内容宽度等于可视宽度（331 px），无横向溢出，控制台无错误/警告。

## 0.21 用户反馈：两枚升星条件与提示（2026-11-03）

用户反馈异虫似乎不能两枚升星。排查时当前游戏界面为第16回合，异虫显示1/2未激活，只持有眼虫一种；重复持有同名棋子不会补足种类。现有合成逻辑没有复现“满足条件仍不合成”的问题：四种异虫均验证两种解锁一星2合1、四种解锁二星2合1，且必须同名同星。没有改成单一种类也能两枚合成。

招募区新增常驻进化提示（持有异虫或商店出现异虫时显示），明确当前种类数、一星/二星的实际合成门槛、尚缺几种及备战计数规则。买入第二或第四种的卡牌显示“购入后激活”；原有升星预览继续列出实际合成结果。提示复用`mergeCount`，与购买结算一致。羁绊详情补全“不同种类、同名同星”的表述。

新增5项交易回归用例：逐一验证四种异虫的同名重复不激活、补第二种立即合成并保留上阵位置，以及不能混星、两种异虫不能提前让二星2合1。结合现有满备战、四种、装备、卡池与旧版用例，招募12项、异虫13项通过。结算计时相关偏好9项通过，共34项必要模块验证；TypeScript检查和Vite构建通过，未跑全量测试。

独立localhost:5174测试局通过正常购买爆裂虫和眼虫，验证0/2→1/2→2/4的提示、第二种购买预告及备战席激活。截图：[已激活提示](../preview-insect-evolution-active.jpg)。用户页面仅核对状态，未代为购买、出售或开战。
