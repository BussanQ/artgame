# 0.33 剑奴：狂舞花绽

新增二费傀儡/先锋剑奴，补充能追击的范围技能前排。当前57种可招募棋子，22近战/35远程、22类羁绊；四月名单对应47/53，仍缺6项，未达到完整原版复原。

## 历史依据与本地适配

[S04玩家属性表](../research/historical-tables.json)第二张表第1行记录生命600、攻击76–82、护甲5、攻击间隔1.2秒、射程1。项目取攻击均值79，以0.25秒步进将间隔取为1.25秒；生命和攻击逐星翻倍，初始能量25为本地配置。

[S42的客户端截图](https://www.9game.cn/cczzq/3173740.html)可读出技能名「狂舞花绽」、6次50/100/150技能伤害、持续6.5秒、冷却12秒、持续期间免疫技能伤害；正文说明更新后可以移动。[S43同期玩家评测](https://www.taptap.cn/moment/15220462338441888)支持移动和免控。前者是媒体转载附截图，后者是玩家观察，都不是官方完整配置；S04日期也不同，不据此宣称统一历史版本已经恢复。

技能在满能量、冷却结束且有相邻可见敌人时启动。范围采用自身当前格的欧氏半径1.5格，包含周围八格；首发在1秒后，此后每秒一次，共六次，保护保持到6.5秒边界。每次重新取当前范围内的存活敌人，隐蔽或飞行不阻止范围命中，空放消耗次数。伤害为法术，按施法时技能强度快照计算。半径、脉冲时序、伤害类型和初始能量为本地适配。

旋转中可以移动追击，不普攻、不重复施法、不回能。免疫所有技能伤害类型，但仍承受普通攻击，包括真伤普攻；免疫不消耗护盾、不虚增伤害统计。免控覆盖眩晕、沉默、魅惑、攻速减慢和击退，清除已有攻速减慢；仍受破甲、能量削减与封锁影响。灼烧可附着，但保护期间其技能伤害为零；保护结束后的剩余伤害恢复。精确控制分类属于对玩家描述的本地解释。阵亡或转换成残魂/火种立即清理旋转状态，杜绝死后脉冲。

技能冷却从启动计12秒。结束后恢复普攻和回能。技能伤害不触发普攻吸血或普攻强化；持续期间受到的反伤也按技能免疫处理。不是全伤害无敌，也不额外加甲或回血。

## 实现、表现与接入

`src/engine/swordthrall.ts`保存和推进旋转状态，战斗主循环复用原有占位和寻路逻辑。伤害、控制、召唤落地控制均检查同一有效窗口，完整回放、快速计算和Worker使用同一机制。

ImageGen生成白陶、青玉和金铜双刀傀儡形象，文件为 `public/assets/units/swordthrall.png`。普攻为双刀错步回切，技能为持续双环刀光及转身姿态，配合音效、剩余时间和技能免伤/免控标记。旋转期间不重复显示冷却文本，结束后显示回充。降低动态效果设置保留静态范围与状态提示。完整提示词、尺寸、透明通道和SHA-256见[资产记录](../research/swordthrall-assets.json)，形象是AI重新设计，并非原版模型。

演示菜单新增「傀儡先锋」六对六战斗。二星剑奴在2.75秒、15.5秒两次施放，产生12次范围脉冲；演示持续32.75秒，己方失败，剑奴造成462生命伤害。该演示不额外强化剑奴，不改当前对局资源或禁用；技能命中护盾时破盾单列于战报。

招募、普通三合一、出售、装备和AI均接入。傀儡禁用时剑奴不能出现。AI按三个脉冲命中两人的保守收益估值，再加少量防护价值，不假设每次技能六轮全中。schema32接续schema31，只为缺失剑奴条目补入30份或禁用时0份；保留金币、商店、阵容、AI偏好、禁用结果与旧回放，战斗版本仍为 `armored`。
