# 忍者熊猫：风魔之刃（0.58）

忍者熊猫由一费近战影袭原型改为三费远程输出：蓄力投出飞镖，在固定落点形成持续刃阵。新形象、普通投掷动作、飞行与范围预告、真实逐跳伤害、战斗详情、分析、装备估值、演示和存档迁移均已接入。旧战斗继续使用原近战规则与形象，已有比赛保持其原价格目录。

## 单机适配与结算

- 将原世界半径6/8/10按本地比例换算为欧氏圆形1.2/1.6/2棋格。它不是已证实的原客户端单位换算。渲染边界使用同一个圆，棋盘外部分裁掉。
- 初始能量0。满100能量且20秒技能冷却结束，在普攻射程3格内选一个可见敌人，锁定其当时的格心。蓄力0.5秒后出手；每秒飞4格，不追踪移动目标，也不改变锁定落点。蓄力、飞行速度、格心判定与选敌均为本地参数。
- 飞镖抵达后生成5秒刃阵，落地1秒后第一跳，之后每秒一跳，共5跳。卡面没有说明首跳相位，这个时序公开作为本地选择。不会在蓄力或飞行时提前扣血；已经走出范围的单位不受下一跳伤害，范围内隐蔽单位仍会被范围技能波及。
- 每跳独立结算法术减伤与护盾，只记录实际扣除生命和实际破盾。技能强度在开始蓄力时冻结；攻击装备只增加普通攻击，不放大固定技能伤害。刃阵不触发普通暴击或普攻吸血。残魂和剑奴技能免伤继续适用。
- 蓄力期间不能移动、普攻或开始第二次技能；眩晕、沉默、魅惑、阵亡会中断，消耗的能量及冷却不退还。目标在锁定后移动或死亡不会取消对该地面的投掷。
- 发出后恢复普通行动。弹体与刃阵固定保留发出时的阵营、威力和范围，施法者受控或阵亡不会撤销；每跳按目标当时阵营过滤。不同来源可以重叠。战斗已经结束时不会为了剩余刃阵延长结算。
- 原有刺杀开场跳跃与普通攻击暴击独立保留；新技能不再进行第二次瞬移。武僧嘲讽仍会阻止开始新技能，已经发出的飞镖不撤销。

这些字段让玩家可以通过分散、走位、控制蓄力和技能免伤反制范围输出，而不是只增加一段立即命中的数字。

## 形象与界面

使用内置ImageGen一次生成飞镖形象，保存为[完整透明PNG](../../public/assets/units/panda-shuriken.png)，原始字节/alpha保持不变；没有改写旧双刀形象。武器、黑青护甲与红色布料参考角色定位，保留项目原有熊猫身份和材质；不是从原客户端提取模型。[最终提示词、模式与校验](../research/shuriken-assets.json)完整归档。

普通攻击使用独立“拧腰扬臂掷镖”动作和小飞镖轨迹，技能有蓄力姿态、虚线落点预告、飞行大镖与持续旋转刃阵。减少动态效果时保留静态范围与武器，不持续旋转。场上短提示仅显示蓄力；固定详情列出发出/落地次数、已发生脉冲、有效波及、剩余跳数与技能冷却，分析只统计所查看到的帧。

“菜单 → 战斗演示 → 风魔飞镖”是六对六非等预算演示，用正常战斗引擎生成，不改变当前比赛。实际完整演示12.25秒获胜：忍者二星发出/落地各1、5次脉冲、10次有效波及、生命伤害2646（普攻1028、技能1618）、破盾132。3秒固定详情显示2次脉冲、6次有效波及、半径1.6格、余3跳与17.3秒冷却；与离线引擎结果一致。

## 价格、AI与兼容

新比赛目录三费25份；L3的三费概率仍为0，购买经验到L4后才有15%三费概率。禁用、商店报价、合星、出售、卡池返还和AI均使用比赛固定目录。旧局一费45份继续保持，准备期可升级新的战斗能力，价格和持有份数不重算。

AI按三次脉冲、1.4名目标估计有限首次技能收益，不默认五跳全中或覆盖全军；法强和初始能量装备按法术输出手估值，攻击/攻速装备仍增加普通攻击与充能。这个启发式不等于实际胜率，当前采样的熊猫构筑覆盖不足仍需后续改进。

`shuriken`是第31个独立战斗版本，继承22类连携与异虫2/4双合。schema57的55→56固定为`wushi-control` / 0.57，56→57仅准备期升级；战斗、结果、终局和历史继续原版本，下一准备期再升级。金币、经验、商店、随机数、禁用、背包、装备、棋子、实际份数和`catalogVersion`保持。
