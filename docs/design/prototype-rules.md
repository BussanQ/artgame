# singleplayer-0.22 实际配置

0.22按用户要求增加回合递增收入：1–5回合5金，此后每5回合+2，26回合起15金；利息与战绩奖励另算，玩家与AI一致。旧存档不补发历史收益，见[经济调整](economy-growth.md)。

0.21新增三费摩托骑兵，逐发转火三连发、10秒技能冷却、可中断连发与独立形象。当前50种，详见[规则与平衡差异](motorcycle.md)。S03/S04已恢复部分历史表，但当前仍为单机配置。

0.20新增火焰兵/投弹手、锥形灼烧和独立沉默状态，49种棋子。步兵保留2/3档并加入6种+600生命档位，与历史2/4/6仍有差异。详见[步兵扩充](infantry.md)。

0.19新增一费军医：固定两格范围每秒治疗一次，共四次，可被打断；目前47种棋子。武僧熊猫更正混用名称，保留master ID与现有战斗行为。详见[军医](medic.md)和[历史映射](../research/roster-mapping.md)。

0.18 新增幻鲸：5 费海神/攻城，固定区域每秒造成目标最大生命 3%/4%/5% 真伤，共十次，可被控制/阵亡打断。46 种棋子，数值和范围为自主配置，详见 [幻鲸](whale.md)。

0.17 新增四费不死鸟：固定 5×3 区域持续喷火；二星起首次致死化蛋，三秒存活后重生，每战一次。卡池增量迁移，不改变既有 44 种棋子战斗规则。详见 [不死鸟](phoenix.md)。

0.16 血鹰满能量恢复至最大生命并落地，每次普攻分三次接触命中，每段 60% 攻击；独立结算闪避、护盾、吸血和反伤，控制可中断剩余连击。新版本 metamorph，旧 fleet 回放不变；详见 [血鹰变身](bloodhawk-transformation.md)。

0.15 新增猛禽/陆行者、六种棋子与独立技能。猛禽 2/3 种对地普攻 +15%/35%；陆行者普攻真实伤害。新增声波持续伤害、单次吞噬、减速和可中断蓄力；详见 [规则与边界](wild-and-walkers.md)。

0.14 新增灵能四人组合：全队在 2/4 档受击反弹 20/30 点真实伤害，残魂及召唤物也生效，反伤不连锁、不吸血、不回能。童子提供能量辅助；天师与雷震子提供范围/连锁法伤，详见 [灵能](psychic.md)。

0.13 新增三枚不朽棋子；上场 2/3 种时，阵亡后继续作战 4/6 秒，免疫伤害、无法恢复生命或获得护盾，到期消散，不增加胜利扣血。具体原型技能与历史差异见 [不朽规则](immortality.md)。

0.12 调整：四空军提供 45% 普攻闪避（双空军仍为 15%）；轰炸机初始能量 50；轰炸机、方舟、电蛟施法期间普攻冷却继续计时，仍不能移动或普攻。AI 保留有价值备战、按血量投入经济，选阵补入完整羁绊候选。旧战斗保留旧版本，详见 [空海与选阵修正](fleet-balance.md)。

本文件明确代码与历史原作之间的差异。规则实现位置：`src/data/units.ts`、`src/engine/game.ts`、`src/engine/battle.ts`。

50 种棋子的生命、攻击、护甲、攻击间隔、射程、分类均是原型平衡。部分名称来自历史资料，部分为原型命名，不能将整张配置视为原作图鉴。羁绊包含步兵、装甲、野兽、熊猫、护卫、狙击、先锋、刺杀、骑兵、支援、召唤、傀儡、异虫、异能、空军、海神、攻城、爆破、不朽、灵能、猛禽、陆行者；已配置可达的多档梯度，见 strategy-and-ai.md。护卫提供 250/600 点开战护盾；狙击高档普攻破甲，刺杀开场跳后排；仍为自主单机规则。

本局支持版本化本地存档、损坏备份回退、战斗中断恢复与回合战报（见 persistence.md）；已加入野怪与装备（见 encounters-and-equipment.md）；尚无多人网络、原画资源、原作全量棋子与全部羁绊。原型的目标是验证框架和基础循环，后续对齐工作见 roadmap。
