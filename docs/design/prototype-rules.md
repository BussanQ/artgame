# prototype-0.1 实际配置

本文件明确代码与历史原作之间的差异。规则实现位置：`src/data/units.ts`、`src/engine/game.ts`、`src/engine/battle.ts`。

| 系统 | 当前实现 | 数据性质 |
|---|---|---|
| 对局 | 玩家 + 7 AI，100 初始生命，最多 30 回合 | 8 人参考历史；生命/回合上限暂定 |
| 准备 | 手动开始，无强制倒计时 | 单机便于研究 |
| 棋盘 | 8×8，己方部署在下 4 行，8 格备战席 | 棋盘/备战席有历史依据 |
| 开局 | 10 金，3 级，空阵容 | 原型暂定 |
| 商店 | 5 格、1–5 费、2 金刷新、可跨回合锁定、共享卡池 | 基础规模有依据；概率暂定 |
| 卡池 | 同种 1–5 费各 45/30/25/15/10 份 | 前四档来自 2020 攻略；5 费暂定 |
| 升星 | 3 合 1，最高三星；基础生命攻击每星×2 | 合成有依据；成长统一化，不含异虫例外 |
| 出售 | 原购买份数×单价，全额返还并回池 | 原型简化 |
| 人口 | 最高 10；5 金买 5 XP；每回合 1 XP | 有历史依据；经验升级曲线暂定 |
| 收入 | 5 基础 + floor(金币/10) 上限 5 + 胜利 1 + 连续同结果每 3 回合加 1、上限 3 | 利息有依据；其余与结算顺序暂定 |
| 收入时点 | 战斗结算先更新连续结果，再按结算前余额算利息 | 暂定 |
| 匹配 | 每名存活玩家独立防守另一位存活玩家阵容；轮换对手 | 不宣称复现原作配对算法 |
| 扣血 | 失败扣 2 + 敌方存活棋子的星级总和；平局扣 3 | 暂定 |
| 结束 | 玩家淘汰 / 最后一人 / 30 回合；存活按生命，淘汰按轮次，同分按 ID | 暂定 |
| 技能 | 能量满 100 后下一次攻击造成 2.2 倍伤害 | 统一占位技能，非原作技能 |
| 回蓝 | 普攻 +25，受到攻击 +10 | 暂定 |
| 护甲 | 伤害乘 100/(100 + armor×6) | 原型公式，未恢复原版公式 |

12 种棋子的生命、攻击、护甲、攻击间隔、射程、分类均是原型平衡。部分名称来自历史资料，部分为原型命名，不能将整张配置视为原作图鉴。羁绊包含步兵、装甲、野兽、熊猫、护卫、狙击、先锋、刺杀；仅实现一个阈值。尤其护卫用额外生命代替护盾，狙击用加攻击替代削甲，刺杀用加攻击替代暴击/跳后排，先锋阈值也作了简化。

当前页面刷新即重开，无存档；没有装备、野怪、多人网络、原画资源、音效、完整技能与全部羁绊。原型的目标是验证框架和基础循环，后续对齐工作见 roadmap。
