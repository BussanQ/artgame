# singleplayer-0.7 实际配置

本文件明确代码与历史原作之间的差异。规则实现位置：`src/data/units.ts`、`src/engine/game.ts`、`src/engine/battle.ts`。

| 系统 | 当前实现 | 数据性质 |
|---|---|---|
| 对局 | 玩家 + 7 AI，100 初始生命，最多 30 回合 | 8 人参考历史；生命/回合上限暂定 |
| 准备 | 手动开始，无强制倒计时 | 单机便于研究 |
| 棋盘 | 8×8，己方部署在下 4 行，8 格备战席 | 棋盘/备战席有历史依据 |
| 开局 | 10 金，3 级，空阵容 | 原型暂定 |
| 商店 | 5 格、1–5 费、2 金刷新、可跨回合锁定、共享卡池 | 基础规模有依据；概率暂定 |
| 卡池 | 同种 1–5 费各 45/30/25/15/10 份 | 前四档来自 2020 攻略；5 费暂定 |
| 升星 | 3 合 1，最高三星；基础生命攻击每星×2 | 合成有依据；成长统一化，不含异虫例外 |
| 出售 | 原购买份数×单价，全额返还并回池 | 原型简化 |
| 人口 | 最高 10；5 金买 5 XP；每回合 1 XP | 有历史依据；经验升级曲线暂定 |
| 收入 | 5 基础 + floor(金币/10) 上限 5 + 胜利 1 + 连续同结果每 3 回合加 1、上限 3 | 利息有依据；其余与结算顺序暂定 |
| 收入时点 | 战斗结算先更新连续结果，再按结算前余额算利息 | 暂定 |
| 匹配 | 每名存活玩家独立防守另一位存活玩家阵容；轮换对手 | 不宣称复现原作配对算法 |
| 扣血 | 失败扣 2 + 敌方存活棋子的星级总和；平局扣 3 | 暂定 |
| 结束 | 玩家淘汰 / 最后一人 / 30 回合；存活按生命，淘汰按轮次，同分按 ID | 暂定 |
| 技能 | 20 种独立技能：破甲、护盾、控制、治疗、范围、贯穿、突袭吸血与击退 | 单机自主平衡，非原作历史技能复原 |
| 伤害类型 | 物理受护甲影响；法术固定减伤 20%；真实伤害忽略减伤；护盾优先吸收三类伤害 | 单机暂定 |
| 回蓝 | 普攻 +25，受到攻击 +10；封能期间不能获取能量；马骑兵、玄龟和落箭虎使用独立触发方式 | 暂定 |
| 护甲 | 伤害乘 100/(100 + armor×6) | 原型公式，未恢复原版公式 |

20 种棋子的生命、攻击、护甲、攻击间隔、射程、分类均是原型平衡。部分名称来自历史资料，部分为原型命名，不能将整张配置视为原作图鉴。羁绊包含步兵、装甲、野兽、熊猫、护卫、狙击、先锋、刺杀、骑兵、支援；已配置可达的多档梯度，见 strategy-and-ai.md。护卫提供 250/600 点开战护盾；狙击高档普攻破甲，刺杀开场跳后排；仍为自主单机规则。

本局支持版本化本地存档、损坏备份回退、战斗中断恢复与回合战报（见 persistence.md）；已加入野怪与装备（见 encounters-and-equipment.md）；尚无多人网络、原画资源、原作全量棋子与全部羁绊。原型的目标是验证框架和基础循环，后续对齐工作见 roadmap。

独立技能的实际系数、控制持续时间与战斗事件规范见 [技能系统](skills.md)。当前单机目标的范围和逐项进展见 [单机实施清单](single-player-plan.md)。

新兵种、护甲强化、能量封锁、驱散及支援阵亡回复见 [20 兵种扩充](roster-expansion.md)。

0.6 调低三步兵和四狙击收益，小幅降低最终野怪强度；数值、对照实验和旧战斗兼容见 [0.6 平衡调整](balance-06.md)。

已加入原创合成音效、音量/静音和后台静音，见 [音效说明](audio.md)。

0.7 加入开场冲锋、衰减玄甲、攻击次数箭雨及灵鱼隐蔽/反隐；具体触发与历史规则兼容见 [兵种触发机制](signature-skills.md)。
