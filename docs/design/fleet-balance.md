# 空海、备战与选阵修正：singleplayer-0.12

0.11 的诊断发现 AI 会在轰炸机升到二星后卖掉它，固定压缩备战席；组合搜索提前裁掉维修机、轰炸机，遗漏四空军收益；部分轰炸机在施法前阵亡，引导结束还需等待完整普攻冷却。0.12 分别修正这些问题，没有增加 AI 金币或卡池份数。当前仍是 32 种棋子、18 类羁绊，使用既有 ImageGen 资产。

## 决策变化

- 备战保留价值独立于购买欲望，考虑星级战力、实际卡池份数、同星对子、偏好和关联羁绊。不再固定裁成六格，可保留全部八格。
- 先尝试正常购买，允许满备战直接合成，包括新异虫种类降低合成门槛。确实无空位时，只有明确更有价值的购买才卖低价值非部署单位腾位。
- 生命不超过 55 时最多保留 10 金；不超过 35 或第 25 回合起投入剩余金币。其他情况下三连败降低储蓄线。
- 有界搜索补入可达羁绊完整核心，再填满人口并按同一评分比较。AI 考虑偏好羁绊及其两两组合；玩家推荐考虑全部可达单羁绊核心。休闲仍按单体强度选阵。

回归场景重建种子 307、第 19 回合的 16 枚棋子：旧搜索选阵评分约 2927.49，完整四空军候选约 3030.28。新搜索与玩家推荐均能找到后者；这证明候选遗漏已修复，不代表每局都应强凑四空军。

## 诊断与采样

```sh
npm run test:fleet
npm run audit:airsea -- final
npm run survey:balance -- fleet-v012-validation 137 307
npm run build
```

固定阵容诊断为八对八、全二星、无装备：四种对手 × 双方分散/抱团 × 左右交换，共 32 场。空海成本 60 金，对手为攻城 51、野兽 51、召唤 57、异虫 63。**不是等预算比较，也不是玩家胜率。**0.11 空海 0 胜 7 平，0.12 为 4 胜 7 平；对攻城仍八场全败，对野兽 1 胜 1 平、召唤 2 胜 6 平、异虫 1 胜。不能据此宣称平衡完成。

两局标准难度真实经济流程（种子 137/307）的空海偏好指挥官名次由 7/7 变为 7/3。两局均未实际组成四空军，排名改善不能归因于该羁绊。每轮保存棋子、交易、星级、装备、经济、部署并校验合法。[修正前](../analysis/airsea-audit-before.json)、[最终诊断](../analysis/airsea-audit-final.json)；reserves/cadence/evasion/candidates 报告保留逐步修改证据。旧中间报告仅记录七个来源哈希，最终诊断为十七个，旧记录不是完整源码快照。

另对七种构筑、三档难度、两个种子采样 42 局，使用正常付费操作、共享卡池和奖励，无资源注入。指挥官策略强度固定，所有回合状态合法。[最终报告](../analysis/balance-fleet-v012-validation.json) 记录十六个核心来源哈希。

全部 32 种棋子在第 20 回合后的部署中出现，但维修机仅 6 条、轰炸机 7 条、方舟 8 条；空海挑战档两局均第八。平均战斗 15.42 秒，本机 Node 平均每轮计算 40.93 ms、最大 192.70 ms，不能外推到弱手机。固定策略不等于人类操作，种子有限；空海构筑及熊猫标准/挑战表现仍需诊断。
