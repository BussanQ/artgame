# 后台模式与定向招募

0.83 增加本地后台模式。顶部工具菜单选择“后台模式”，或在未编辑文字且没有弹窗时按 `/` 打开输入框。输入 `/投石车` 等图鉴中的完整兵种名称，按 Enter 或“加入下次刷新”提交；中文输入法确认候选词的 Enter 不提交指令。

在“数量”输入框设置1–5的整数，一次即可加入多枚同名一星棋子。例如指令填 `/投石车`、数量填3，提交后队列增加三枚投石车。队列总容量为五枚，容量或可用库存不足时整批拒绝，保留原队列；支持逐枚移除和清空。未填写数量参数的旧调用仍默认一枚。指令本身不扣金币、不消耗随机数、不预留库存。队列在招募中心标题与工具入口显示数量，随本局存档保存；重新开局清空。

下次玩家成功刷新商店时，先归还旧商店，再按队列顺序从共享卡池取出指定兵种，剩余格正常随机。支持付费手动刷新和未锁店的回合免费刷新；余额不足、非准备阶段、锁店跳过的自然刷新不消费指令。AI 刷新不使用玩家队列。某条临时缺货时保留，其他有库存的指令可先执行；库存补充后再消费。

可指定当前等级随机概率为零的高费兵种，购买仍按该局原价与正常备战、合成规则处理。禁用系列和共享库存保持有效；提交时库存不足、名称无效或队列已满会给出反馈，不改变游戏状态。编辑只在玩家存活的准备阶段开放；战斗、演示、计算中或存档冲突时只可查看。

实现分为 `src/engine/debug-shop.ts` 的指令与队列、`roll` 的玩家定向取卡，以及 `src/ui/debug-shop.ts` 与 `src/debug-shop.css` 的弹窗。普通刷新仍执行原有的五次随机抽取；无指令的固定种子商店与改动前一致。

规则版本为 `singleplayer-0.83`，存档 schema82，战斗版本仍为 `detonation`。81→82只升级格式，不调整战斗、价格目录、卡池、金币、历史与播放进度。80→81的中间规则版本固定为0.82后继续迁移。缺省队列兼容旧存档；新字段只接受不超过五个已知且未被禁用的兵种 ID。
