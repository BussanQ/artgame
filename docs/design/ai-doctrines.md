# 0.28 对手构筑风格与正式装甲AI

规则 `singleplayer-0.28`，schema27；兵种仍为54种，战斗版本仍为 `infantry`。新增正式装甲爆破偏好，新局从8种风格中选7种分配给AI，并将风格保存到本局。棋子、羁绊、经济、难度参数和战斗数值没有在本轮调整。这是单机策略设计，不是已恢复的原版AI配置。

## 解决的问题

0.27默认七种偏好的63局代理采样中，铁猿只在1局、2回合上阵；装甲偏好诊断9局则有7局选用、5局升至二星。旧代码用 `AI_PROFILES[player.id]` 同时决定购买、攒息、备战保留、候选阵容和侦察说明，七个座位固定且没有装甲/爆破方向。新兵种虽可招募，这条构筑并未进入正式对手候选。

## 新局分配与策略行为

候选为步兵防线、幽影猎杀、荒原兽群、空海舰队、熊猫宗师、异虫蜂群、灵能不朽、装甲爆破。新局根据种子打乱候选，取7种，不重复；同一座位不再绑定固定风格。不是每局必有装甲AI，也不保证每个AI最终形成所偏好的羁绊。

分配使用独立随机流，并混合相近种子以避免首个抽样结果高度相关；不消费原商店随机数。相同种子仍产生相同开局商店、相同风格和确定性决策。玩家本人保持自由构筑，没有AI策略字段。策略在整个对局中固定，后续回合和刷新不重新抽取。

装甲爆破偏好装甲、爆破、攻城，储蓄偏移为0；早期优先铁狗、铁猿及可用拼图，再考虑投石车、摩托骑兵、铁巨神等。没有硬编码必买名单，不赠金币、棋子或装备，允许根据实际商店使用过渡阵容。低血投入、升级条件、合法购买/卖出/刷新/经验接口均沿用现有规则。

`profileFor`统一解析购买、储蓄、备战评分、组合选阵、排行榜提示和侦察面板。挑战档继续进行同样的可见对手试算；玩家推荐布阵仍使用自由指挥偏好。

## 存档与兼容

`Player.aiProfile`为可选、稳定字符串标识，不使用候选列表位置保存新局策略。保存校验只接受8个已知AI标识，玩家0不能带该字段；非法字符串、对象、数字、null等按损坏存档处理。

schema26/0.27→27仅升级封套，不重分配旧对手，不改随机数、金币、生命、商店、阵容、装备、战报和播放状态。旧玩家缺少字段时继续使用原七种座位策略。旧座位映射应保留兼容顺序，未来增量不能随意重排原七项。schema25→26固定写入0.27再继续迁移，避免跳过中间版本。

Worker接收完整Game，策略随结构化克隆进入计算并返回；恢复正在播放的战斗只重建已有参战阵容，不重新购买或抽取风格。原战斗数值未更改，20个旧回放哈希一致。

## 可见信息

排行榜在对手名字下直接显示风格，侦察按钮提示与弹窗使用同一数据。侦察仍只读当前部署，明确提示AI会在开战前调整。作战指南加入8选7和整局保持说明。桌面与窄屏共用风格标签，没有另设可能不同步的显示配置。

## 剩余目标

本轮补上正式AI构筑覆盖的一个缺口，没有完成整体单机目标。历史名单仍缺9项、已有8项分类差异，装甲/爆破等历史梯度与时间切片需核对；休闲偏易、挑战偏难，仍需更多独立种子和人工构筑体验。下一步应继续规则和兵种还原，不能用AI风格数量或绿色测试替代可玩性完成判定。
