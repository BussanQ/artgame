# 牛魔变身与冲锋表现

本次补齐现有「牛魔变」技能的视觉形态，规则仍为 singleplayer-0.8。战斗引擎的冲锋、范围伤害和眩晕没有改动，也没有新增商店棋子或存档字段。

## 表现

- 成功施法时，从持斧牛魔过渡为四足巨牛，冲锋完成后恢复。普通攻击继续使用挥斧动作。
- 冲锋沿已有事件的起终点连续移动，带地面拖迹、落点冲击环和受画质限制的尘粒；取消该动作原先通用的紫色传送表现。
- 已贴近目标时，原地变身震击，不伪造位移。变身持续不超过 3.2 tick（0.8 秒），且不超过当前攻击间隔；下一次普通攻击或死亡中断形态。
- 所有姿态仅由当前及过去战斗帧计算。暂停、回放跳转和速度切换无需额外动画状态；减少动态效果时直接显示落点形态，保留名称和生命信息。
- 历史规则回放也可使用新外观，结算事件和战斗结果不变。

这是牛魔短时施法形态，不代表已实现全兵种的持续变身系统。历史资料 S06 提及牛魔变为巨牛冲锋；这里的动画时长为网页表现设计，不作为原作技能持续时间或冷却证据。

## 短生命周期单位修复

召唤物可能在同一 tick 出生并被击杀，前一帧没有该单位。原死亡淡出逻辑直接读取前一帧单位的生命，可能抛出异常。现在以单位首次出现且死亡的帧作为淡出起点，限定回溯窗口；缺失前帧不再中断绘制。
