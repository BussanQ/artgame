# 藤妖荆棘缠绕 / singleplayer-0.66

藤妖从一次攻击倍率伤害加眩晕，改为分段缠绕、逐段汲取和目标失效后的转火，补上不朽前排的续航与控制空隙。新局本体为二费、650生命、120平均攻击、5护甲、1格、1.7秒攻击间隔；保留初始25能量和原有内置ImageGen藤妖形象。

## 资料与适配边界

[S05原作者评测](https://www.taptap.cn/moment/15216144952591652)的藤妖段明确描述多段控制、每段回血、目标死亡后不浪费剩余控制，以及段间能放出瞬发技能。页面修改时间为2019年7月15日，作者说明主体采用S1末期；本次普通HTTP取得完整原文，不能把此前网页读取失败说成没有资料。原始HTML指纹归档在[研究记录](../research/thornbind-history.json)，HTML本体只存`tmp/`。

S04实测表第36行提供上述本体属性，99–141攻击取均值120，冷却60秒。名称“荆棘缠绕”由[S62开发方署名的2021年6月10日公告](https://news.17173.com/z/zzq/content/06102021/180944537.shtml?_platform=PC)确认。该后期公告新增5/7/9护甲，不并入当前早期目录；技能名称跨期引用，不宣称所有字段来自同一客户端。

没有取得可读的早期技能原卡，不能确认段数、各星伤害、控制时长、回血比例或精确施法距离。当前采用三段、起手0.5秒、间隔0.75秒、每段0.5秒控制，把原型160%攻击总预算分到三段，每段按实际生命伤害等量自疗。这些是明确的单机适配，补齐已知玩法方向，不冒称原版数列。初始25能量、全程维持、法术分类及1格转火范围也属于本地选择。

## 实际战斗规则

满能量且60秒冷却结束时，在1格内锁定可见敌人，冻结攻击和技能强度。三段按累计整数差分摊预算，每段读取当前魔抗、护盾和免伤；已扣除生命才提供汲取，纯破盾、过量伤害、免伤和溢出治疗不重复计收益。

每段0.5秒眩晕采用终点不包含的计时；下一段前留出0.25秒行动空隙。0.66–0.69的原型盾兵可趁此释放即时护盾与控制，打断藤妖后续段数；0.70改为[护甲盾阵](bulwark.md)后不再以盾击中断维持。灵鱼能驱散当前束缚，下一段仍可重新施加。狂舞、已激活残魂和涅槃火种免疫这次控制；火种可以受伤，破碎后剩余段数寻找其他合法敌人。

锁定目标死亡、走出1格、隐蔽或转成友军后，余下段数转向1格内最近可见敌人，距离相同按稳定ID排序；无目标则结束，记录目标丢失。维持期间不能移动、普攻或重入，最后一段同帧也不额外攻击。受控、沉默、魅惑、阵亡或残魂到期会立即终止；反伤致死不借本段汲取复活。残魂仍可施法，但不恢复生命或延长存在时间。

## 表现与信息

Canvas绘制抬藤维持姿态、双藤连接、目标身上的短束缚环和向自身回流的生命光点。控制空隙中连接变松、束缚环消失；驱散后的画面跟随真实状态。减少动态效果时保留连接与束缚提示，停止摆动和光点。

战场详情和战斗分析分别记录结算段数、有效命中、束缚、实际汲取治疗、转火和中断，回看只读取对应时间片。普通攻击继续使用原双藤甩鞭动作。AI按两段收益及部分有效治疗估值，不假定完整维持或必定回血。

入口为“菜单 → 战斗演示 → 荆棘汲取”，一个普通引擎二对二片段，不影响正式比赛。二星藤妖携能量与生命装备，在2.5、3.25和4秒结算三段，实际汲取113、113、112，共338生命；8.5秒进入残魂、12.5秒消散，20.5秒己方失败。该局面不是等预算平衡比较，没有为演示胜利调参。

## 骨龙属性纠错

本轮重新目视S04第34行：骨龙攻击间隔为2.2秒，129平均攻击除以2.2约为表中58.6 DPS。0.65代码和其研究记录误写1.2秒，而原始`historical-tables.json`已经正确记录2.2。当前新局改为8.8模拟步；0.65的4.8步只留在历史定义中，避免旧回放变化。1.7／2.2秒是名义属性，实际普攻仍受0.25秒模拟步取整影响。
