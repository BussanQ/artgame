## 数据恢复流程

先选定历史目标版本，再定位对应图鉴截图/更新公告 → 人工录入/OCR 辅助 → 对照原图复核 → 标记字段级来源 → 用同版本独立来源交叉校验 → 写入版本目录 → 校验和审核后接入引擎。未确认值保持 null，不以猜测冒充历史值。

建议记录：`sourceId / url / publishedAt / accessedAt / targetVersion / field / value / unit / confidence / notes`。同字段出现冲突时保留两个版本的证据，不直接覆盖。
