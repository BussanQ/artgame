## 已交付的技术基线

- 严格类型 TypeScript 工程、Vite 开发与生产构建、引擎模块测试。
- 8 人本地演习（玩家 + 7 AI）、共享有限卡池、5 格商店、刷新与锁定。
- 8×8 棋盘、8 格备战席、部署/交换/撤回/出售、三合一升星。
- 等级/人口/经验、金币/利息/连续胜负、8 类简化羁绊。
- 12 种原型棋子、格子寻路、自动普攻/统一技能、固定 tick 战斗快照与播放。
- 扣血、淘汰、卡池回收、30 回合终局与排名、图鉴和操作指南。

这是一套可运行的开发框架与垂直原型，尚未实现原版全量棋子、技能、装备、野怪和在线对战。研究资料的历史值不会自动进入原型配置。
